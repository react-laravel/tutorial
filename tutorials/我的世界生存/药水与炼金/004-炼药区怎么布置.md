# 炼药区怎么布置

炼药区如果只是随手把酿造台往角落一丢，后面每次做药都会很烦。真正好用的炼药区，重点是材料集中、顺手、安全。

## 1. 核心组成

- 酿造台
- 箱子或桶装材料
- 玻璃瓶和水源
- 下界疣种植区或近距离存放
- 一点照明和操作空间

## 2. 最顺手的摆法

- 中间放酿造台。
- 一侧放常用材料和烈焰粉。
- 另一侧放瓶子、水源、成品药水。
- 如果空间够，下界疣田直接放在隔壁。

## 3. 为什么材料要集中

- 炼药最烦的是反复翻箱子。
- 你一旦要连续做几种药水，动线差会非常折磨。
- 集中后，整套流程会像工作台区一样顺。

## 4. 炼药区放哪里合适

- 放在主基地里。
- 靠近附魔、仓储或村民体系也不错。
- 不建议丢在很远的单独房间，除非你本来就做功能分区基地。

## 5. 一个实用结论

炼药区不需要很大，但一定要顺手。你只要愿意反复走进去用，它就算是成功的布局。
