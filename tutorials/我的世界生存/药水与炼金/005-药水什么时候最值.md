# 药水什么时候最值

药水不是任何时候喝都赚。很多人觉得药水没用，往往不是药水弱，而是喝的时机不对。

## 1. 高风险探索前

- 下界找要塞
- 海底找遗迹
- 大型洞穴深探
- 末地或高空远行

这些场景里，药水的价值会远高于平时乱喝。

## 2. 明确知道自己要做什么时

- 要加速跑图，就带速度。
- 要下海，就带夜视或水肺。
- 要碰岩浆环境，就带抗火。

药水最怕的是“先喝了再说”，这样经常白白浪费时效。

## 3. 为什么日常不一定要常驻

- 普通砍树、整理基地、简短挖矿不一定需要。
- 药水做起来有成本，别为了心理安慰乱喝。
- 真正常驻的，往往是有成熟材料线和明确习惯的后期玩家。

## 4. 一个实用结论

药水最值的时候，是你提前知道风险和目标的时候。把药水当成“关键场景强化”，它的收益会非常高。
