# 烈焰棒和下界疣怎么带回家

很多人第一次去下界，知道这两样重要，但回到家还是没把炼药真正启动。问题通常不在打不到，而在于没有把它们当成“必须建立长期补给”的材料。

## 1. 烈焰棒为什么不能只拿一点

- 它能做烈焰粉。
- 烈焰粉关系酿造台运作。
- 后面还会持续消耗，不是拿一次就永远不用。

## 2. 下界疣为什么一定要种起来

- 你不可能每次缺药水都回下界要塞找现成的。
- 自己种一小片后，药水线会轻松很多。
- 和灵魂沙一起带回主世界，效率最高。

## 3. 第一次带回家建议拿多少

- 烈焰棒多拿一点，别只拿够开门票的量。
- 下界疣至少带一批能当种子的数量。
- 灵魂沙也顺手拿一些，避免后面专门补跑。

## 4. 回家后立刻做什么

1. 留一部分烈焰棒做备用。
2. 把下界疣种起来。
3. 在基地里固定一个炼药区。
4. 把瓶子、下界材料和附加材料放在一起。

## 5. 一个实用结论

第一次下界拿到这些材料后，最重要的不是“我已经见过”，而是“我已经把它们变成稳定补给”。只有这样，炼药才算真正开始。
