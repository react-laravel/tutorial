# 装备怎么长期维护

很多人不是做不出好装备，而是好装备用了几次就开始舍不得用。装备维护做得好，整套成长体验会轻松很多。

## 1. 为什么维护很重要

- 材料和附魔来得不容易。
- 真正强力的装备通常投入很大。
- 如果每次都靠重做整套来解决损耗，成本非常高。

## 2. 经验修补为什么几乎是后期标配

- 只要你有稳定经验来源，就能边用边修。
- 它能明显降低你重做装备的频率。
- 和交易、刷怪、挖矿这些日常活动都能联动。

## 3. 什么时候该做备用装

- 你经常远行。
- 你准备打高风险内容，比如下界深挖或末地远征。
- 你已经有足够资源，不怕备用装吃库存。

## 4. 怎么避免装备越修越贵

- 不要把乱七八糟的小附魔一直叠来叠去。
- 重要装备尽量在路线成型后再做成品。
- 关键核心装优先走图书管理员和清晰的合成路线。

## 5. 一个实用结论

装备维护的核心不是省着不用，而是让它可持续。只要经验和附魔路线通了，强装备就应该大胆拿出来用。
