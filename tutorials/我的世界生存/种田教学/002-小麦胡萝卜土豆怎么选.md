# 小麦、胡萝卜、土豆怎么选

很多新手不是不会种，而是不知道该把时间投在哪种作物上。生存里真正影响体验的，不是“能不能种”，而是“哪种最值得你先种”。

## 1. 小麦

### 小麦的优点

- 最容易开局获得，打草就有种子。
- 能做面包。
- 能繁殖牛和羊，价值一直在线。

### 小麦的缺点

- 作为主食不算顶级，面包要 3 个小麦才合成 1 个。
- 如果你已经有更好的食物，小麦更多是拿来养动物。

## 2. 胡萝卜

### 胡萝卜的优点

- 可以直接吃，不用熔炉。
- 能繁殖猪和兔子。
- 也是村民繁殖和农民村民运作的重要食物之一。

### 胡萝卜的缺点

- 开局不一定拿得到，通常要靠村庄或沉船等战利品。

## 3. 土豆

### 优点

- 种植稳定，收成直观。
- 烤马铃薯是前中期非常好用的主食。
- 比面包更适合你在基地里批量生产后直接吃。

### 缺点

- 需要熔炉和燃料，才能把价值完全发挥出来。

## 4. 甜菜根值不值得优先种

通常不值得优先投入。

- 能吃，但实战里不如烤土豆顺手。
- 可以拿来染色或做甜菜汤。
- 如果地很多、种子顺手拿到了，可以补种一点，但别当主力。

## 5. 最实用的优先级

推荐顺序：

1. 土豆
2. 胡萝卜
3. 小麦
4. 甜菜根

这个顺序不是绝对收益表，而是更适合普通生存玩家的发展路线。

- 土豆负责稳定主食。
- 胡萝卜负责补充和联动村民、猪。
- 小麦负责动物养殖和开荒过渡。

## 6. 怎么搭配最省事

- 小麦不要停，但不用占最大面积。
- 土豆可以做主田。
- 胡萝卜保持一小块备用田，够繁殖和补给就行。

## 7. 一句话结论

开荒只有小麦就种小麦；一旦拿到土豆和胡萝卜，尽快把主力切过去，尤其是土豆，实用性非常高。
