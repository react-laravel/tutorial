# 动物养殖入门

严格来说这是养殖，不是纯种地，但在生存里它和农田几乎是一套体系。你手里的小麦、胡萝卜和种子，最后很多都会变成更稳定的肉类和材料。

## 1. 先养什么最值

推荐顺序：

1. 牛
2. 鸡
3. 羊
4. 猪

## 2. 牛为什么最优先

- 牛排是很稳的食物。
- 皮革能做书，直接关系到书架和附魔。
- 用小麦繁殖，和小麦田联动非常自然。

如果你只想先做一个最值得的动物圈，那就先做牛圈。

## 3. 鸡的价值

- 鸡肉能吃。
- 羽毛能做箭。
- 鸡占地小，数量起来很快。

鸡用各种种子繁殖，所以哪怕你还没把主食田做大，鸡圈也能很早开起来。

## 4. 羊和猪什么时候做

### 羊

- 羊毛做床、地毯和装饰。
- 前期如果还没拿够羊毛做多张床，羊很有价值。

### 猪

- 猪排是正常食物。
- 但总体优先级不如牛。
- 如果胡萝卜和土豆很多，再顺手做猪圈就行。

## 5. 动物圈怎么搭最省心

- 每种动物分开圈养。
- 入口用栅栏门，别图省事直接留缺口。
- 圈里插火把，防止夜里刷怪。
- 不用一开始就做很大，先够放 4 到 8 只就够了。

## 6. 一个稳妥的起步方案

1. 先做一块小麦田。
2. 拉两头牛回家。
3. 做一个最简单的牛圈。
4. 每轮小麦成熟后就繁殖一次。

只要这个循环跑起来，你的食物和皮革问题就会好解决很多。
