# 开荒第一块农田

前期最怕的不是没铁，而是没吃的。你只要先做出一块稳定的小农田，后面探索、挖矿和夜里防守的容错都会高很多。

## 1. 先准备什么

- 一个木锄或石锄。
- 一些种子，打草就能拿到小麦种子。
- 一格稳定水源，河边、池塘边都行。
- 几根火把，保证夜里不黑。
- 如果附近怪多，顺手做一点栅栏。

## 2. 最稳的起步布局

最常见、也最好记的布局就是一格水带一圈农田。

- 中间放一格水。
- 水周围往四个方向各延伸 4 格耕地。
- 做成完整一圈后，就是经典的 9x9 农田。

## 3. 开荒时先种什么

- 只有小麦种子时，先种小麦。
- 如果村庄里拿到了胡萝卜和土豆，优先补种它们。

## 4. 实际操作顺序

1. 选一块离家近、晚上也敢去的地方。
2. 挖一格放水，或者直接贴河岸种。
3. 用锄头把泥土翻成耕地。
4. 把手里已有的种子或作物种下去。
5. 周围插几根火把，防止夜里刷怪。

## 5. 前期最容易犯的错

- 农田离基地太远，结果收菜要冒险跑图。
- 完全不插火把，晚上怪一刷就没人敢收。
- 只种小麦，结果长得慢、回饱效率也一般。
