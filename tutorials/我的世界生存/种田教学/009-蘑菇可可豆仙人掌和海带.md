# 蘑菇、可可豆、仙人掌和海带

这几种都不属于“必须第一时间做”的农田，但它们属于很典型的副业种植。平时不起眼，真要用染料、食物、燃料或装饰时，没有又很烦。

## 1. 蘑菇

### 什么时候值得种

- 你想做蘑菇煲当过渡食物。
- 你想收集一些特殊装饰材料。
- 你愿意在基地里留一个阴暗角落做副业种植。

### 重点是什么

- 蘑菇更怕环境不对，不是随便插地上就稳定量产。
- 最简单的做法是专门留一块低光区域。
- 不追求高效率的话，少量备用就够了。

## 2. 可可豆

### 可可豆什么时候值得种

- 你需要棕色染料。
- 你想补一点丛林风格装饰材料。
- 你在丛林附近定居，拿可可豆很方便。

### 可可豆种植要点

- 可可豆种在丛林原木侧面。
- 占地不大，适合贴墙做一排。
- 它更偏装饰和染料，不是主力食物作物。

## 3. 仙人掌

### 仙人掌什么时候值得种

- 你需要绿色染料。
- 你想做一个几乎不用管的副业田。
- 你后面准备用熔炉顺手烧成染料或经验。

### 仙人掌种植要点

- 仙人掌种在沙子上。
- 周围摆放要留意，别让它一长出来就被旁边方块顶掉。
- 适合单独拉成长条，不要和别的作物挤在一起。

## 4. 海带

### 海带什么时候值得种

- 你住在海边或水域附近。
- 你想做一点稳定燃料或食物补充。
- 你准备以后做水下区域、码头或海边基地。

### 海带种植要点

- 海带适合在竖直水柱里种。
- 早期手收就够，长起来很快。
- 晒成干海带以后，存储和使用都更方便。

## 5. 这些作物怎么安排

- 蘑菇放阴暗副房间。
- 可可豆贴墙做成一排。
- 仙人掌和海带尽量单独分区。

不要把它们硬塞进主食农田区，不然会显得又乱又不好收。

## 6. 一个实用结论

- 这些都不是“先做才活得下去”的内容。
- 但基地一旦稳定，补一点会让你的材料链舒服很多。
- 最值得最早补的，通常是仙人掌或海带；最看环境的，则是可可豆和蘑菇。
