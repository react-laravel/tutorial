# 绿宝石循环与资源交换

村民体系真正强的地方，不是某一笔交易特别赚，而是你能把低价值、可再生的资源，稳定换成绿宝石，再换成更高价值的东西。

## 1. 什么叫绿宝石循环

- 你先批量生产一种容易获取的资源。
- 用它和合适的村民换绿宝石。
- 再把绿宝石换成附魔书、装备、红石材料或其他难拿的资源。

## 2. 最常见的起步循环

- 作物 -> 农民 -> 绿宝石
- 纸 -> 图书管理员 -> 绿宝石或书系资源
- 腐肉 -> 牧师 -> 绿宝石

## 3. 为什么作物循环通常最稳

- 可再生。
- 产量可控。
- 和种田、农民、村民繁殖体系都能联动。

这也是为什么很多人的第一条稳定经济线，不是矿物，而是农田。

## 4. 什么时候循环开始成型

- 你已经有一片稳定农田。
- 你有 1 到 2 个固定职业的村民。
- 你能持续拿出同类资源反复交易。

做到这一步后，绿宝石就不再只是“偶尔捡到的货币”，而是你基地里的稳定产物。

## 5. 不要犯的错

- 只盯着贵的交易，不做基础供给。
- 没有批量资源来源，就想让整套交易站高速运转。
- 绿宝石刚有一点，就乱花在短期不重要的项目上。

## 6. 一个实用结论

村民体系的核心不是交易本身，而是循环。只要你的循环通了，绿宝石、附魔和装备都会跟着顺起来。
