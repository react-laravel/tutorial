# 六、下矿准备

## 1. 下矿前带什么

最低配置：

- 石镐或铁镐。
- 石剑或铁剑。
- 食物一组左右。
- 火把至少 32 个，越多越好。
- 木头或木板。
- 工作台。
- 熔炉。
- 一桶水，拿到铁后尽快做。
- 盾牌。

拿到铁之后，强烈建议制作：

- 盾牌：1 铁锭 + 木板。
- 铁镐：挖钻石、红石、金矿、绿宝石。
- 铁桶：装水，防岩浆、防摔、做传送门。
- 铁剑或铁斧。
- 铁套。

## 2. 重要矿物用途

### 煤炭

用途：

- 火把。
- 烧矿。
- 烤食物。

### 铁

前中期最重要资源。

优先级：

1. 盾牌。
2. 铁镐。
3. 铁桶。
4. 铁剑或铁斧。
5. 铁胸甲。
6. 铁护腿。
7. 铁头盔。
8. 铁靴子。
9. 剪刀、打火石、铁砧等。

### 金

用途：

- 做金靴子，下界防猪灵主动攻击。
- 和猪灵交易。
- 合成金苹果。
- 动力铁轨等红石用途。

### 红石

前期不是必须，但可以挖一些。

用途：

- 指南针。
- 红石机关。
- 药水材料相关。

### 青金石

附魔需要青金石。

### 钻石

钻石非常关键。

如果前期只有 3 个钻石，优先制作钻石镐。因为钻石镐可以挖黑曜石，用来制作下界传送门和附魔台。

钻石优先级建议：

1. 钻石镐。
2. 附魔台需要 2 个钻石。
3. 钻石剑或钻石斧。
4. 钻石胸甲。
5. 其他钻石装备。

如果你打算靠村民交易获得钻石装备，钻石可以优先留给钻石镐和附魔台。

## 3. 挖矿层数建议

不同版本矿物分布不完全一样。较新的版本中：

- 铁矿：高山和地下都能找到。
- 钻石：深层更常见，接近世界底部更容易出。
- 红石、青金石、金：地下深处常见。

稳妥做法：

- 前期找天然洞穴，优先拿暴露的煤和铁。
- 有铁套和水桶后，再去深层找钻石。
- 深层挖矿时注意岩浆湖。

## 4. 下矿安全规则

非常重要：

- 不要垂直往下挖，容易掉进岩浆或洞穴。
- 不要垂直往上挖，可能被沙砾、沙子、岩浆压住。
- 洞穴里先插火把再深入。
- 听到怪物声音要放慢。
- 看到苦力怕先举盾或拉开距离。
- 看到岩浆先用水桶处理。
- 背包快满就回家，不要贪。
- 重要资源回家存箱子，不要全带身上乱跑。
