# 五、如果找到村庄

村庄是非常重要的前期资源点。

## 1. 可以拿什么

村庄里常见有：

- 干草块：分解成小麦，能做很多面包。
- 箱子：可能有食物、铁锭、绿宝石、工具、盔甲。
- 床：可以拿，但不要让村民全部没床，否则村庄发展会受影响。
- 作物：小麦、胡萝卜、土豆、甜菜根。
- 工作站：堆肥桶、砂轮、制图台、讲台、锻造台等。

找到村庄后，基本可以解决前期食物问题。

## 2. 保护村民

村民很有价值，后期可以交易：

- 农民：换食物和绿宝石。
- 图书管理员：换附魔书，比如经验修补、保护、锋利。
- 盔甲匠：换盔甲。
- 工具匠：换工具。
- 武器匠：换武器。

建议：

- 晚上睡觉，避免僵尸杀村民。
- 给村庄插火把。
- 用方块或栅栏堵住危险入口。
- 不要乱打铁傀儡。

## 3. 村庄交易前期思路

如果你想稳扎稳打，可以发展村民交易。

简单路线：

1. 多种小麦、胡萝卜、土豆。
2. 找农民换绿宝石。
3. 找图书管理员刷附魔书。
4. 找盔甲匠、工具匠、武器匠换钻石装备。

刷图书管理员附魔书的方法：

1. 放讲台，让无职业村民变成图书管理员。
2. 查看第一个交易是否是想要的附魔书。
3. 如果不是，打掉讲台再放回去。
4. 重复直到出现满意交易。
5. 交易一次后职业和交易会锁定。

常见强力附魔：

- 经验修补。
- 保护 IV。
- 锋利 V。
- 效率 V。
- 耐久 III。
- 无限或经验修补弓。
- 摔落保护 IV。
