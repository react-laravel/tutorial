# 十二、末地打龙

## 1. 进入末地后的第一件事

进入末地可能出现两种情况：

- 出生在主岛上。
- 出生在主岛外的黑曜石平台上。

如果在岛外平台：

- 不要乱跑。
- 用方块搭桥到主岛。
- 小心末影龙撞你。
- 可以从平台向主岛方向慢慢搭。

## 2. 末地基本规则

末地危险点：

- 看到末影人眼睛会激怒它。
- 末影龙会冲撞玩家。
- 末影龙会喷龙息。
- 黑曜石柱顶部有末影水晶，会给龙回血。

避免激怒末影人：

- 视角尽量看地面。
- 可戴雕刻南瓜头，末影人不会因对视攻击你，但视野会变差。

## 3. 摧毁末影水晶

末影水晶在黑曜石柱顶端，会治疗末影龙。

摧毁方法：

- 用弓射。
- 爬上柱子打掉。

有些水晶外面有铁栏杆，需要爬上去破坏。

爬柱子注意：

- 带方块搭上去。
- 上去前确认龙没有马上冲撞。
- 打水晶时离远一点，水晶爆炸伤害很高。
- 可以先破坏铁栏杆，再离远射水晶。

推荐先用弓解决没有铁栏杆的水晶，再处理有铁栏杆的。

## 4. 打末影龙

水晶清理完后，末影龙不能回血。

攻击方式：

- 龙飞行时，用弓射。
- 龙停在中间基岩祭坛上时，用剑或斧砍头部。

注意：

- 龙停在祭坛上时，弓箭通常无效或效果不好，近战输出更好。
- 不要站在龙正前方太近，容易被击退。
- 看到地上的紫色龙息，立刻离开。
- 被打飞时，尝试用水桶落地或末影珍珠自救。

## 5. 击败后做什么

末影龙死亡后：

- 掉大量经验。
- 中间出现返回传送门。
- 上方有龙蛋。
- 远处会生成末地折跃门，用末影珍珠可以进入外岛。

龙蛋获取方法：

1. 不要直接挖，直接挖会传送走。
2. 右键龙蛋让它传送到附近地面。
3. 在龙蛋下面第二格放火把。
4. 挖掉龙蛋下面的方块。
5. 龙蛋掉到火把上变成物品。

进入返回传送门后，会播放终末之诗，然后回到重生点。
