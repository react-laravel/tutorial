# 十六、推荐的一条稳妥通关路线

下面是一条比较适合新手的路线。

## 阶段 1：出生到第一晚

1. 砍 3-5 棵树。
2. 做工作台、木镐。
3. 挖圆石，换石器。
4. 找羊做床。
5. 找食物。
6. 找一个平原、河边或村庄附近建临时基地。

## 阶段 2：建立食物来源

1. 打草拿种子。
2. 做锄头，开小麦田。
3. 找牛、羊、鸡、猪。
4. 做栅栏和动物圈。
5. 用小麦繁殖牛羊，用种子繁殖鸡，用胡萝卜或土豆繁殖猪。
6. 做箱子存资源。

## 阶段 3：下矿发展

1. 带火把、食物、木头、石镐下矿。
2. 找煤和铁。
3. 做盾牌、铁镐、水桶。
4. 继续挖铁，做铁套。
5. 找钻石。
6. 如果有 3 个钻石，先做钻石镐。

## 阶段 4：准备下界

1. 找岩浆池。
2. 用钻石镐挖黑曜石，或用水桶岩浆桶浇筑传送门。
3. 做打火石。
4. 做金靴子。
5. 带食物、方块、弓箭、盾牌进入下界。

## 阶段 5：下界收集材料

1. 保护下界传送门。
2. 记录坐标。
3. 找下界堡垒。
4. 击杀烈焰人，获得烈焰棒。
5. 用金锭和猪灵交易，获得末影珍珠。
6. 回主世界。

## 阶段 6：寻找要塞

1. 烈焰棒分解成烈焰粉。
2. 合成末影之眼。
3. 扔末影之眼找方向。
4. 找到要塞。
5. 找末地传送门房间。
6. 设置重生点，整理装备。

## 阶段 7：击败末影龙

1. 进入末地。
2. 搭桥到主岛。
3. 用弓摧毁末影水晶。
4. 处理带铁栏杆的水晶。
5. 龙飞时弓射。
6. 龙停在祭坛时近战输出。
7. 躲龙息，避免看末影人。
8. 击败末影龙，进入返回传送门。
