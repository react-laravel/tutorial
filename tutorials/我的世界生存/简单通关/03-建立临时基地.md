# 三、建立临时基地

## 1. 基地位置怎么选

推荐选在这些地方附近：

- 河流旁：有水，方便种甘蔗和种田。
- 平原：视野开阔，适合种田养动物。
- 村庄旁：资源多，村民交易方便。
- 山脚：方便下矿。
- 森林边：木头充足。

不推荐刚开始住在：

- 沙漠深处：木头少，食物少。
- 雪山高处：行动不便，容易摔死。
- 沼泽深处：夜晚怪多，视野差。
- 黑森林深处：树太密，怪容易藏起来。

## 2. 临时基地需要什么

不用一开始就造豪宅，实用最重要。

基础配置：

- 工作台。
- 熔炉。
- 箱子。
- 床。
- 火把。
- 简单围墙或门。
- 一块农田。
- 一个动物圈。

建议把床、箱子、熔炉放在安全屋里，门口插火把，附近也插火把，减少刷怪。

## 3. 火把很重要

火把可以照明，也能减少怪物生成。

火把合成：

- 煤炭或木炭 + 木棍。
