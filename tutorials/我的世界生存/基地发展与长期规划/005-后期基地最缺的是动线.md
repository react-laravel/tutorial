# 后期基地最缺的是动线

很多后期基地的问题，不是材料不够，也不是房间不够，而是走起来太累。你如果每做一件事都要来回穿半个基地，再漂亮的建筑也会很烦。

## 1. 什么叫动线差

- 常用功能区离得太远。
- 入口和出口绕。
- 仓库不在核心位置。
- 经常要上下好多层才能完成一轮补给。

## 2. 为什么后期更容易出这个问题

- 功能越来越多。
- 扩建往往是哪里有空就补哪里。
- 前期随手摆的结构，后面会变成长期负担。

## 3. 怎么慢慢修正

- 把高频功能集中。
- 给常走路线铺正式通道。
- 仓储、工坊、出入口尽量形成清晰核心。

## 4. 一个实用结论

后期基地真正决定体验的，往往不是面积，而是动线。只要你走起来顺，整个基地的价值都会立刻上一个台阶。
