# 临时基地怎么过渡到主基地

很多人一直住在第一间小木屋，不是不能玩，而是玩到中期以后会越来越挤。真正顺的基地发展，是知道什么时候该从“能住”升级到“好用”。

## 1. 什么叫该升级了

- 箱子开始乱堆。
- 工具、熔炉、附魔、种田都挤在一起。
- 每次补给都要来回绕。

## 2. 过渡时别做什么

- 一口气想搬成超级大城堡。
- 还没规划动线就开始大拆大建。
- 只顾外观，不先保住基本生活功能。

## 3. 更稳的过渡方式

1. 先选定长期位置。
2. 先搬仓储和睡觉区。
3. 再搬熔炼、种田、附魔这些高频功能。
4. 最后慢慢处理旧基地和美化。

## 4. 一个实用结论

临时基地过渡到主基地，不是一次性大迁移，而是分步骤把高频功能先转过去。这样最不容易中途崩盘。
