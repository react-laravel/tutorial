# 结构刷怪区与特殊生成

不是所有刷怪都只看群系和光照。某些结构本身就有特殊生成规则，这也是为什么要塞、下界要塞、海底神殿、女巫小屋这类地方，常常能做出特定农场。

## 1. 什么叫结构特殊生成

- 某些结构区域里，会优先生成特定怪物。
- 有些地方甚至基本只刷结构对应的怪。
- 这会压过一部分普通地形和群系逻辑。

## 2. 常见例子

- 下界要塞和烈焰人、凋灵骷髅。
- 海底神殿和守卫者。
- 女巫小屋和女巫。
- 掠夺者前哨站和掠夺者。

## 3. 为什么生电特别在意这个

- 因为结构刷怪区能让目标怪更集中。
- 你不用在普通群系里和一大堆别的怪抢刷怪位。
- 这就是很多特化农场能成立的根本原因。

## 4. 一个实用结论

只要一个农场是“专门刷某一种怪”，你就该先想：它是不是利用了结构生成规则。很多高效率装置，核心不是图纸，而是地点选对了。
