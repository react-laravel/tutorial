# 区块加载与模拟距离

很多人会说“机器坏了”，但真实情况往往只是机器所在的区块根本没在工作。区块和模拟距离，是理解农场、村民、红石和刷怪装置能不能正常运行的底层前提。

## 1. 什么是区块

- 世界不是整张地图一起运算的。
- 它会按区块分开加载和处理。
- 你靠近时，周围区块会工作；你走远后，有些区块就会停下来。

## 2. 什么是模拟距离

- 不是“看得见”就一定在工作。
- 真正重要的是它有没有被当成正在模拟的区域。
- 超出模拟距离后，很多实体 AI、村民行为、刷怪和装置逻辑都会停。

## 3. 哪些内容最怕超出模拟距离

- 刷怪塔
- 村民工作与铁傀儡农场
- 漏斗和红石运输链
- 依赖实体移动的机器

## 4. 哪些东西相对没那么怕

- 纯静态建筑
- 你不需要实时产出的装饰区
- 某些只需要保留状态、不需要持续运算的结构

## 5. 一个实用结论

很多装置不是搭错了，而是你离它太远了。只要牵涉到刷怪、村民、漏斗、实体和自动产出，就先检查它有没有在真正工作的区块里。
