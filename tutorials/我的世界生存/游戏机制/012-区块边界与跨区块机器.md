# 区块边界与跨区块机器

区块边界经常是机器莫名其妙出问题的源头。你肉眼看它是一台完整机器，但游戏并不是按“这台机器”在算，而是按 16×16 的区块一块一块在加载和处理。

## 1. 为什么区块边界会带来麻烦

- 机器一半在这个区块，一半在另一个区块。
- 你移动位置后，可能出现一部分还在工作，另一部分已经停了。
- 运输链、村民、矿车、掉落物都可能在边界处表现异常。

## 2. 哪些装置特别怕跨区块

- 长物流线。
- 矿车运输。
- 村民和铁傀儡装置。
- 多段式刷怪和处决系统。

## 3. 实际建造时怎么规避

- 尽量把核心逻辑和关键收集区放在同一块里。
- 大型装置先确定中心，再往外扩，不要随手越线。
- 如果你发现机器时好时坏，就先怀疑它是不是被区块切开了。

## 4. 一个实用结论

区块边界不是高级玩家才需要管的事。只要机器够长、够复杂、够依赖实体，它迟早会影响你，早点考虑会省很多返工。
