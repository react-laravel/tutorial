# 漏斗冷却与物流节奏

漏斗看起来只是搬运物品，但它并不是瞬间传送。只要你的机器里开始出现长漏斗链、多个分类口或者高频输入，漏斗本身就会变成节奏瓶颈。

## 1. 为什么说漏斗有节奏

- 漏斗按固定频率搬运物品，不是无上限吞吐。
- 一两个漏斗通常感觉不出来，链一长就会明显变慢。
- 所以很多新手会误以为机器卡了，其实只是物流速度跟不上。

## 2. 哪些机器最容易被漏斗拖慢

- 自动熔炉阵列。
- 分类仓储。
- 大型刷怪塔收集链。
- 高频掉落的竹子、甘蔗、仙人掌一类机器。

## 3. 为什么老手常减少漏斗长度

- 漏斗越多，延迟越长。
- 漏斗越多，后台持续检查也越重。
- 能用水流拉长距离时，通常比整条全漏斗更省资源也更顺。

## 4. 一个实用结论

漏斗适合做精确交接，不适合无脑承担所有长距离运输。只要物流量一大，就该开始考虑“哪里必须用漏斗，哪里该换成别的运输方式”。
