# 村民、床、工作站与铁傀儡

村民系统看起来像交易系统，实际上底层是“床、工作站、路径和行为”共同决定的。铁傀儡农场也不是凭空出铁，而是靠村民机制在工作。

## 1. 村民为什么老出问题

- 床位绑定乱了。
- 工作站绑定乱了。
- 村民走不到该走的位置。
- 你以为它“看到了”某个点位，实际上路径根本不通。

## 2. 铁傀儡为什么能刷出来

- Java 常见做法是利用村民恐慌或交流行为触发铁傀儡生成。
- 这要求床、村民距离、最近是否有傀儡、可生成方块等条件都满足。
- Bedrock 更偏“村庄条件是否完整”，比如床、村民数量、工作状态和村庄中心。

## 3. 这和生电为什么直接相关

- 铁傀儡农场本质上就是村民机制农场。
- 村民繁殖、交易大厅、农民种田也都吃这些底层规则。
- 你不理解 POI、床位和路径，装置就容易时好时坏。

## 4. 一个实用结论

村民装置最怕“看起来差不多”。床、工作站、站位和路径，只要有一个环节不稳定，铁傀儡和交易体系就都容易出毛病。
