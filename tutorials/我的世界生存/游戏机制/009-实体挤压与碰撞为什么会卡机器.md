# 实体挤压与碰撞为什么会卡机器

只要一台机器里塞了很多生物、矿车、船或者掉落物，碰撞和挤压问题就会开始出现。它不只是让画面卡，还会直接改变机器表现。

## 1. 什么是实体挤压

- 多个可碰撞实体被塞在很小空间里时，会互相顶开、重叠、乱走位。
- 数量太多时，还可能触发挤压伤害。
- 这会让农场、缓存仓、处决区和村民装置都变得不稳定。

## 2. 哪些地方最容易出问题

- 牛、鸡、猪等生物圈养区。
- 刷怪塔缓存区。
- 村民交易大厅的站位设计。
- 堆太多矿车、船的运输或固定方案。

## 3. 为什么它会影响生电

- 实体一多，寻路和碰撞计算就会变重。
- 走位一乱，村民、怪物和运输实体就可能站错位置。
- 有些机器明明线路没错，却因为实体堵塞而表现异常。

## 4. 一个实用结论

机器里能少堆实体就少堆。很多“玄学卡机”问题，最后查下来都不玄，纯粹是实体太多、太挤、太久没清。
