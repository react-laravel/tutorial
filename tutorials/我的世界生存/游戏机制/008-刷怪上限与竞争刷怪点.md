# 刷怪上限与竞争刷怪点

自然刷怪不是无限往外吐怪，而是在一套上限里分配机会。你看到刷怪塔产量忽高忽低，很多时候不是塔坏了，而是别的地方把刷怪机会抢走了。

## 1. 什么叫刷怪上限

- 自然生成的生物会按类别受上限控制。
- 这个上限不是“某个平台专属”，而是周围符合条件的位置一起分。
- 所以你平台能刷，不代表机会一定都给它。

## 2. 什么叫竞争刷怪点

- 地下洞穴。
- 附近没点亮的地表阴影区。
- 山体内部、废弃矿洞、深洞和各种漏光不到的位置。

这些地方如果也能刷怪，就会一起吃掉自然生成机会。

## 3. 为什么高空塔和清洞有用

- 高空塔是把有效刷怪位置集中起来。
- 清洞、点灯、铺半砖不是为了好看，而是为了删掉竞争位置。
- 竞争位置越少，目标平台拿到的生成机会越多。

## 4. 一个实用结论

很多刷怪问题，本质不是“平台黑不黑”，而是“附近还有多少别的地方也能刷”。只要理解这一点，你看刷怪塔就不会只盯着图纸了。
