# 生物消失与持久化

很多装置出问题，不是怪没刷出来，而是刷出来以后消失了。理解“哪些会消失、哪些会常驻”，是做刷怪塔、村民装置和展示型基地的基础。

## 1. 普通自然怪为什么会消失

- 大部分自然生成的敌对怪、本来就不是永久存在的。
- 玩家离太远，它们会直接消失或进入可消失状态。
- 所以你离开太久，没做持久化处理的怪，回来很可能已经没了。

## 2. 什么叫持久化

简单理解就是：这只生物被游戏认定为“不要按普通自然怪处理”。

常见做法有：

- 用命名牌命名。
- 放进船或矿车。
- 让它捡起物品。
- 对某些生物做驯服、繁殖、装桶等玩家交互。

## 3. 为什么这对生电很重要

- 铁傀儡农场常要让吓村民的怪长期存在。
- 某些展示区想保留稀有怪，也必须做持久化。
- 不做这一步，装置可能一开始有用，后来突然失效。

## 4. 一个实用结论

只要你希望一只生物“长期留在这里”，就别把它当普通自然怪对待。命名、装船、装矿车，都是最常见的稳定处理方式。
