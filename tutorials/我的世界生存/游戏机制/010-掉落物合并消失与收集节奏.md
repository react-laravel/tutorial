# 掉落物合并、消失与收集节奏

怪物掉落、作物掉落、机器吐出的物品，本质上都是地上的掉落物实体。它们不是永远留着，也不是一掉出来就自动进箱子，所以“掉落物怎么活着走到箱子里”本身就是一套机制。

## 1. 掉落物会发生什么

- 同类物品会尝试合并，减少实体数量。
- 长时间躺在地上会消失。
- 如果区块不工作，很多计时和运输也就不会继续推进。

## 2. 为什么这会影响产量

- 收集太慢，物品可能先消失。
- 一次爆出太多，地面容易堆积成一片。
- 收集口太窄，水流或漏斗吃不干净，就会漏物。

## 3. 生电里常见的处理思路

- 尽快把掉落物送进水流、漏斗矿车或漏斗口。
- 尽量别让物品长时间停在露天地面。
- 对高产机器，优先考虑连续运输，不要等它先堆一地再想办法收。

## 4. 一个实用结论

很多机器不是“没有产出”，而是“产出掉在地上没被及时带走”。看一台机器稳不稳，收集链和生产链一样重要。
