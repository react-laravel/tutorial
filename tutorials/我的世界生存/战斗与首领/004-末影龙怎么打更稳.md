# 末影龙怎么打更稳

打龙并不一定需要极限装备，但一定需要清晰流程。很多翻车不是因为伤害不够，而是水晶没拆明白、位置没站好、补给没分配好。

## 1. 打龙前最该准备什么

- 足够的方块和食物。
- 弓箭、床或其他明确拆水晶思路。
- 缓降、回复或至少可靠的摔落应对手段。

## 2. 打龙时最容易乱的地方

- 一上来直冲塔下，被龙和末影人一起干扰。
- 水晶没清干净就急着输出。
- 掉进空中或被击飞后没有马上自救。

## 3. 更稳的基本流程

- 先外围观察和拆容易的水晶。
- 再处理高塔和铁笼水晶。
- 最后等龙俯冲时稳定输出，不要乱追。

## 4. 一个实用结论

末影龙战更像流程战，不像纯拼装备。你只要先拆水晶、稳站位、留自救手段，第一次打龙也完全能很稳地过。
