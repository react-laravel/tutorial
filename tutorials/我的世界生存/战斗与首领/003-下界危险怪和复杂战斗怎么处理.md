# 下界危险怪和复杂战斗怎么处理

下界难打，不只是怪更猛，而是地形、坠落、火焰和多方向来敌经常叠在一起。你如果还按主世界那套“看见怪就上”的思路打，下界会特别容易掉装备。

## 1. 下界最怕什么

- 恶魂把你炸下去。
- 烈焰人远程逼位。
- 猪灵、疣猪兽和地形落差一起夹击。

## 2. 在下界打架先做什么

- 先修路，再推进。
- 先做掩体，再交战。
- 先想退路，再想战利品。

## 3. 哪些习惯能明显提高生存率

- 过桥和熔岩边别边跑边打。
- 在要塞、堡垒这种高风险区域，先清门口和转角。
- 抗火、金头盔、方块和远程手段常常比多一格伤害更重要。

## 4. 一个实用结论

下界战斗最重要的不是输出，而是控场。你先把路、掩体和撤退点做出来，再打怪，难度会完全不一样。
