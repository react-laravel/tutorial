# 前中期战斗怎么减少暴毙

前中期最常见的问题不是打不过，而是死得太突然。很多暴毙并不是装备太差，而是站位、补给和撤退习惯全都没建立起来。

## 1. 别把每场战斗都打成硬拼

- 看到多只怪先后退，不要急着冲。
- 优先把怪拉到自己熟悉的地形里打。
- 夜里和洞里最怕被包，不怕单挑。

## 2. 前期最重要的是容错

- 盾牌比多一把更好的剑更能救命。
- 食物要够，别总想着半血也能继续顶。
- 背包里留方块、火把和水桶，很多时候比多带一件武器更重要。

## 3. 哪些死法最常见

- 被苦力怕贴脸炸。
- 洞穴里被弓箭手和近战怪一起夹。
- 下矿时被摔落或 lava 接战一套带走。

## 4. 一个实用结论

前中期战斗的目标不是打得帅，而是别乱打。只要你开始主动控距离、控地形、控补给，死亡率会立刻降一大截。
