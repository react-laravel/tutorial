# 凋灵和袭击什么时候值得打

凋灵和袭击都属于“不是主线马上逼你打，但迟早可能会碰”的内容。它们值不值得现在打，不只看你敢不敢，而是看你打完以后能不能把收益接住。

## 1. 凋灵什么时候适合打

- 你已经有稳定装备和补给。
- 你知道要在哪里打，不会把主基地炸烂。
- 你确实准备进入信标阶段，而不是单纯想试试。

## 2. 袭击什么时候适合打

- 你能守住村庄，不会把村民体系直接打崩。
- 你有清杂怪和处理远程怪的能力。
- 你想要不死图腾或准备玩掠夺者相关内容。

## 3. 哪些时候不该急着打

- 你装备刚成型，但补给和地形控制还没跟上。
- 你还没选好战场。
- 你打完也暂时用不上对应收益。

## 4. 一个实用结论

凋灵和袭击都不是“能打就立刻打”的内容。先确认场地、补给和收益，再开战，体验会比硬着头皮上好太多。
