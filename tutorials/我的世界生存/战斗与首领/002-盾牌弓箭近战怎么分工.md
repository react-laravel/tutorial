# 盾牌弓箭近战怎么分工

很多人打架时只有一种习惯：不是全程冲脸，就是全程远程。真正稳定的战斗方式，通常是盾牌、弓箭和近战轮着用，而不是死守一种打法。

## 1. 盾牌什么时候最值

- 面对骷髅、苦力怕、下界复杂地形时。
- 你不确定前方到底有几只怪时。
- 你需要先观察局面、争取一口喘息空间时。

## 2. 弓箭什么时候最值

- 高低差明显的地形。
- 你能先手处理远处威胁时。
- 打龙、清高台怪、削薄怪群时。

## 3. 近战什么时候最值

- 怪已经被你拉成单个。
- 地形安全，没有额外怪能绕后。
- 你确认一波能稳稳收掉对手时。

## 4. 一个实用结论

盾牌负责保命和观察，弓箭负责先手和削威胁，近战负责收尾。你把这三样分工想明白，战斗会比单纯“拿剑乱砍”稳很多。
