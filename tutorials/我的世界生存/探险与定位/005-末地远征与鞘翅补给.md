# 末地远征与鞘翅补给

打完末影龙以后，真正危险的探索通常才刚开始。末地远征看起来像“去拿个鞘翅”，实际是一次长线高风险操作。

## 1. 为什么末地远征不能太随便

- 地形断裂多。
- 掉虚空就很难挽回。
- 路程可能比你想的长很多。

## 2. 远征前最好准备什么

- 足够方块
- 食物
- 备用装备
- 末影珍珠
- 潜影盒或至少较清爽的背包空间

## 3. 鞘翅拿到以后别急着浪

- 先考虑怎么安全带回家。
- 烟花火箭供应没起来前，鞘翅的使用频率可能没你想的那么高。
- 真正舒服的飞行体验，依赖后续材料链和补给。

## 4. 一个实用结论

末地远征的关键不是“拿到没有”，而是“拿到后能不能稳稳带回来并长期用起来”。准备越完整，这趟越值。
