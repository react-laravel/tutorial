# 海底遗迹和林地府邸值不值得去

这两类地点都很有代表性：一个资源和挑战都集中在水下，一个路程长、战斗密度高。它们都值得去，但不是任何阶段都该去。

## 1. 海底遗迹什么时候值

- 你已经有夜视、水肺或至少不错的水下准备。
- 你想拿海晶类方块或做后续海底建设。
- 你有把握处理守卫者压力。

## 2. 林地府邸什么时候值

- 你已经有较稳定装备。
- 你准备长途远征。
- 你想打唤魔者、拿不死图腾或体验高风险探索。

## 3. 为什么别太早冲

- 海底遗迹前置准备不足时会非常折磨。
- 林地府邸路远、房间多、战斗节奏长。
- 对前中期来说，投入和回报不一定立刻划算。

## 4. 一个实用结论

这两类地点都值得去，但更适合作为“装备已经成型后的目标”。太早去，通常风险比收益更高。
