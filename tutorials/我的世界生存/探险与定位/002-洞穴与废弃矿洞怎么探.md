# 洞穴与废弃矿洞怎么探

洞穴和废弃矿洞的收益很高，但也最容易把人打乱节奏。真正稳的探法，不是见路就冲，而是逐段推进、留路、留光、留退路。

## 1. 洞穴为什么容易翻车

- 岔路多。
- 高低差复杂。
- 怪容易从看不见的角度冒出来。

## 2. 最稳的探法

- 一段一段推进。
- 走过的关键路口插火把。
- 危险位置先封半边再看。
- 听到怪多就先停，不要硬冲。

## 3. 废弃矿洞为什么更麻烦

- 洞穴蜘蛛威胁很高。
- 立体结构更多，容易漏怪。
- 你会很容易因为想顺手拿矿，结果被多个方向包夹。

## 4. 什么情况下该撤

- 食物已经明显不够。
- 护甲状态差。
- 背包快满且路线已经开始记不清。
- 遇到刷怪笼但你现在处理不了。

## 5. 一个实用结论

洞穴探险的核心不是一次挖光，而是稳定回收。只要你愿意留路、留灯、留退路，死亡率会下降很多。
