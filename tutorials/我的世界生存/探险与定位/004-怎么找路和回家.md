# 怎么找路和回家

探索最怕的不是没打赢，而是打赢了却回不来。找路能力看起来不起眼，但它直接决定你敢不敢越走越远。

## 1. 最简单的做法

- 沿路做明显标记。
- 记大方向，不只记局部地形。
- 重要节点留火把、柱子或小路标。

## 2. 为什么不要只信感觉

- 地形很容易看起来差不多。
- 你打完怪、挖完矿以后，记忆会快速混乱。
- 天色、天气和视角变化都会误导判断。

## 3. 常见回家保命手段

- 带床过夜。
- 带船应对水路和搬运。
- 带指南针、地图或记录关键坐标。

## 4. 如果真的迷路了

- 先停下来，不要继续乱跑。
- 回想上一个明确地标。
- 如果有坐标或标记，从已知点慢慢回推。

## 5. 一个实用结论

找路不是技术活，而是习惯。你越早养成做标记、记方向、留已知点的习惯，远行就越稳。
