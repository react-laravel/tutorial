# 远古城市、海底神殿、林地府邸和末地城什么时候去

这几类结构都很有代表性，但共同点是：太早去往往会很折磨。它们更像阶段性目标，而不是看见就该冲的地方。

## 1. 远古城市什么时候去

- 你已经理解潜行、撤退和高风险探索。
- 你准备好备用装备和稳定补给。
- 你不是拿普通下矿思路硬闯。

## 2. 海底神殿什么时候去

- 你已经有夜视、水肺或不错的水下准备。
- 你打算认真做海洋路线或海晶材料路线。
- 你能处理守卫者和远古守卫者压力。

## 3. 林地府邸和末地城什么时候值

- 林地府邸适合装备稳定后的长途远征。
- 末地城适合打龙后正式进入外岛探索阶段。
- 两者都不是越早越值，而是准备越充分越值。

## 4. 一个实用结论

这几类结构真正的价值都很高，但都更吃阶段和准备。你晚一点去，往往不是亏，而是把原本痛苦的流程变成稳定收益。
