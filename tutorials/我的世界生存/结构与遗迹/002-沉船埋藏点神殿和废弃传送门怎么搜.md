# 沉船埋藏点神殿和废弃传送门怎么搜

这几类结构最适合当早期和中前期的收益点，因为它们通常不需要你打太长时间，也不需要极限装备，但能明显改善物资储备。

## 1. 沉船和埋藏点为什么常常最赚

- 找起来相对容易。
- 回报通常覆盖食物、铁、金、地图和早期工具需求。
- 对海边或海岸开局的人尤其友好。

## 2. 沙漠神殿搜的时候注意什么

- 先确认落脚安全。
- 先拆陷阱，再拿箱子。
- 别为了快直接跳底部中心。

## 3. 废弃传送门的价值是什么

- 能提前拿黑曜石、金块和下界相关资源。
- 有时候能把你进下界的节奏整体往前推。
- 但别为了修门把自己全部资源砸空。

## 4. 一个实用结论

这几类结构真正的价值，不在于一次暴富，而在于很早就能补齐关键物资。你要的是稳稳拿到手，而不是为了贪快翻车。
