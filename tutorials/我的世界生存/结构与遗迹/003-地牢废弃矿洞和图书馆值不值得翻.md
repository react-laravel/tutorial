# 地牢、废弃矿洞和图书馆值不值得翻

这类地下结构没有神殿那么直给，但非常适合中期资源补充。它们的核心价值往往不是某一个超级战利品，而是一整套稳定的探索收益。

## 1. 地牢为什么常常顺手就值

- 体量小，拿完就走。
- 刷怪笼本身就可能有后续价值。
- 箱子奖励常常能补到前中期缺口。

## 2. 废弃矿洞的价值在哪里

- 线路多，矿物、木材、蜘蛛网和箱车都可能顺手拿到。
- 很适合一边探索一边补物资。
- 但也特别容易因为地形复杂而死得稀里糊涂。

## 3. 图书馆什么时候特别有用

- 你开始准备附魔或长期探索时。
- 想拿书、纸和后续强化材料时。
- 找到要塞图书馆后，很多中期路线都会更顺。

## 4. 一个实用结论

地下结构的收益更偏“补全资源线”，不是一锤子买卖。它们值不值，很多时候取决于你现在缺的到底是矿、书，还是后续刷怪点位。
