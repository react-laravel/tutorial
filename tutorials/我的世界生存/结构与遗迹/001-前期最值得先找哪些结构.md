# 前期最值得先找哪些结构

前期找结构，最重要的不是“看见什么都去”，而是优先盯那些投入低、回报直接的目标。找对了，发展速度会快很多；找错了，只会变成长途送装备。

## 1. 最值得优先找的几类

- 村庄。
- 沉船。
- 废弃传送门。
- 沙漠神殿。

## 2. 为什么它们优先级高

- 村庄能直接提升生存起点。
- 沉船和埋藏点常常给你早期飞跃资源。
- 废弃传送门能加快下界准备。
- 沙漠神殿收益直接，战斗门槛也不算夸张。

## 3. 哪些结构别太早上头

- 海底神殿。
- 林地府邸。
- 远古城市。
- 堡垒遗迹。

这些地方不是不值，而是太早去通常风险大于回报。

## 4. 一个实用结论

前期找结构的核心是“少冒高风险，先吃低门槛高收益”。村庄、沉船、神殿这类地方，往往才是最稳的起飞点。
