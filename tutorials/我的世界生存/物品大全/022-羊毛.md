# 羊毛

分类：动物材料

## 获取方式

- 剪羊毛或击杀羊获得。剪羊更推荐，因为羊会继续长毛。

## 主要用途

- 制作床、地毯、旗帜、画、装饰方块。
- 可用染料染色。

## 可以和什么物品结合

- 3 个羊毛 + 3 个木板：床。
- 2 个羊毛：地毯。
- 羊毛 + 木棍：旗帜。
- 羊毛 + 木棍：画。

## 小技巧

- 不同颜色羊毛可以直接从染色羊身上剪，适合批量获得彩色羊毛。
- 床在下界和末地会爆炸，不能当普通床使用。
- 地毯可以铺在栅栏上，玩家能跳上去，动物通常出不来。

## 通关价值

前期床的关键材料，后期也是装饰常用材料。
