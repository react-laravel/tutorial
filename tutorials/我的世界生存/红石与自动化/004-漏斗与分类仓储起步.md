# 漏斗与分类仓储起步

漏斗是自动化里最容易被低估的东西。很多机器的核心不在多复杂，而在于“物品最后怎么稳定流到该去的地方”。

## 1. 漏斗最直接的价值

- 自动收集。
- 自动转运。
- 帮你减少地上物品乱飞和手动整理。

## 2. 为什么仓储要尽早起步

- 东西一多，整理时间会迅速爆炸。
- 你越往后玩，越需要稳定收纳，而不是到处塞箱子。
- 哪怕只是最简单的分类，也能显著提升使用体验。

## 3. 起步别做太大

- 先做几个高频物品分类。
- 先解决石头、木头、矿物、作物这类大宗资源。
- 不要一开始就想把全仓库做成完美系统。

## 4. 一个实用结论

分类仓储的第一目标不是完美，而是减压。只要你打开箱子时不再一团乱，就已经很值了。
