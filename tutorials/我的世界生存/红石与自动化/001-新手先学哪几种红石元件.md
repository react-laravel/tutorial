# 新手先学哪几种红石元件

红石最容易把人劝退的地方，不是太难，而是零件太多。新手如果一开始什么都想学，通常最后只会更乱。

## 1. 最先认识的几样东西

- 红石粉
- 红石火把
- 中继器
- 比较器
- 活塞
- 漏斗

## 2. 为什么先学这些

- 红石粉负责传信号。
- 红石火把是很多反相和基础逻辑的起点。
- 中继器能延长和整理信号。
- 比较器常用于检测容器状态。
- 活塞和漏斗分别对应“推动作”和“搬东西”。

## 3. 不用一开始就碰什么

- 超复杂时钟电路。
- 大型隐藏门。
- 视频里那种堆很多细节才成立的高难机器。

## 4. 一个实用结论

新手先把“传信号、延时、检测、推动、搬运”五件事搞懂，很多实用装置就已经能看明白一大半了。
