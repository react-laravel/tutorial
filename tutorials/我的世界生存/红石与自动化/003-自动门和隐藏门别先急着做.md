# 自动门和隐藏门别先急着做

很多人一碰红石，就想先做自动门和隐藏门。问题是这类装置很显眼，但对前中期生存的实际帮助，通常没有你想的那么大。

## 1. 为什么它们常常优先级不高

- 主要是体验和观感提升。
- 对资源、时间和调试要求往往更高。
- 真正影响生存效率的收益，不如基础仓储和资源自动化明显。

## 2. 什么时候开始值得做

- 你已经有稳定基地。
- 常用自动化都做了一部分。
- 你开始追求基地观感和功能细节。

## 3. 为什么新手容易卡在这里

- 布线稍微一乱就看不懂。
- 地形、空间、活塞位置很容易互相打架。
- 为了隐藏效果，调试难度比表面装置高很多。

## 4. 一个实用结论

自动门和隐藏门很好玩，但更适合在你基础红石已经稳了以后再碰。前期别让它们占掉你太多时间。
