# 红石排错思路

红石最烦的不是搭，而是搭完不工作时完全不知道从哪看。排错如果没有顺序，越改通常越乱。

## 1. 先看最基础的问题

- 电有没有通到。
- 方向有没有反。
- 活塞、漏斗、中继器朝向对不对。
- 有没有被别的方块或信号干扰。

## 2. 为什么要一段一段查

- 红石一旦系统稍微复杂，就不能靠整体肉眼硬猜。
- 把装置拆成几段测试，最容易定位问题在哪。
- 一次只改一个地方，也更不容易把原本能用的部分改坏。

## 3. 新手最常见的排错误区

- 一口气改很多处。
- 不知道自己改了什么。
- 直接照搬视频，但版本或朝向其实不一致。

## 4. 一个实用结论

红石排错的核心不是天赋，而是顺序。只要你能从电源、方向、时序、分段测试一步步排，问题大多都能找到。
