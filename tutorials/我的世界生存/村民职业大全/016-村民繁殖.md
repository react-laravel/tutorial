# 如何繁殖村民

本文面向 Java 26 版本的生存通关，讲清楚现代村民繁殖的关键条件、常见问题和一个稳妥的繁殖房搭建思路。

## 1. 目标

- 让两个村民进入“愿意”状态。
- 给新村民预留一个可用床位。
- 让繁殖过程在安全、可控的空间里完成。

## 2. 繁殖条件

### 2.1 必须有两名村民

- 任意职业都可以，双农民很方便，因为农民会自动种田/分享食物。
- 让村民站在同一个区域内，方便彼此交互。

### 2.2 必须有可用床

- 版本 1.14 及以后，村民繁殖只看床，不看门。
- 每个新出生的婴儿需要一个“未被占用”的床。
- 床必须有空格并与村民可见到的工作区保持连接。
- 推荐预留 2~4 张额外床以保证繁殖稳定。

### 2.3 食物：让村民“愿意”

为了让村民进入繁殖状态，至少满足以下食物之一：

- 每个村民 `3 个面包`
- 每个村民 `12 个胡萝卜` 或 `12 个土豆` 或 `12 个甜菜`

现代版本中，农民村民会自动收集农作物并分享给其他村民，因此“农民+田地”的配置最省力。

### 2.4 空间与安全

- 建议在一个封闭繁殖房中操作，防止僵尸、爬行者、开花鬼干扰。
- 入口用栅栏门或活板门隔离，避免村民跑出。
- 确保天花板足够高，婴儿可以生成。1.5 格高度即可。

## 3. 最简单的繁殖房搭建

### 3.1 基本布局

- 在地面挖一个小房间，建议 5x5 或 7x5。
- 房间中央放置 2~4 张床，床头朝向墙壁或面向房间。
- 在床旁再放置 1~2 个工作站（推荐堆肥桶 + 另一个你想要的职业工作站）。
- 让两名村民分别拿到不同职业，这样更容易稳定。

### 3.2 让农民帮你

- 将一名村民变成农民，给他一个堆肥桶。
- 准备几行胡萝卜/土豆/甜菜，让农民收割并分享。
- 农民会主动把食物分给其他村民，从而让他们快速变成“愿意”状态。

### 3.3 确保床位足够

- 不要把床塞成一个乱堆，床旁最好留一点空间给婴儿生成。
- 确认床没有被其他村民“占用”，空床可以在旁边看到床头上方出现“爱心”的效果。

## 4. 操作步骤

1. 把两个村民放到同一间房间。
2. 准备好至少 2 张空床，建议预留 3 张以上。
3. 给每名村民喂食：
   - `3 个面包`，或者
   - `12 个胡萝卜/土豆/甜菜`
4. 等待村民进入“愿意”状态。愿意后会出现爱心粒子。
5. 当条件满足时，村民会自动繁殖，房间里会生成一个婴儿村民。

## 5. 你可以怎么做得更稳妥

### 5.1 让农民做分享

- 如果你有农民村民，让他收割作物并分享给其他村民，可以自动生成繁殖的能量。
- 只要房间中保留一个农民，繁殖过程会更省时。

### 5.2 多余床位优先

- 最好多准备 2 张以上空床，这样即便有村民没及时躺下也不会卡住。
- 只要床足够，村民就不会因为“床已满”而停止繁殖。

### 5.3 给出交易奖励后再繁殖

- 在繁殖前先做一次简单交易，让村民心情稳定。
- 交易后村民“愿意度”会提升，繁殖成功率也更高。

## 6. 常见问题

### 问：为什么他们不繁殖？

- 检查床是否足够。
- 检查是否给足了食物。
- 检查是否有可见的工作站，让村民保持职业状态。
- 检查周围是否有敌对生物或村民首先逃跑。

### 问：为什么孩子变成傻子？

- 新生成的孩子在出世时默认是“无职业”状态。
- 给孩子留一个空工作站，或者等他长大后主动找工作站，就能获得职业。

### 问：可以连接多个繁殖房吗？

- 可以，但要注意床和村民之间的路径不要被阻断。
- 推荐先弄一个稳定的主繁殖房，再扩展到更多房间。

## 7. 版本 26 的额外提示

- 26 版本及其后续更新依然沿用“床+食物”机制。
- 只要你不是运行老版本（如 1.13 以前），就不需要门数，只需关注床位和愿意度。
- 如果你想持续扩展村民，建议把繁殖房放在主基地附近，减少搬运和防守开销。

## 8. 实用总结

- 关键：2 个村民 + 空床 + 足够食物。
- 最稳方式：1 名农民 + 1~2 张空床 + 1~2 张备用床。
- 备用方案：先让农民收集胡萝卜/土豆，再给村民喂食。

> 这个教程适合“想快速养活村民、为交易和铁傀儡农场准备村民资源”的生存玩家。成功后你就能快速扩展村民数量，为通关后期的附魔、药水、铁和铁傀儡农场打基础。
