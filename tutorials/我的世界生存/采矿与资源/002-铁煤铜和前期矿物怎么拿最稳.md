# 铁煤铜和前期矿物怎么拿最稳

前期真正决定节奏的，通常不是钻石，而是铁、煤和铜这些常用矿。它们决定你有没有桶、盾牌、工具链、照明和一堆功能方块。

## 1. 铁为什么永远缺

- 桶、盾牌、剪刀、铁砧、漏斗、铁轨全都吃铁。
- 你会以为自己铁够了，开始做自动化和交通后马上发现不够。
- 所以前期看到铁，基本都值得拿。

## 2. 煤为什么别嫌普通

- 火把和冶炼都离不开它。
- 你如果总是煤不够，整个下矿和基地节奏都会很烦。
- 早期顺手多拿煤，体感提升非常明显。

## 3. 铜什么时候开始有价值

- 做望远镜、避雷针、刷怪塔抗雷保护时有用。
- 进入建筑阶段后，铜的观感价值会快速上升。
- 它不是最急的矿，但也不是纯摆设。

## 4. 一个实用结论

前期别只盯着钻石。铁保功能，煤保日常，铜保后续拓展，这三类矿拿稳了，你的生存节奏会顺很多。
