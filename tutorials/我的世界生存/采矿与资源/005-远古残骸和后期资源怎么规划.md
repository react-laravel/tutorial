# 远古残骸和后期资源怎么规划

进入后期以后，资源问题不再只是“够不够用”，而是“哪些值得主动刷，哪些顺手拿就行”。远古残骸就是这种典型资源：不急，但一旦开始做后期装备和长期项目，它就会变得非常关键。

## 1. 远古残骸什么时候该认真挖

- 你已经有稳定钻石套和下界生存能力。
- 你准备长期玩，不只是单纯通关。
- 你知道下界挖矿的风险，且能承担抗火和补给成本。

## 2. 后期还常缺什么

- 石英。
- 黑石、玄武岩等下界建筑材料。
- 大量铁、红石、煤和建材类资源。

真正到后期后，你会发现“基础资源的大量稳定供给”反而比零散稀有矿更重要。

## 3. 资源规划怎么做更合理

- 稀有资源按目标挖，不要盲目囤。
- 常用资源尽量建立稳定获取线。
- 真正稀缺时，优先补会卡住整条玩法链的那种资源。

## 4. 一个实用结论

后期资源规划的重点不是把每种矿都堆到天上，而是搞清楚什么资源正在拖慢你。远古残骸、铁、红石、建材，谁卡你就先补谁。
