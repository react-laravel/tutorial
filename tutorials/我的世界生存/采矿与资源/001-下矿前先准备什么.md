# 下矿前先准备什么

下矿翻车，很多时候不是因为矿洞太难，而是因为人下去得太随便。你只要先把最基础的准备做齐，挖矿的容错会高很多，背包也不会刚下去五分钟就乱成一团。

## 1. 下矿前最低限度该带什么

- 足够的食物。
- 火把。
- 方块。
- 水桶。
- 至少一把主镐和一把备用镐。

## 2. 为什么这些东西比“多一把武器”更重要

- 火把决定你会不会回头时被怪堵。
- 方块决定你能不能封路、垫路、抢高点。
- 水桶决定你能不能处理岩浆、摔落和高低差。

## 3. 哪些错误最常见

- 镐耐久不够就下去，挖到关键矿反而带不回来。
- 背包没整理，几分钟就满。
- 不做照明和路标，出来比进去还难。

## 4. 一个实用结论

下矿前先把补给、照明和撤退工具带齐，效率通常比多带一件高级装备更重要。能安全回来，挖到的矿才算真的到手。
