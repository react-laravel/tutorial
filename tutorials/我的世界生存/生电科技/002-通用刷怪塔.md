# 通用刷怪塔

分类：基础资源生电

## 适用范围

- Java 26.1.2 可以稳定使用。
- 基岩版也能做高空刷怪塔，但刷怪上限、运输方式和效率表现会有差异。

## 主要收益

- 骨头、箭、火药、线、腐肉。
- 适合作为前中期的综合材料来源。

## 为什么这个版本还能用

- 26 系列的基础怪物生成逻辑仍然围绕黑暗、可生成方块和玩家距离展开。
- 只要把地面洞穴竞争位尽量排除，高空塔依旧是最稳的通用方案之一。

## 推荐做法

- 新手优先做高空或海上空的“通用综合塔”。
- 不追求极限效率，先追求稳定掉火药、骨头和箭。

## 材料思路

- 大量圆石或其他廉价方块。
- 活板门、半砖、水桶。
- 漏斗、箱子。
- 后期想升级的话，再补发射器、观察者和红石时钟。

## 位置怎么选

- 最省心的是海面上空或高空平台。
- 待机点和刷怪层要保持在怪物可生成的距离内，不要站得太近，也不要离得太远。
- 如果你把塔建在地面附近，记得补洞穴照明，不然效率会被地下刷怪严重吃掉。

## 新手实用结构

1. 先做一个收集层，底部放漏斗和箱子。
2. 中间留 2x2 或 3x3 的落井，把怪物集中下落。
3. 每层刷怪层做成 2 格高的黑暗空间，四边用水道或活板门把怪推向中央落井。
4. 多叠几层，但不要一上来叠太多，先做一层能运行再往上加。
5. 塔顶和外表面都要补好防刷怪照明。

## 26 版本下的细节建议

- 刷怪面尽量用常规实心方块或可靠的半砖布局，不要依赖老视频里的脚手架刷怪思路。
- 想要运行更顺，可以用地毯、按钮等方式限制蜘蛛生成，减少卡塔情况。
- 如果你只想刷火药，后续可以再单独做苦力怕塔，不必一开始就追极限分类。

## 击杀和收集

- 最简单的是摔落加收集箱。
- 更稳的是摔落后接岩浆刀、营火或其他稳定处死方式。
- 想顺带拿经验，就把掉落高度改成“剩一丝血”，自己补最后一下。

## 常见翻车点

- 人站得太近，怪根本不刷。
- 塔建得太低，地下洞穴抢掉大部分刷怪位。
- 蜘蛛太多，把中间通道卡死。
- 收集层没封好，被苦力怕炸箱子。

## 升级方向

- 后期可改成发射器定时冲水的水冲塔。
- 也可以拆分成苦力怕塔、蜘蛛刷线塔、骷髅塔等专项装置。

## 通关价值

非常高。骨头能做骨粉，火药能做烟花，箭和线也都能稳定缓解中期资源压力。
