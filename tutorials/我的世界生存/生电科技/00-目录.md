# 我的世界生电科技

这份目录按 26 系列版本整理，默认以 Java 版 26.1.2 为主，优先写不依赖复制 bug 的方案。基岩版能通用的我会在文中单独说明，涉及刷怪判定、红石时序、复制类机制时请先在创造档测试。

## 阅读顺序

- 先看版本说明，分清哪些是稳定机制，哪些只是视频里流传的技巧。
- 再做圆石、木头、基础刷怪塔这类前中期收益最高的装置。
- 真要碰复制类、TNT 类、凋灵类方案，再单独测试，不要直接搬进主存档。
