# 铁傀儡农场

分类：中期核心生电

## 先说结论

- 在 26 系列里，铁傀儡农场依然非常值得做。
- 但 Java 和基岩的机制差别很大，别直接照搬跨平台教程。

## 为什么它这么重要

- 铁会长期卡桶、漏斗、铁轨、铁砧、盾牌和大量红石工程。
- 靠挖矿拿铁够通关，但不够长期发展。

## Java 26.1.2 的常见思路

- 最稳的是 3 个村民加持续惊慌机制。
- 村民需要能满足召唤条件，且附近要有可生成铁傀儡的安全平台。
- 新手最常见的做法，是让 3 个村民看到被控制住的僵尸，然后把生成的铁傀儡用水推去熔岩刀处死。

## Java 版搭建重点

1. 先把 3 个村民安全运到位。
2. 给村民安排床位，并确保它们能满足基本行为条件。
3. 把僵尸隔着视线窗关好，既能吓到村民，又不能伤到他们。
4. 上方或侧边做专门的生成平台。
5. 用水流把铁傀儡推到熔岩刀、营火区或其他收集处死区。

## Java 版常见翻车点

- 村民一直不睡或状态异常，导致农场时好时坏。
- 附近有别的铁傀儡没清掉，卡住下一轮生成。
- 生成平台外还有别的可生成位置，铁傀儡刷到外面去了。
- 僵尸没命名、没坐船或没穿戴，结果白天烧死或直接消失。

## 基岩版别照搬 Java

- 基岩版更像“村庄型铁 farm”。
- 通常需要更多村民和床，而且村庄中心控制比 Java 麻烦很多。
- 如果你玩的是基岩 26.21，更建议做基岩专门方案，不要按 3 村民 1 僵尸的 Java 图纸硬搭。

## 适合什么时候做

- 你已经找到村庄或做出了村民繁殖体系。
- 你开始缺漏斗、桶、铁轨、工具和各种铁制功能块。

## 值得配套一起做的东西

- 村民繁殖区。
- 临时交易站。
- 漏斗和箱子收集线。
- 一小段脚手架或铁路，方便前期搬村民。

## 我建议的新手做法

- 第一台别追极限效率，先做“小而稳”的版本。
- 只要能稳定出铁，它已经比手挖铁矿舒服太多了。

## 通关价值

极高。它不是打龙必须，但它会直接决定你中后期做机器和扩基地时的舒适度。
