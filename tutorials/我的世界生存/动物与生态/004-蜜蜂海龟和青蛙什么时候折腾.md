# 蜜蜂、海龟和青蛙什么时候折腾

这些生物都很有特色，但它们大多不属于“先做先赚”的前期项目。更适合把它们当成基地进入中后期后的生态扩展。

## 1. 蜜蜂什么时候值

- 你已经有固定基地。
- 你想做蜂蜜、蜂蜡或相关装饰。
- 你愿意给它们留花圃和活动空间。

## 2. 海龟什么时候值

- 你住在海边。
- 你愿意处理较慢的培育过程。
- 你对特定材料或生态玩法有兴趣。

## 3. 青蛙什么时候值

- 你已经开始玩沼泽、蛙明灯等后期或装饰向内容。
- 你愿意花时间研究生态条件和搬运。

## 4. 一个实用结论

这些生物更适合“基地稳定后慢慢玩”，而不是“我现在缺资源所以必须马上做”。
