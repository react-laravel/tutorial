# 猫和狗各有什么用

猫和狗都不是那种“必须马上抓”的生物，但它们确实能给基地生活和探索带来不同价值。要不要养，取决于你看重实用还是陪伴。

## 1. 狗更偏实战陪伴

- 跟随感强。
- 在某些战斗场景里能帮忙。
- 对很多玩家来说，情绪价值很高。

## 2. 猫更偏基地生活

- 更适合待在家里。
- 能让基地更有生活感。
- 对部分骚扰型生物也有一定影响。

## 3. 为什么别一开始投入太多

- 前期养它们并不能直接解决生存核心问题。
- 搬运、命名、安置也要花时间。
- 更适合在基地稳定后作为补充。

## 4. 一个实用结论

狗更像外出伙伴，猫更像基地成员。它们不是前期主线，但很适合在你生活稳定后补进去。
