# 前哨站、神殿、府邸附近能不能定居

这类结构周边不是不能住，而是“住”本身就意味着你要接受额外风险和管理成本。它们更像高收益、高干扰的特殊据点，而不是最轻松的日常主基地。

## 1. 掠夺者前哨站附近

- 好处是掠夺者路线清晰，做相关玩法会方便。
- 问题是骚扰性太强，日常生活体验容易被打断。
- 更适合做专门功能据点，不太适合轻松生活。

## 2. 海底神殿附近

- 后期价值很高，尤其是你想开发海晶和守卫者路线时。
- 但前期改造门槛高，水下工程也更折磨。
- 更适合中后期建立海上基地或海洋工业区。

## 3. 林地府邸附近

- 地标感强，建筑氛围很好。
- 但通常位置偏远，周边资源整合成本高。
- 适合做风格基地，不适合无脑当第一家。

## 4. 一个实用结论

前哨站、神殿、府邸附近都更适合“专题据点”，不是最通用的长期主基地。除非你就是冲着相关玩法或建筑风格去住，不然一般还是把它们当副基地更合理。
