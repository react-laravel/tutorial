# 末地外岛与末地城周边怎么发展

真正适合长期利用的末地空间，往往不是主岛，而是外岛。这里有紫颂果、鞘翅路线、末地城探索和大片可改造空间，所以它更像一个后期开发区。

## 1. 外岛的优势

- 空间大，地形相对规整。
- 末地城探索会逐渐让你形成固定航线。
- 紫颂植物和后期资源路线都能在这里展开。

## 2. 末地城周边为什么值得整理

- 找到鞘翅后，你来外岛的频率会明显提高。
- 附近可以顺手做临时仓库、备用潜影盒点和返程门标记。
- 一个整理好的末地城周边据点，会让后续探索效率高很多。

## 3. 不足在哪里

- 前期来这里的门槛高。
- 跌落虚空的代价极大。
- 没有成熟移动方式前，扩建和跑图都比较累。

## 4. 一个实用结论

外岛更适合后期发展，不适合早期硬住。等你已经拿到鞘翅、潜影盒并开始大规模探索时，再把这里当长期开发区，价值会一下子体现出来。
