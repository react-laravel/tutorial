# 沼泽、红树林与蘑菇岛

这三类地形都很有个性，而且各自有完全不同的价值。沼泽偏机制和副资源，红树林偏特色材料和生态感，蘑菇岛则是非常少见的“安全型特例”。

## 1. 沼泽为什么常被记住

- 史莱姆机制和它关系很大。
- 女巫小屋、泥巴、青蛙等内容都和它有关。
- 夜里氛围重，但地形也会更拖慢移动。

## 2. 红树林的价值

- 红树林木材和泥巴体系很有特色。
- 青蛙、红树根、潮湿环境很适合生态风建筑。
- 但地形更绕，跑图和定居都没那么省心。

## 3. 蘑菇岛为什么特殊

- 常规敌对怪在这里基本不会自然刷在地表。
- 很适合做后期安全主基地。
- 缺点是少见，而且通常比较远。

## 4. 一个实用结论

沼泽适合拿机制和特色资源，红树林适合做氛围基地，蘑菇岛适合后期安全定居。它们都很有特点，但都不像平原那样是最通用的开局地形。
