# 海洋与海岸怎么玩

海洋和海岸最大的特点就是移动方式和资源结构不一样。住在海边的人，跑图、钓鱼、沉船、海底遗迹都会更顺；但如果你完全靠海开局，也会更容易遇到木头和早期照明节奏的问题。

## 1. 海岸为什么好用

- 有陆地也有水路，是很平衡的落脚点。
- 船的价值会很早体现出来。
- 沉船、海滩资源和近海探索都方便。

## 2. 海洋的优势

- 跑图很快。
- 水产、沉船、海底遗迹、海晶类路线都能更早接触。
- 适合做码头、水边基地和海上平台。

## 3. 海洋的问题

- 水下活动门槛高。
- 没准备好夜视、水肺之前，很多内容会很折磨。
- 大面积纯海面不适合早期开荒主基地。

## 4. 一个实用结论

海岸往往比纯海洋更适合长期住。你既能享受船和海边资源的便利，又不会把自己困在高门槛的水下路线里。
