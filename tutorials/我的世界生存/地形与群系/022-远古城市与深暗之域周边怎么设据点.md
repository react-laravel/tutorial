# 远古城市与深暗之域周边怎么设据点

远古城市和深暗之域周边不适合粗暴定居，但很适合做谨慎型据点。这里的重点不是生活，而是潜行、回收、存放和安全撤退。

## 1. 为什么需要据点

- 深暗之域探索节奏慢，背包容易满。
- 你不想每次出事都从很远的主基地重新跑回来。
- 一个安全箱点和睡点能明显提升容错。

## 2. 据点应该设在哪里

- 最好放在深暗之域上层或边缘安全区。
- 不要直接压在高风险声感区域核心。
- 入口最好单一、明确，方便撤退和回收路线固定。

## 3. 据点里最该放什么

- 潜行和探险备用装备。
- 羊毛、食物、夜视、箱子与应急建材。
- 明确的回撤通道和方向标识。

## 4. 一个实用结论

远古城市附近应该设的是“探险据点”，不是生活基地。你要的是低暴露、好撤离、好补给，而不是把功能区一股脑铺在危险区旁边。
