# 玄武岩三角洲值不值得久留

玄武岩三角洲是典型的“很有辨识度，但住起来真的难受”的地方。它并不是没有价值，只是这个价值通常不体现在舒适定居上，而是体现在材料、路线和挑战上。

## 1. 这里的价值是什么

- 玄武岩、黑石这类材料非常有用。
- 做黑灰风建筑时，这里像天然采石场。
- 如果你需要某些特定下界材料，这里值得专门来一趟。

## 2. 为什么不舒服

- 岩浆、落差、碎地形很多。
- 岩浆怪和恶魂带来的骚扰感很强。
- 跑图经常像在跨施工现场，走路体验很差。

## 3. 适合什么玩法

- 材料采集站。
- 下界穿越路上的短暂停靠点。
- 想做工业感或废土感基地的人。

## 4. 一个实用结论

玄武岩三角洲通常不值得当长期生活区，但很值得当材料区和交通线上的功能节点。你把它当资源地，会比把它当家更合理。
