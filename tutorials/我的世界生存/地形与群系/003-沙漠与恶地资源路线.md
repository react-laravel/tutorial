# 沙漠与恶地资源路线

沙漠和恶地都属于“看起来缺东西，但其实很有特色”的地形。它们不一定适合所有人长期住，却很适合拿一波关键资源。

## 1. 沙漠的优点

- 视野开阔，白天跑图很舒服。
- 沙子量大，玻璃、TNT、建筑都能受益。
- 沙漠神殿、沙漠村庄和骆驼路线都很有价值。

## 2. 沙漠的问题

- 木头少。
- 常规食物线不如平原和森林舒服。
- 夜里地表很空旷，怪会看得很清楚，但你也很容易被围。

## 3. 恶地的优点

- 金矿很丰富。
- 地表废弃矿洞很有特色，资源获取节奏快。
- 陶瓦、红沙和层次感地形很适合建筑。

## 4. 恶地的问题

- 木头和水通常都偏紧张。
- 地形起伏大，定居成本高。
- 更适合掠资源，不一定适合新手第一主基地。

## 5. 一个实用结论

沙漠适合快搜结构、拿沙子和开阔视野；恶地适合拿金和做特色建筑。它们都不是最稳的纯开荒住区，但都很值得早期去一趟。
