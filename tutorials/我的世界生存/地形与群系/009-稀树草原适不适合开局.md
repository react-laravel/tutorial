# 稀树草原适不适合开局

稀树草原经常被忽视，但它其实是一个相当能打的开局地形。它没有平原那么标准，也没有森林那么全能，不过在“视野、村庄、动物、跑图”这几件事上通常表现不错。

## 1. 稀树草原的优点

- 视野通常不错，怪接近时容易发现。
- 村庄和动物资源不算难找。
- 金合欢木风格很特别，早期建筑就能有辨识度。

## 2. 开局时会遇到的问题

- 水源不一定像平原那样顺手。
- 地形容易出现台阶和断崖，跑图不如纯平地流畅。
- 金合欢木好看，但如果你不喜欢橙色系，可能会更想去别地补木头。

## 3. 适不适合长期住

- 如果附近有村庄、河流或平坦平台，很适合定居。
- 如果周围全是裂开的高低台地，前期住着会有点烦。

## 4. 一个实用结论

稀树草原不是最稳的万能开局点，但绝对不是差地形。它更像“有一点地形感的平原替代品”，条件合适时完全可以直接住下。
