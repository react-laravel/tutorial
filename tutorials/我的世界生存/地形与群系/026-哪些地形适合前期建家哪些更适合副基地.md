# 哪些地形适合前期建家，哪些更适合副基地

很多新手选地的错误，不是选了差地形，而是把“适合拿资源的地方”当成了“适合长期生活的地方”。这两类地点常常不是一回事。

## 1. 最适合前期建家的地形

- 平原。
- 森林边平地。
- 海岸附近平地。
- 有村庄的开阔区域。

它们共同的特点是：视野不差、木头不难补、农田好铺、动物好找、夜里好管理。

## 2. 更适合做副基地的地形

- 丛林和竹林。
- 繁花森林与花海。
- 沼泽和红树林。
- 沙漠、恶地、海底神殿周边、堡垒遗迹周边。

这些地方往往资源或玩法很有特色，但舒适度、通用性和生活成本没那么友好。

## 3. 哪些地形适合中后期主基地

- 樱花林与草甸。
- 山地景观区。
- 海上平台和海底神殿周边。
- 蘑菇岛。

这类地方常常不是最强开局点，但一旦你已经有交通、仓储和稳定物资，住起来会非常有成就感。

## 4. 一个实用结论

前期建家先看好不好活，中后期定居再看好不好经营。很多地形不是不值得住，而是不适合你现在这个阶段住。
