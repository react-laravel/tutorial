# 地形和建筑风格怎么搭配

地形和建筑风格如果搭得对，基地会非常自然；搭得不对，就容易显得像硬塞进去。你不一定要完全按地形来建，但至少知道什么地形更适合什么方向，会省很多返工。

## 1. 开阔地形适合什么风格

- 平原适合村庄扩建、农庄、大院、风车和功能基地。
- 海岸适合码头、小镇、灯塔和水边仓库。
- 稀树草原适合暖色木屋、台地村落和坡地聚落。

## 2. 林地和花地适合什么风格

- 森林和针叶林适合猎人小屋、北地木屋、木石混搭基地。
- 樱花林和草甸适合庭院、庄园、神社感和观景基地。
- 花海和繁花森林适合花园、温室、浅色系景观建筑。

## 3. 特殊地形适合什么风格

- 恶地适合废土、矿业镇和西部风建筑。
- 沼泽适合高脚屋、栈道、巫术感和潮湿生态风。
- 山地适合山城、要塞、悬崖宅和分层平台基地。

## 4. 维度地形怎么搭配

- 下界适合工业感、祭坛感、黑红系和功能前哨站。
- 末地适合极简、科幻、空岛桥梁和中转枢纽风格。

## 5. 一个实用结论

先顺着地形做，比强行和地形对着干更省力。真正好看的基地，很多不是材料多高级，而是看起来像“本来就应该长在这里”。
