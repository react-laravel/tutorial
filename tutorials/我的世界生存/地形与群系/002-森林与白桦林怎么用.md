# 森林与白桦林怎么用

森林类地形最大的优势很直观：木头多。问题也同样明显：树多会挡视线、挡走位、挡照明，所以它很适合拿资源和建半封闭基地，但不一定是最舒服的夜间战斗地形。

## 1. 森林为什么好用

- 木头供应稳定。
- 前期原木、木板、木棍、箱子这些全都不容易断。
- 蜜蜂、花、蘑菇等生态补给也常见。

## 2. 白桦林有什么特点

- 地面通常更干净，树形更直，砍树效率不错。
- 视觉更亮，做浅色建筑也顺手。
- 比密林更容易导航。

## 3. 森林的麻烦点

- 夜里树荫下更难看清怪。
- 苦力怕和蜘蛛会更容易借掩体贴近你。
- 跑图时绕树很烦，不如平原直接。

## 4. 适合做什么

- 木材资源站。
- 山林小屋、猎人风基地。
- 半开放营地或工坊区。

## 5. 一个实用结论

森林和白桦林都很适合前期补木头，也适合定居，但最好先清一块空地再认真住。只要视野和照明处理好，森林其实很稳。
