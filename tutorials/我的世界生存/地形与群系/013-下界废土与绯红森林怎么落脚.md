# 下界废土与绯红森林怎么落脚

下界里最常见、也最容易让人考虑落脚的，通常就是下界废土和绯红森林。它们都不算真正安全，但如果你的目标是建立下界中转站、刷猪灵交易、跑要塞路线，它们往往是最先接触到的区域。

## 1. 下界废土的特点

- 地形相对直白，视野通常比别的下界群系更容易读。
- 猪灵、僵尸猪灵、恶魂都可能让你很烦，但整体资源路线比较通用。
- 适合做交通门厅、中继补给点和最早的下界临时站。

## 2. 绯红森林的价值

- 猪灵和疣猪兽多，食物和猪灵相关路线更容易展开。
- 绯红木材、菌柄、菌光体等资源都很有特色。
- 如果你已经会处理猪灵关系，这里能提供很强的下界生存资源。

## 3. 真正的问题在哪里

- 两边都不是“能放松站着不动”的地方。
- 恶魂视野线、猪灵仇恨和疣猪兽冲脸，都会打断你建家。
- 不做围墙、顶棚和安全门厅，定居体验会很差。

## 4. 一个实用结论

下界废土更适合做第一落脚点，绯红森林更适合做资源型据点。真要在下界认真住，重点从来不是好不好看，而是你有没有先把安全动线做出来。
