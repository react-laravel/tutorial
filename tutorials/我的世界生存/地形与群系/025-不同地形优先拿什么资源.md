# 不同地形优先拿什么资源

地形不只是“住起来舒不舒服”，还直接决定你最先能拿到什么资源。你要是知道每种地形最值得顺手拿什么，跑图效率会高很多，也不会把稀有地形只当成普通风景区。

## 1. 平原、森林和稀树草原先拿什么

- 平原先拿动物、农田条件和村庄机会。
- 森林先拿木头、蘑菇、蜜蜂和稳定建材。
- 稀树草原先看村庄、动物和便于跑图的开阔地。

这几类地形都偏开局资源，重点是让你尽快活稳，而不是追高端材料。

## 2. 沙漠、恶地、海洋先拿什么

- 沙漠优先拿沙子、神殿战利品和村庄机会。
- 恶地优先拿金矿、陶瓦和地表矿洞优势。
- 海洋优先拿沉船、海底遗迹、水产和海边交通优势。

这些地方通常很适合“专门跑一趟”。

## 3. 丛林、竹林、沼泽和花地先拿什么

- 丛林和竹林优先拿竹子、可可豆、西瓜。
- 沼泽优先拿泥巴、青蛙路线、史莱姆相关条件。
- 繁花森林和花海优先拿花、染料和养蜂条件。

这类地形资源很有特色，但不一定需要你长期住下。

## 4. 山地、洞穴、下界、末地先拿什么

- 山地早期更容易顺手摸到煤和铁。
- 洞穴群系重点看苔藓、发光浆果和深层探险路线。
- 下界重点拿烈焰棒、下界疣、珍珠条件、玄武岩和黑石等特殊材料。
- 末地重点拿鞘翅、潜影壳、紫颂植物和外岛开发空间。

## 5. 一个实用结论

跑图时别只问“这里值不值得住”，还要问“这里最该带走什么”。很多地形真正的价值，不在于定居，而在于你有没有把它最关键的资源带回主基地。
