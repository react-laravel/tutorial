# 多基地路线怎么分工

真正玩到中后期后，一般不会只有一个家。更高效的做法，通常是一个主基地配几个功能据点。这样你既能住得舒服，也不会每次缺资源都跨半张地图跑回去。

## 1. 主基地负责什么

- 仓储。
- 常用制作与附魔。
- 主农田、主居住区、主要展示区。
- 日常上线后的大部分活动。

主基地最好放在你最愿意长期待着、交通也不算差的地方。

## 2. 副基地负责什么

- 丛林或竹林资源站。
- 下界前哨站。
- 末地主岛中转站。
- 海底神殿或结构周边专题据点。

副基地不需要很漂亮，但要明确解决一个问题。

## 3. 为什么多基地比一个超级基地更合理

- 不用把所有地形优点硬塞进同一个点位。
- 跑图成本更低。
- 每个据点都能按自己的任务来设计，不容易越做越乱。

## 4. 一个实用结论

当你开始觉得“主基地什么都想要，但什么都离得远”时，就说明该走多基地路线了。一个住得舒服的主基地，加几个清晰分工的副基地，通常比一处包打天下更顺手。
