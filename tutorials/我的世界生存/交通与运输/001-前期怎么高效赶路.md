# 前期怎么高效赶路

前期的赶路核心不是“跑得最快”，而是“别白跑”。你装备差、补给少、背包小，很多时候最浪费时间的不是路本身，而是迷路、绕路和死在半路。

## 1. 前期赶路最该带什么

- 食物。
- 船。
- 方块和火把。
- 一张床或明确的过夜计划。

## 2. 什么路线最省事

- 河流和海岸线通常比纯山地更好走。
- 有开阔视野的平原、稀树草原很适合前期拉距离。
- 真遇到复杂山地，绕路常常比硬爬更快。

## 3. 哪些错误最浪费时间

- 不记路，回程全靠猜。
- 夜里还硬跑，结果一路打怪。
- 看见什么都想挖，导致整趟远行节奏全乱。

## 4. 一个实用结论

前期赶路最值的不是高级交通，而是先学会顺地形、记路线、少走回头路。只要这三件事做好，移动效率会比你想象中高很多。
