# 村民动物和物资怎么运输

运输最头疼的往往不是玩家自己怎么走，而是怎么把别的东西带过去。村民、动物和物资的运输逻辑完全不同，如果你全用一种办法硬搬，效率会很差。

## 1. 村民最怕什么

- 路线不连续。
- 高低差太乱。
- 半路卡住、脱轨或重新绑定别的点位。

所以村民运输更适合短段分步处理，不要一口气想从天南搬到海北。

## 2. 动物怎么搬更省事

- 近距离用拴绳、围路和食物引导。
- 水路、船和矿车在很多场景里都很好用。
- 真要大规模搬，先想好终点圈养区，不然搬到一半还是乱。

## 3. 物资运输怎么选

- 近距离手搬和潜影盒最直接。
- 固定线路可以用矿车、漏斗和箱车。
- 超远距离通常还是靠下界交通和分站仓储更省心。

## 4. 一个实用结论

运输的本质不是“把东西挪过去”，而是“用最少折腾把它稳定送到位”。村民、动物和物资最好分开设计，不要混着想。
