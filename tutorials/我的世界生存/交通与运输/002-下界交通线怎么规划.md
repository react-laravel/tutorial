# 下界交通线怎么规划

真正进入中期以后，下界交通线通常是性价比最高的远距移动方案。问题不在于它能不能用，而在于很多人一开始就乱开门、乱连线，后面越修越乱。

## 1. 为什么下界交通这么重要

- 主世界远距离会被显著压缩。
- 资源点、村庄、副基地之间的往返成本会明显下降。
- 一旦线路稳定，后面扩很多据点都会更轻松。

## 2. 一开始怎么规划更稳

- 先定几个最常去的点位。
- 门的位置尽量按坐标对好。
- 通道先求安全和清晰，再求好看。

## 3. 哪些错误最常见

- 门没校准，结果串门。
- 通道贴着熔岩海和悬崖修，走路压力过大。
- 不做标识，走久了自己都分不清哪条通哪。

## 4. 一个实用结论

下界交通线是越早规划越省事的系统。你先把主干线拉直、拉稳，后面加支线会轻松很多。
