# 7.3 HDRI 环境光

> HDRI 是"高动态范围图像"的环境贴图。用一张 HDRI 就能照亮整个场景——简单、自然、效果好。

---

## 一、HDRI 是什么

**HDRI（High Dynamic Range Image）**：一种记录了广范围亮度信息的全景图像。通常是 360° 的球面投影，覆盖一整个环境。

### 关键特点

- **高动态范围**：能记录从极暗到极亮的全部细节（普通 JPG 做不到）
- **全景**：360° × 180°，完整环境
- **包含光照信息**：不只是颜色，还有每个方向的光强度

### 用途

- **作为环境背景**
- **作为主要光源**（反射出 HDRI 的明暗变成光照）
- **提供反射贴图**（让金属和玻璃反射真实环境）

---

## 二、为什么用 HDRI

比起手动布灯：

| 优势 | 说明 |
|---|---|
| **快速** | 一张贴图搞定整个场景光照 |
| **自然** | 真实环境的光照远比手工布光复杂 |
| **反射真实** | 金属和玻璃的反射立刻生动 |
| **便宜** | 免费资源丰富 |

**局限**：
- 不可方向控制每一道光
- 不适合戏剧性强光影
- 适合"真实感"而非"戏剧性"

---

## 三、下载 HDRI

强烈推荐 **Poly Haven**（polyhaven.com）：

- 全部 CC0 免版权
- 数百个高质量 HDRI
- 分辨率从 1K 到 16K 可选
- 商用免费

**推荐分辨率**：
- 预览：2K 就够
- 最终出图：4K
- 近景反射：8K+

文件格式：**.hdr** 或 **.exr**。

---

## 四、加载 HDRI 到场景

### 方法 1：通过世界属性

1. 属性编辑器 → 世界属性（地球图标）
2. 表面 → 颜色 旁边的"小圆点" → 选"**环境纹理**"
3. 点"打开"加载 .hdr 文件
4. 3D 视图切到渲染预览
5. 场景立即亮起来

### 方法 2：通过着色器编辑器

1. 着色器编辑器顶部切换"着色器类型"为 **世界**
2. 看到默认的"背景"节点
3. `Shift + A` → 纹理 → 环境纹理
4. 打开文件
5. 连到 背景 的颜色输入
6. 背景连到 世界输出

---

## 五、调整 HDRI

### 强度

背景节点有一个 **强度（Strength）** 参数。

- 1.0 = 原始亮度
- 0.5 = 暗一半
- 2.0 = 亮一倍

根据 HDRI 本身的亮度不同，合适值可能从 0.1 到 5 都有。

### 旋转

想让阳光从不同方向来？

1. 节点编辑器 `Shift + A` → 输入 → 纹理坐标
2. `Shift + A` → 矢量 → 映射
3. 纹理坐标的 "生成的" → 映射的输入
4. 映射的矢量输出 → 环境纹理的 Vector
5. 调整**映射节点的 Z 旋转**来旋转 HDRI

这个流程 Node Wrangler 可以一键完成：选环境纹理，`Ctrl + T`。

---

## 六、HDRI 作为背景 vs 只作为光照

有时候你想**只用 HDRI 照明，但渲染时不显示它作为背景**（背景变纯色或透明）。

### 方法

1. 渲染属性 → 胶片 → 勾选"透明（Transparent）"
2. HDRI 仍然照亮场景，但渲染结果背景透明
3. 导出 PNG 时保留 Alpha 通道

另一种方法：

1. 节点里分两路：一路给 **相机光线** 用纯色，一路给 **其他光线** 用 HDRI
2. 用"**光线路径**"节点分辨

这是进阶技巧，新手先用方法 1。

---

## 七、HDRI + 附加灯光

HDRI 提供基础光照，但可能太"**平均**"——没有明显的主光方向。

**解决**：
- 用 HDRI 作为环境光和反射
- 再加一盏**主光**作为戏剧性照明
- 这种组合结合了真实感和戏剧性

---

## 八、MatCap 和工作室灯光

"**材质预览**"模式使用的是**内置工作室 HDRI**，不是你场景里的 HDRI。

想改工作室 HDRI：

1. 3D 视图右上角点"**叠加层**"旁的下拉
2. 材质预览 → 照明 → 环境
3. 选择内置预设

这只影响"材质预览"的显示，不影响真实渲染。

## 十、HDRI 与金属/玻璃

HDRI 最大的优势：**金属和玻璃的反射立刻真实**。

- 抛光金属：环境中的明暗、形状、颜色都反射出来
- 玻璃：透过玻璃看到的折射也是 HDRI

如果你要做真实感的金属或玻璃物体，HDRI 几乎是必需的。

---

## 十一、颜色管理

HDRI 的动态范围很大。Blender 的"**视图变换**"决定最终看到的样子：

- **标准（Standard）**：传统 sRGB 响应
- **AgX**：Blender 5.x 新默认，更自然
- **Filmic**：电影风格，保留高光细节
- **Raw**：不处理，直接显示

渲染属性 → 颜色管理 → 视图变换。

**推荐**：**AgX** 或 **Filmic**。"标准"会让高光很容易过曝。

---

## 十二、HDRI 的尺寸与性能

HDRI 的分辨率会影响：

- **加载时间**：越大越慢
- **内存占用**：4K ≈ 50MB，8K ≈ 200MB
- **反射细节**：越大越清晰

**新手建议**：用 2K 工作，导出前切到 4K 渲染。

## 动手练习 7.3

### 练习 A：加载 HDRI
1. 从 polyhaven.com 下载一张 2K HDRI
2. 世界属性 → 颜色 → 环境纹理 → 打开文件
3. 渲染预览模式
4. 场景立即被照亮

### 练习 B：旋转 HDRI
1. 世界节点编辑器
2. 选中环境纹理节点
3. `Ctrl + T`（Node Wrangler）自动加映射和坐标
4. 调整映射的 Z 旋转
5. 看光线方向变化

### 练习 C：HDRI + 主光
1. 加载 HDRI，强度调到 0.3（暗一点）
2. 加一个面光作为主光，指向物体
3. 主光 + HDRI 组合——环境有细节、主体有戏剧感

### 练习 D：视图变换
1. 有 HDRI 的场景
2. 渲染属性 → 颜色管理 → 视图变换
3. 切到 "标准" → "AgX" → "Filmic"
4. 对比三者的差异

### 练习 E：金属球测试
1. 加一个球，给它金属材质（金属度 1，粗糙度 0.05）
2. 加载一个室外 HDRI
3. 球上反射出整个 HDRI 的内容
4. 旋转球，反射也转
