# 7.4 相机与构图

> 相机决定了"观众看到什么"。再好的模型和灯光，没有合理的构图也会浪费。本节讲相机的使用和基础构图原则。

---

## 一、默认相机

新建的场景里已经有一个相机。你可以：

1. 按 `Num 0` 切换到**相机视角**——从相机的眼睛看世界
2. 再按 `Num 0` 退出相机视角

### 相机的位置

相机是一个普通物体，可以用 `G/R/S` 移动、旋转、缩放。在物体模式下选中它就能操作。

---

## 二、调整相机的位置

### 方法 1：直接 G/R/S

1. 选中相机
2. 移动到想要的位置
3. 旋转让它朝向物体
4. `Num 0` 看结果

这个方法很"盲"——不容易对准。

### 方法 2：相机到视图（最常用）

1. 选择一个自由视角（用中键转动）
2. 按 `Num 0` 进入相机视图
3. `N` 打开侧栏 → 视图标签 → 勾选 "**相机到视图**"
4. 现在视图导航（中键、平移、缩放）**同时移动相机**
5. 调到满意的角度后**取消勾选**，防止误动

这是最舒服的相机调整方式。

### 方法 3：吸附

先用中键找到满意角度，然后：
1. `Ctrl + Alt + Num 0` → **将相机对齐到视图**
2. 相机立即跳到当前视角位置

---

## 三、相机参数

选中相机，属性编辑器 → 相机图标（小相机）：

### 焦距（Focal Length）

以毫米为单位，对应真实相机的焦距。

| 焦距 | 视角 | 用途 |
|---|---|---|
| **14mm** | 超广角 | 空间宽阔、夸张透视 |
| **24mm** | 广角 | 风景、建筑 |
| **35mm** | 标准广角 | 环境人像 |
| **50mm** | **标准** | 最接近人眼 |
| **85mm** | 中长焦 | 人像特写 |
| **135mm** | 长焦 | 紧凑构图 |
| **200mm+** | 超长焦 | 远物放大 |

**新手默认 50mm**。复杂场景 35mm。特写用 85mm。

### 视角（FOV）

焦距的另一种表达（角度）。两者等价，改一个另一个自动变。

### 裁剪开始/结束

相机只渲染距离在 **开始** 和 **结束** 之间的几何体。

- 过近 → 近处物体不可见
- 过远 → 远处物体被裁掉

默认 0.1 和 100 米，够用。场景很大时把"结束"调大。

### 传感器尺寸

对应真实相机的底片大小。大多数情况保持默认（36mm 全画幅）。

---

## 四、景深 Depth of Field

**景深**：前景清晰，背景模糊（或反之）。是电影摄影里常用的艺术手法。

### 开启景深

1. 相机属性 → 景深 → 勾选
2. **焦点物体**：拖一个物体到这里，相机会对焦到它
3. 或者手动设 **距离**
4. **光圈 F/Stop**：值越小景深越浅（背景越糊）
   - F/1.4：极浅
   - F/2.8：浅
   - F/8：中等
   - F/16：深，几乎全清

### 景深生效

- **渲染预览**或**渲染**时生效
- 实体/材质预览模式看不到

---

## 五、构图：三分法

**三分法**：把画面用两条水平和两条垂直线等分为 9 格。

**主体放在交叉点**（不是正中央），构图更好看。

在 Blender 里可以显示三分法辅助线：

1. 相机属性 → 视口显示 → 构图参考线
2. 勾选 **三分法**
3. 在相机视图里就能看到

---

## 六、构图：黄金比例

黄金分割的辅助线。和三分法类似但比例是 1.618:1。

同样在构图参考线里找到。

---

## 七、构图：安全框

对于视频，边缘可能被裁掉。安全框帮你避开。

---

## 八、相机的标题栏和边框

按 `Num 0` 进入相机视图时，屏幕上会出现一个**黑色边框**——那就是相机实际看到的区域。

边框外是渲染不到的区域，但仍然可以在这里放灯光和辅助物体。

---

## 九、多个相机切换

你可以在场景里有多个相机：

### 切换激活相机

方法 1：
1. 选中一个相机
2. `Ctrl + Num 0` → 设为激活相机

方法 2：
1. 属性编辑器 → 场景属性 → 相机下拉选择

只有**激活相机**才会被 `Num 0` 和渲染使用。

---

## 十、相机约束：跟踪

想让相机自动跟着某个物体？

1. 选相机
2. 约束属性（链条图标）
3. 添加约束 → 跟踪到 → **阻尼跟踪**
4. 目标物体拖进去
5. 相机自动对准目标

物体移动，相机跟着转。

---

## 十一、相机动画（预告）

相机和其他物体一样可以加**关键帧**做动画：

1. 按 `I` 插入位置关键帧
2. 在时间线上移动到下一帧
3. 移动相机，再按 `I`
4. 播放即可

镜头运动是动画的重要组成。本教程不深入动画。

---

## 十二、构图检查清单

出图前检查：

- [ ] 主体是否在画面的合理位置（不一定居中）
- [ ] 有没有头顶留太多空间或脚被砍
- [ ] 前景/中景/背景是否分明
- [ ] 有没有"指鼻子"效果（物体过度透视变形）
- [ ] 是否避免了"被背景截断头"
- [ ] 是否有视线方向的呼吸空间

---

## 十三、摄影师常用焦距参考

### 电影感构图

- 24mm：广角建立环境
- 35mm：标准叙事
- 50mm：人物肩上
- 85mm：人物特写
- 135mm：紧凑特写

### 产品摄影

- 50mm - 85mm：标准产品图
- 100mm 微距：近距离细节

### 建筑摄影

- 16mm - 24mm：广角

---

## 十四、等比锁定

渲染属性 → 输出属性 → 分辨率，决定渲染输出的比例。

- 1920×1080：16:9（电视/YouTube）
- 1080×1920：9:16（手机竖屏）
- 1080×1080：1:1（Instagram）
- 1920×960：2:1（电影感）

改分辨率后，相机视图的边框会跟着变。

## 动手练习 7.4

### 练习 A：相机视图和相机到视图
1. 添加 Suzanne 到原点
2. `Num 0` 进入相机视图
3. 大概率拍不到 Suzanne
4. `N` → 视图 → 勾选"相机到视图"
5. 中键转动 + 滚轮缩放，把 Suzanne 居中
6. 取消勾选

### 练习 B：焦距对比
1. 选相机
2. 焦距 24 → 拍一下
3. 焦距 50 → 拍一下
4. 焦距 135 → 拍一下
5. 对比画面差异（透视、压缩感）

### 练习 C：三分法构图
1. 相机视图勾选三分法辅助线
2. 调整相机让 Suzanne 的眼睛在左上交点
3. 画面感觉更稳定

### 练习 D：景深
1. 加一排 3 个物体（球、立方体、圆柱）
2. 相机对准它们
3. 开启景深，焦点物体设为中间那个
4. 光圈 F/1.8
5. 渲染预览看前后物体虚化

### 练习 E：多相机
1. 加第二个相机 `Shift + A → 相机`
2. 放在不同位置
3. `Ctrl + Num 0` 把它设为激活
4. 在两个相机之间切换
