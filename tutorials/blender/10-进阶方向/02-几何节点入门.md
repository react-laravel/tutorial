# 10.2 几何节点入门

> 几何节点（Geometry Nodes）是 Blender 最强的**程序化建模**系统。用节点生成几何，可控、可变、可重用。它是未来的方向。

---

## 一、几何节点是什么

**几何节点（Geometry Nodes）**：用节点编辑器定义几何体。你不手动拉点，而是"**描述如何生成**"。

类比：
- 传统建模 = 照着菜谱手动做菜
- 几何节点 = 写一个自动做菜的程序

---

## 二、能做什么

- **散布物体**：在地面随机撒草、石头、树
- **程序化建筑**：参数化的窗户、栏杆、管道
- **动态效果**：随时间变化的结构
- **模拟**：粒子、烟雾、水（5.x 有模拟节点）
- **自定义工具**：做一个"桥梁生成器"

---

## 三、开始使用

### 添加几何节点修改器

1. 选一个物体（比如平面）
2. 修改器属性 → 添加修改器 → **几何节点**
3. 点 "新建" 创建一个节点树
4. 底部出现**几何节点编辑器**

### 默认节点

- **组输入**：输入的几何（当前物体的网格）
- **组输出**：输出的几何（修改后的）
- 默认直连，等于什么也没做

---

## 四、第一个例子：散布物体

让我们在一个平面上随机撒小立方体。

### 步骤

1. 平面，加几何节点修改器
2. 打开几何节点编辑器
3. `Shift + A` → 点 → **在面上分布点（Distribute Points on Faces）**
4. 连接：组输入 → 在面上分布点
5. 点变成点云

### 添加实例

6. `Shift + A` → 实例 → **在点上实例化（Instance on Points）**
7. 在面上分布点的"点"输出 → 在点上实例化的"点"输入
8. 实例化的"几何"输出 → 组输出

现在每个点上还是没东西，因为没指定实例。

### 指定实例物体

9. `Shift + A` → 输入 → **对象信息（Object Info）**
10. 选一个立方体作为实例源（先在场景里创建一个小立方体）
11. 对象信息的"几何"输出 → 在点上实例化的"实例"输入

平面上出现一堆小立方体。

---

## 五、核心节点概念

### 几何类型

- **网格（Mesh）**：普通网格
- **点云（Point Cloud）**：纯点
- **曲线（Curve）**：线
- **体积（Volume）**：3D 网格（烟、雾）
- **实例（Instance）**：引用的几何

### 节点分类

- **输入**：场景、物体、曲线、常量
- **几何操作**：拉伸、合并、变换
- **属性**：读取/写入属性（位置、法线、颜色）
- **实用**：数学、向量、随机
- **输出**：组输出

### 字段（Field）

几何节点 3.0+ 引入了"字段"概念：
- **字段** = 在每个点/面上计算的值
- 比如"位置"就是一个字段
- 字段通过菱形插槽传递

新手先不用深究，跟例子做就行。

---

## 六、例子：程序化楼梯

```
[输入曲线 Line] → [重采样曲线 10 个点] → [实例化：立方体]
```

每级楼梯是一个立方体。

### 详细步骤

1. 加一个立方体
2. 几何节点
3. `Shift + A` → 曲线 → 曲线直线
4. `Shift + A` → 曲线 → 重采样曲线（数量 10）
5. `Shift + A` → 实例 → 在点上实例化
6. 立方体作为实例源

改变曲线长度或重采样数量，楼梯自动跟着变。

---

## 七、例子：随机缩放

让分布的物体有随机大小。

### 步骤

1. 在前面"散布立方体"的基础上
2. `Shift + A` → 实用 → **随机值**
3. 随机值的输出 → 在点上实例化的"缩放"输入
4. 每个立方体大小随机

### 类型匹配

如果颜色不一样：随机值的"类型"要和目标输入匹配（这里要向量或数值）。

---

## 八、例子：曲线生成植物

1. `Shift + A` → 曲线 → 贝塞尔曲线
2. `Shift + A` → 曲线 → 曲线 → 基础 → 曲线圆
3. `Shift + A` → 曲线 → 操作 → **曲线到网格**
4. 曲线作为主线，圆作为横截面
5. 输出一条管道

改曲线形状 → 管道跟着变。

这是所有"自动画树"类节点的基础。

---

## 九、常用节点速查

### 几何基础
- **变换几何**：移动、旋转、缩放
- **合并几何**：多个几何合并
- **分离几何**：按条件分离

### 点
- **分布点**：在面上撒点
- **在点上实例化**：在点位置放物体

### 实例
- **实例化到几何**：实例转换为几何（可以继续编辑）

### 网格
- **立方体 / 网格线 / 网格圆**：生成基础形状
- **挤出网格**：几何节点里的挤出

### 属性
- **位置**：当前点的位置
- **法线**：当前点的法线
- **存储命名属性**：写入属性

### 实用
- **数学 / 矢量数学**：基础运算
- **随机值**：随机数
- **比较**：>, <, ==

---

## 十、几何节点 vs 修改器

- **一般修改器**（镜像、阵列）：固定功能
- **几何节点**：可以自定义任何功能

**关系**：几何节点是修改器的"终极形态"。几乎所有传统修改器都能用几何节点实现。

---

## 十一、使用资产浏览器

Blender 内置一些预设的几何节点"资产"：
- 文件 → 顶部"资产浏览器"
- 自带"散布""曲线""实用"节点组
- 拖到你的节点树里可以直接用

---

## 十二、Viewer 节点和预览

Blender 5.x 有 **Viewer 节点**：

1. `Ctrl + Shift + 点击` 任何节点
2. 相当于接了一个 Viewer
3. 3D 视口会显示那个节点的几何

方便调试中间结果。

---

## 十三、几何节点模拟（Simulation）

Blender 3.6+ 引入了模拟块：

- 模拟输入 + 模拟输出
- 可以做"每一帧基于上一帧"的效果
- 烟雾、布料、粒子等

高级用法，先掌握静态几何节点。

---

## 十四、学习路径

1. **跟着官方例子**做几个
2. **散布类**：掌握点、实例化
3. **曲线类**：曲线生成管道、路径
4. **模拟类**：动态效果
5. **高级**：写自己的"节点工具"

### 推荐资源

- **Blender 官方文档 - Geometry Nodes**
- **Erindale** YouTube 频道（顶级几何节点大师）
- **CGMatter** 的几何节点视频
- **Blender Studio** 的开源项目里有大量几何节点
