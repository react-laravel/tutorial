# 10.1 雕刻模式入门

> 前 9 章的建模是"**硬表面建模**"——用点线面搭建。雕刻模式完全不同，像捏泥巴一样塑形。本节让你入个门。

---

## 一、什么是雕刻

**雕刻（Sculpt）**：用"笔刷"直接在网格表面推、拉、捏、磨，像捏泥巴或雕塑。

### 适用

- **有机物体**：人脸、动物、生物
- **复杂表面**：布料褶皱、岩石、树皮
- **概念设计**：快速塑形探索

### 不适用

- 精确的硬表面（汽车、建筑、工具）
- 需要干净拓扑的资产

---

## 二、进入雕刻模式

1. 选一个物体（比如立方体或球）
2. 顶部模式下拉 → **雕刻模式**
3. 或快捷键 `Ctrl + Tab` → 雕刻

左侧出现一长排**笔刷工具**。

---

## 三、推荐起手：Dyntopo 或 Multires

雕刻需要**海量的面**。两个思路：

### 动态拓扑（Dyntopo）

- 随笔刷自动增加/减少面
- 边雕刻边细分
- 自由度高
- 最终拓扑凌乱

### 多分辨率（Multires）

- 添加多分辨率修改器
- 雕刻时可以切换细节级别
- 拓扑保持整洁
- 最终可以烘焙成法线图

### 新手推荐：Dyntopo + 球体

1. 加一个 UV 球
2. 进入雕刻模式
3. 顶部菜单 **雕刻 → 动态拓扑** 启用
4. 开始雕

---

## 四、核心笔刷

### Draw（绘制）

- 快捷键 `X`
- 推出或推入
- 最常用
- 按 `Ctrl` 反向（推入）

### Clay Strips（粘土条）

- 一层层堆积
- 像贴黏土
- 做大型体积

### Grab（抓取）

- 快捷键 `G`
- 拉动一整块区域
- 做大变形

### Smooth（平滑）

- 快捷键 `Shift + 笔刷`
- 任何时候按 Shift 变成平滑笔刷
- 最常用的辅助动作

### Crease（折痕）

- 压出锐利的线
- 做嘴角、眼窝

### Inflate（膨胀）

- 把区域推出或拉进
- 像吹气

### Pinch（捏合）

- 顶点向中心靠拢
- 锐化边缘

### Flatten（压平）

- 把区域压成平面
- 做平面过渡

### Mask（遮罩）

- 快捷键 `M`
- 绘制遮罩，保护区域不受笔刷影响
- `Ctrl + 笔刷` 擦除遮罩
- `Alt + M` 清除所有遮罩
- `Ctrl + I` 反转遮罩

---

## 五、笔刷参数

顶部有笔刷的参数：

- **半径（Radius）**：笔刷大小，`F` 快捷调整
- **强度（Strength）**：笔刷力度，`Shift + F` 调整
- **自动蒙版**：根据法线或其他条件限制作用范围
- **衰减**：笔刷边缘的过渡曲线

---

## 六、笔刷快捷键总表

| 操作 | 快捷键 |
|---|---|
| 绘制笔刷 | X |
| 抓取笔刷 | G |
| 平滑（临时） | Shift + 笔刷 |
| 反转（推入而非推出） | Ctrl + 笔刷 |
| 调整半径 | F |
| 调整强度 | Shift + F |
| 遮罩笔刷 | M |
| 清除遮罩 | Alt + M |
| 反转遮罩 | Ctrl + I |

## 七、对称

雕刻人脸时必须开对称。

1. 顶部工具栏 → **对称** 面板
2. 勾选 X 轴对称
3. 雕一边，另一边自动跟

---

## 八、雕刻人头基本流程

### 步骤 1：粗体

1. UV 球 → 雕刻模式 → Dyntopo
2. Grab 笔刷把球拉成椭圆（头型）
3. 定大体比例

### 步骤 2：五官区块

1. Clay Strips 粘土条，堆出鼻梁
2. 压出眼窝（Draw 反向）
3. 推出嘴巴区域

### 步骤 3：细节

1. 提高 Dyntopo 细节
2. Crease 刻出嘴角
3. 细刻眉骨和颧骨
4. 不断 Smooth 保持整体感

### 步骤 4：超细节

1. 皮肤纹理
2. 汗毛
3. 细小凸起

这一步通常用法线图或多分辨率。

---

## 九、基础网格技巧

### 从球体开始 vs 从立方体开始

- **球**：适合头部、生物
- **立方体**：适合角色全身、硬边物体

### Remesh

雕刻到中途网格变乱？

1. 顶部 → Remesh
2. Voxel 尺寸调到合适（0.02 左右）
3. 点 Remesh
4. 网格被重新生成为均匀的四边形或三角形

---

## 十、常用设置

### 启用对称笔刷可视化

打开后你能看到两边同时作用的痕迹。

### 动态拓扑的细节大小

- **恒定细节**：所有地方细节一致
- **相对细节**：相对笔刷大小

新手用恒定细节，8–15 之间。

---

## 十一、雕刻 vs 盒子建模

| 对比 | 雕刻 | 盒子建模 |
|---|---|---|
| 直觉性 | 高 | 中 |
| 有机感 | 高 | 低 |
| 精确度 | 低 | 高 |
| 拓扑质量 | 差（需要后续重拓扑） | 好 |
| 入门门槛 | 中 | 低 |

**组合使用**：雕刻出有机外形 → 重拓扑 → 导出低模 → 烘焙法线图。

---

## 十二、重拓扑（Retopology）

雕刻后面数太多，要做成游戏资产必须"重新画一套拓扑"：

### 方法

- **QuadriFlow**：自动，快，质量一般
- **手动**：收缩包裹 + 多边形建模
- **插件**：RetopoFlow 等

### 最终流程

```
雕刻高模
 → 重拓扑 → 低模
 → UV 展开
 → 烘焙法线图
 → 应用到低模
 → 低模看起来像高模
```

## 动手练习 10.1

### 练习 A：第一次雕刻
1. UV 球 + Dyntopo
2. Grab 拉成椭圆
3. 推出鼻子区
4. 压出眼窝
5. 平滑整体
6. 看出一个"头"的雏形

### 练习 B：石头
1. 立方体 → 雕刻模式
2. Remesh voxel 0.02
3. Clay Strips 随机敲打
4. Smooth 一些地方
5. 像一块天然石头

### 练习 C：遮罩保护
1. 任何雕刻模型
2. `M` 绘制遮罩保护一块区域
3. 用其他笔刷作用在其他地方
4. 被遮罩的地方不变
5. `Alt + M` 清除遮罩
