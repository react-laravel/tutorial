# 10.3 动画与骨骼基础

> 动画让模型动起来。Blender 的动画系统非常完整——从关键帧到物理到角色动画，全都有。本节讲基础概念。

---

## 一、动画的本质

**动画 = 随时间变化**。

- 在第 1 帧物体在 A 位置
- 在第 50 帧物体在 B 位置
- 中间帧自动插值
- 播放就"动"了

**关键帧（Keyframe）**是记录"某个属性在某一帧的值"。

---

## 二、时间线

底部的 **时间线（Timeline）** 是动画的主要工具：

- **当前帧**：竖线所在位置
- **帧数**：左右两边的数字
- **播放/暂停**：空格或播放按钮
- **首帧/末帧**：`Shift + ←` / `Shift + →`
- **关键帧可见**：时间线上的菱形标记

### 帧范围

- **起点 / 终点**：时间线左右的数字框
- 也可以在输出属性里设

---

## 三、插入关键帧

### 快捷键 `I`

1. 选物体
2. 到某一帧
3. `I` → 弹出菜单选属性
4. 常见：**位置**、**旋转**、**缩放**、**位置+旋转+缩放**（LocRotScale）

### 在属性上右键

1. 右键任何属性（比如 X 位置）
2. → **插入关键帧**
3. 或直接鼠标在属性上 → `I`

### 自动关键帧

1. 时间线底部"录制"按钮（红点）
2. 打开后，改变属性自动插关键帧
3. 不小心会记错东西，谨慎使用

---

## 四、最简单的动画

### 物体从 A 到 B

1. 选立方体
2. 第 1 帧：位置 (0, 0, 0)，`I` → 位置
3. 到第 50 帧
4. `G X 5`（移动）
5. `I` → 位置
6. 空格播放
7. 立方体从 0 平滑移到 5

---

## 五、图表编辑器（F-Curve）

**图表编辑器（Graph Editor）** 显示关键帧之间的曲线：

1. 顶部切换编辑器 → 图表编辑器
2. 看到每个属性的**F 曲线**
3. 可以调整：
   - **关键帧的位置**
   - **插值类型**（线性、贝塞尔、常值）
   - **曲线切线**

### 插值类型

- **贝塞尔（Bezier）**：默认，平滑加减速
- **线性（Linear）**：匀速
- **常值（Constant）**：瞬间跳变

---

## 六、摄影表（Dope Sheet）

**摄影表（Dope Sheet）** 显示所有关键帧：

- 以条形图显示
- 可以选中关键帧移动、复制、删除
- 快速编辑动画节奏

`Shift + 拖动` 关键帧 = 复制。

---

## 七、骨骼（Armature）

角色动画的核心是**骨骼**。

### 添加骨骼

1. `Shift + A` → 骨架
2. 默认一根骨头
3. `Tab` 进入编辑模式（骨骼专用编辑模式）
4. 选骨骼尾部 `E` 挤出 → 生成链条骨骼

### 命名

- 每根骨骼命名
- 左右对称的骨骼用 `.L` 和 `.R` 后缀（Blender 自动识别镜像）

---

## 八、蒙皮（Skinning）

蒙皮 = 把骨骼绑定到网格上。

### 简单流程

1. 选网格
2. Shift + 选骨骼
3. `Ctrl + P` → 骨架形变 → **带自动权重**
4. 网格成为骨骼的子物体
5. 每个顶点根据距离自动分配到最近的骨骼

### 姿态模式

1. 选骨骼
2. 模式下拉 → **姿态模式**
3. 选任意骨骼 `R` 旋转
4. 网格跟着变形

---

## 九、权重绘制（Weight Paint）

自动权重不完美，需要手动调：

1. 选网格
2. 模式 → 权重绘制
3. 笔刷涂抹
4. 红 = 全权重，蓝 = 无权重
5. 按 `Ctrl + 点击骨骼` 切换查看哪根骨骼的权重

---

## 十、角色动画基础流程

### 准备
1. 建模（第 4 章）
2. 雕刻细节（第 10.1 章）
3. 重拓扑 + UV + 材质

### 绑定
1. 添加骨架（按人体比例摆骨头）
2. 带自动权重蒙皮
3. 调权重

### 动画
1. 姿态模式
2. 第 1 帧：初始姿势，`I` → LocRotScale
3. 第 N 帧：变化姿势，再 `I`
4. 播放看动画

### 输出
- 渲染为 PNG 序列
- 合成视频

---

## 十一、物理模拟

Blender 的物理系统：

### 刚体（Rigid Body）

- 碰撞、重力、摩擦
- 多米诺骨牌、破坏效果

### 布料（Cloth）

- 旗帜、衣服
- 钉住某些顶点不动

### 软体（Soft Body）

- 果冻、橡胶
- 比布料少用

### 流体（Fluid）

- 液体和气体
- 5.x 有新的节点流体

### 粒子

- 尘土、火星、下雪

每个都是独立的大话题。

---

## 十二、简单物理例子：球落地

1. 加一个平面（`G Z -2`）
2. 物理 → 刚体 → **被动**（不动的地面）
3. 加一个球（高处）
4. 物理 → 刚体 → **活动**
5. 空格播放
6. 球落下撞地

---

## 十三、NLA 编辑器（非线性动画）

**NLA（Non-Linear Animation）** 允许把多段动画组合：

- 行走循环
- 跑步循环
- 跳跃动作
- 在 NLA 里排列组合

进阶话题，角色动画必学。

## 十六、动画的原则

1. **时机（Timing）**：动作持续时间决定感觉
2. **加减速（Ease In/Out）**：真实物体不是匀速
3. **预备动作（Anticipation）**：动作前先"反向拉伸"
4. **跟随（Follow Through）**：动作后的惯性
5. **弧线（Arcs）**：自然运动是弧线而不是直线
6. **夸张（Exaggeration）**：比现实稍微夸张看起来更"对"
7. **挤压拉伸（Squash & Stretch）**：卡通的灵魂

这 12 条叫"迪士尼动画十二原则"，每个动画师都要懂。

## 动手练习 10.3

### 练习 A：弹跳球
1. 一个球
2. 第 1 帧：位置 (0, 0, 5)，`I` 位置
3. 第 15 帧：位置 (0, 0, 0)，`I`
4. 第 30 帧：位置 (0, 0, 3)，`I`
5. 第 45 帧：位置 (0, 0, 0)，`I`
6. 播放 → 弹跳
7. 打开图表编辑器调曲线让它"加速下落"

### 练习 B：最简单的骨骼
1. 加一根骨骼
2. 挤出几节
3. 加一个圆柱（手臂模型）
4. `Ctrl + P` → 带自动权重
5. 姿态模式 → 旋转骨骼
6. 圆柱变形

### 练习 C：刚体物理
1. 平面（被动）
2. 堆几个立方体（活动）
3. 空格播放 → 立方体倒塌

### 练习 D：布料
1. 一个立方体（碰撞体）
2. 一个细分平面（布料）
3. 平面物理 → 布料
4. 平面铺在立方体上方
5. 播放 → 布料落下覆盖
