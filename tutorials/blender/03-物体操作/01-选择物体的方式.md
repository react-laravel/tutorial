# 3.1 选择物体的方式

> "选择"听起来微不足道，但它决定了你接下来的所有操作作用于谁。Blender 的选择功能极其丰富，掌握 10 种选择技巧能让你的效率翻倍。

---

## 一、基础选择：鼠标点击

### 单选：左键点击

- **左键** 点物体：选中它，取消之前的选择
- 被选中的物体轮廓变成**橙色**
- 屏幕底部状态栏会显示选中物体的信息

### 加选 / 减选：Shift + 左键

- `Shift + 左键` 点一个未选中的物体：加入选择
- `Shift + 左键` 点一个已选中的物体：从选择中移除

### 激活项（Active Object）

当你选中多个物体时，**最后点击的那一个**称为"**激活项**"，它的轮廓颜色**更亮的黄色**。

为什么要区分"激活项"和"选中项"？因为某些操作只作用于激活项：
- 修改器
- 父级设定（子物体跟随激活项）
- 材质分配
- 吸附目标

---

## 二、全选与取消

| 快捷键 | 作用 |
|---|---|
| `A` | 全选 |
| `Alt + A` | 取消全选 |
| `A A`（快速按两下） | 取消全选（另一种方式） |
| `Ctrl + I` | 反选（选中所有未选中的） |

---

## 三、框选：B 键

按 `B` 键进入**框选模式**：

1. 按 `B`
2. 鼠标变成十字
3. 左键拖动画出一个矩形
4. 矩形里的所有物体都被选中
5. 右键或 Esc 取消

**中键拖动**：减选（框内物体取消选择）

### 直接拖选（无需按 B）

在选择工具激活状态下，**直接在空白处按左键拖动**就能框选。很多新手不知道这个捷径。

---

## 四、刷选：C 键

按 `C` 键进入**圆形刷选**：

1. 鼠标变成一个圆圈
2. 滚动滚轮调整圆圈大小
3. **左键拖动**：像画笔一样刷过的物体被选中
4. **中键拖动**：减选
5. 右键或 Esc 退出

**适合场景**：需要选中一片区域内的大量物体时。

---

## 五、套索选择：Ctrl + 左键拖动

按住 `Ctrl` 并用左键拖动，画出一个自由的闭合区域，区域内物体被选中。

适合选择不规则排列的物体。

---

## 六、按类型选择

菜单 `选择` → **按类型选择所有**：

- **网格**
- **曲线**
- **灯光**
- **相机**
- **空物体**
- **力场**
- ...

**场景里所有同类物体瞬间全选**。比如要选中所有灯光调整亮度，用这个最快。

---

## 七、按特征选择

菜单 `选择` → **按特征选择**：

### 相关选项

- **层级（Linked）**：和当前激活项共享网格数据的物体
- **子级**：激活项的所有子物体
- **父级**
- **同一集合**
- **游戏属性**

---

## 八、模式选择

菜单 `选择` → **模式选择**：

- **反选（Invert）**：`Ctrl + I`
- **随机（Random）**：按百分比随机选
- **镜像（Mirror）**：选对称位置的物体

---

## 九、大纲视图中选择

大纲视图里的选择和 3D 视图是同步的：

- **左键** 大纲里的物体名：选中它
- **Shift + 左键**：加选范围
- **Ctrl + 左键**：加选/减选单个

**大纲选择的优势**：
- 可以选中被其他物体遮挡的目标
- 按名字搜索定位
- 不怕手抖点错

---

## 十、F3 搜索选择命令

按 `F3` 弹出命令搜索框，输入"**选**"或"**select**"可以查到所有选择相关命令，直接执行。**快捷键记不住时的救命键**。

---

## 十一、选择的颜色代码

理解屏幕上的颜色含义：

| 颜色 | 含义 |
|---|---|
| **深橙色** | 选中（但不是激活项） |
| **亮黄色 / 亮橙色** | 激活项（最后选中的） |
| **灰色/原色** | 未选中 |
| **红色** | 某些约束或关联问题 |

---

## 十二、选择历史

Blender 记录了你的选择历史。菜单 `选择` → **按顺序校验**可以依次回到过去的激活项。

进阶用法：选中三个物体 A → B → C 后，某些操作会按这个顺序处理它们（比如父级、吸附）。

---

## 十三、操作未命中空白

默认情况下，**点击 3D 视图空白处会取消选择**。这个行为有时很烦人——比如你想按快捷键但不小心点空白就取消了。

### 关闭"点击空白取消选择"

偏好设置 → 键位映射 → 搜索 "deselect all" → 编辑对应的键位绑定。

或者更简单：不小心点空了就按 `Ctrl + Z` 撤销。

---

## 十四、在编辑模式里的选择（预告）

编辑模式里选择的对象是**点、边、面**，快捷键大部分相同：
- `A` 全选
- `B` 框选
- `C` 刷选

但多了几个强大的技巧：
- `L` 选中连通块
- `Alt + 左键` 选边环 / 面环
- `Ctrl + 左键` 选最短路径

这些第 4 章会详讲。

---

## 动手练习 3.1

先清空场景，再添加一些物体用来练习：

1. `A` 全选 → `X` 删除 → 确认删除
2. `Shift + A` 添加 5 个立方体（每加完一个挪动游标再添加下一个）
3. `Shift + A` 添加 2 个球体
4. `Shift + A` 添加 1 个圆柱

然后练习：

### 练习 A：基础选择
1. `A` 全选
2. `Alt + A` 全部取消
3. 左键点一个立方体
4. `Shift + 左键` 再点两个立方体（加选）
5. 看屏幕，确认最后点的是**最亮的黄色**（激活项）

### 练习 B：框选与刷选
1. `Alt + A` 取消全部
2. `B` 开始框选
3. 拖动框住所有立方体
4. `A` `A` 快速按两下取消
5. `C` 刷选，滚轮调大圆圈，刷过所有球体

### 练习 C：按类型选择
1. `Alt + A` 取消全部
2. 菜单 `选择` → `所有按类型` → `网格`
3. 所有网格物体被选中（8 个）

### 练习 D：反选
1. 选中一个立方体
2. `Ctrl + I` 反选
3. 所有其他物体被选中，那个立方体反而没选

### 练习 E：F3 搜索
1. 按 `F3`
2. 输入"随机"
3. 选择 "选择随机"
4. 调整百分比，一半物体随机被选

### 练习 F：大纲选择
1. 在大纲视图里用 `Ctrl + 左键` 依次点选 3 个物体
2. 确认 3D 视图同步高亮
