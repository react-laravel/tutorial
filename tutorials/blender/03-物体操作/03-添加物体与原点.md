# 3.3 添加物体与原点控制

> 本节讲如何往场景里添加东西，以及每个物体都有的"**原点（Origin）**"概念。很多新手卡在"为什么我的物体旋转中心不对"——答案就是原点没设好。

---

## 一、添加菜单：Shift + A

`Shift + A` 是 Blender 最重要的快捷键之一。它弹出一个层次很深的菜单，分类列出所有可添加物体。

### 菜单结构

```
Shift + A
├─ 网格 (Mesh)
│  ├─ 平面 (Plane)
│  ├─ 立方体 (Cube)
│  ├─ 圆环 (Circle)
│  ├─ 经纬球 (UV Sphere)
│  ├─ 棱角球 (Ico Sphere)
│  ├─ 柱体 (Cylinder)
│  ├─ 锥体 (Cone)
│  ├─ 环体 (Torus)
│  ├─ 栅格 (Grid)
│  └─ 猴头 (Monkey / Suzanne)
├─ 曲线 (Curve)
│  ├─ 贝塞尔曲线
│  ├─ 圆
│  ├─ NURBS
│  └─ ...
├─ 曲面 (Surface)
├─ 融球 (Metaball)
├─ 文本 (Text)
├─ 体积 (Volume)
├─ 蜡笔 (Grease Pencil)
├─ 骨架 (Armature)
├─ 晶格 (Lattice)
├─ 空物体 (Empty)
│  └─ 箭头 / 轴 / 球 / 立方体...
├─ 图像 (Image)

```

**新手阶段用得到的**：网格、曲线、空物体、灯光、相机、文本。

## 二、9 种基础网格详解

### 1. 平面（Plane）
- 1 个面，4 个顶点
- 用途：地面、墙、桌面、作参考

### 2. 立方体（Cube）
- 6 个面，8 个顶点
- 用途：**90% 硬表面建模的起点**

### 3. 圆环（Circle）
- 默认 32 个顶点组成一个圆圈（只有边，没有面）
- 用途：作为 profile 用挤出/螺旋挤出成 3D 形状

### 4. 经纬球（UV Sphere）
- 用经度和纬度划分，像地球仪
- 默认 32 段 × 16 环
- 用途：规则球体，贴图友好

### 5. 棱角球（Ico Sphere）
- 由三角形拼成，每个面大小相似
- 默认 2 级细分 = 42 顶点
- 用途：要雕刻或均匀变形时更好

### 6. 柱体（Cylinder）
- 默认 32 边的圆柱
- 用途：管道、柱子、桌腿

### 7. 锥体（Cone）
- 默认 32 边的圆锥
- 用途：箭头、尖顶

### 8. 环体（Torus）
- 默认 48 大段 × 12 小段
- 用途：甜甜圈、戒指，配合 Blender 经典教程

### 9. 猴头 Suzanne
- Blender 的吉祥物，一个猴子头
- 用途：测试材质/光照/渲染时的标准模型

## 三、添加后的"调整面板"（F9）

添加任何物体后，3D 视图**左下角**会出现一个折叠面板。展开它可以改变物体的初始参数：

### 立方体的参数
- **尺寸**：默认 2 米
- **生成 UV**：是否自动创建 UV
- **对齐**：世界 / 视图 / 3D 游标

### UV 球的参数
- **分段数**：经度数
- **环数**：纬度数
- **半径**
- **生成 UV**

### 柱体的参数
- **顶点数**
- **半径**
- **深度**
- **封盖填充类型**：无 / N 边面 / 三角扇

**关键**：你只能**紧接着添加之后**改这些参数，一旦做了其他操作就无法改了（所以后悔就按 Ctrl+Z 再重加）。想事后改？进编辑模式手动修改。

按 `F9` 可以让这个面板显示在鼠标旁边，方便编辑。

---

## 四、物体生成在哪里

**新物体出现在 3D 游标的位置**。记住这个规则：
- 想从世界中心建模：`Shift + C`（游标归零）后再 `Shift + A`
- 想在某个位置建模：先 `Shift + 右键` 定位游标再 `Shift + A`

### 对齐选项

添加面板里的"对齐"下拉控制物体朝向：

| 选项 | 行为 |
|---|---|
| **世界（默认）** | 按世界坐标轴对齐 |
| **视图** | 按当前视角方向对齐（面朝你） |
| **3D 游标** | 对齐到游标的旋转 |

## 五、物体的原点（Origin）

每个物体都有一个"**原点**"——就是那个**橙色小圆点**。

### 原点是什么

原点是物体在世界里的"**代表点**"：

- 物体的位置 = 原点的坐标
- 变换（G/R/S）以原点为参考
- 父子级关系通过原点连接

### 原点 ≠ 网格的几何中心

你可以把原点放在物体的任何地方。默认添加物体时，原点在它的几何中心。但你可以：

- 把原点移到底部 → 方便对齐地面
- 把原点移到铰链位置 → 方便旋转门
- 把原点移到旋转轴 → 方便动画

---

## 六、控制原点位置

### 物体菜单 → 设置原点

菜单：`物体` → `设置原点`（快捷键需要自行绑定）

### 几种设置方式

| 选项 | 作用 |
|---|---|
| **几何到原点** | 移动网格，让几何中心回到当前原点位置（物体不动原点，网格挪过去） |
| **原点到几何体** | 移动原点到网格的几何中心（原点挪过去，网格不动） |
| **原点到 3D 游标** | 原点移到游标位置（网格不动） |
| **原点到质心（表面）** | 原点移到面积加权的中心 |
| **原点到质心（体积）** | 原点移到体积加权的中心 |

### 典型用例：把原点放到物体底部

1. 选中物体
2. 进入编辑模式（Tab）
3. 选中**底面**的所有顶点
4. `Shift + S` → **游标 → 选中项**（游标跳到底面中心）
5. 退出编辑模式（Tab）
6. 菜单 `物体` → `设置原点` → **原点到 3D 游标**
7. 完成！原点现在在底面中心，物体可以精确对齐地面了

---

## 七、变换方向如何影响原点

### 应用变换的效果

当你 `Ctrl + A` 应用变换时：
- **应用位置**：原点位置被设为 `(0,0,0)`，网格不动
- **应用旋转**：原点旋转清零，网格不动
- **应用缩放**：缩放清零，网格尺寸变化

所以**应用变换 ≠ 原点重置**。应用是把当前状态设为"新的零点"，原点的位置并不改变。

---

## 八、复制原点到其他物体

通过一个曲折的办法：

1. 选中源物体，`Shift + S` → 游标到选中项
2. 选中目标物体，`物体 → 设置原点 → 原点到 3D 游标`

---

## 九、查看/隐藏原点

有时候原点的橙色小点太显眼。可以在**物体属性**（🟧 橙色方块图标）→ **视口显示** 中关闭"**原点**"显示。

## 十、添加文本与空物体

### 文本（Text）
- `Shift + A` → 文本
- 进入编辑模式可以修改文字内容
- 可以改字体（物体数据属性 → 字体）
- 可以转换为网格：`物体 → 转换 → 网格`

### 空物体（Empty）
- `Shift + A` → 空物体 → 各种形状
- 无实体、不渲染，只是一个锚点
- 用途：做父级、约束目标、参考点
- 对**修改器里的镜像、阵列**很有用（作为对象参考）

### 图像参考（Image as Reference）
- `Shift + A` → 图像 → 参考
- 导入一张图片作为建模参考
- 本身不渲染，只在视图显示

## 动手练习 3.3

### 练习 A：添加与参数调整
1. 删除默认立方体
2. `Shift + A` → 网格 → 柱体
3. 展开左下角面板，改"顶点数"为 `12`（12 边柱）
4. 再加一个柱体，顶点数保持默认 32，比较两者差异
5. 再加一个 UV 球，改分段数为 `16`，环数为 `8`
6. 观察都变低模了

### 练习 B：原点控制
1. 删所有，`Shift + C` 游标归零
2. 加一个立方体
3. `G Z 1` 向上移 1 米（立方体浮空，因为原点在几何中心）
4. 进入编辑模式，面模式，选底面
5. `Shift + S` → 游标到选中项
6. 退出编辑模式
7. `物体 → 设置原点 → 原点到 3D 游标`
8. 现在原点在底面。再次 `G Z` 移动，你会发现原点可以精确对齐到平面

### 练习 C：文本
1. `Shift + A` → 文本
2. `Tab` 进入编辑模式
3. 删掉默认的 "Text"，输入 "Blender"
4. `Tab` 退出
5. `R X 90` 让它立起来

### 练习 D：空物体
1. `Shift + A` → 空物体 → 纯轴
2. 它没有实体，但可以 G/R/S 变换
3. 在大纲视图里把这个空物体拖进某个集合作为锚点
