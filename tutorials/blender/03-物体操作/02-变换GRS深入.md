# 3.2 变换 G/R/S 深入

> G、R、S 是 Blender 里使用频率最高的三个快捷键。本节把它们的所有变体、修饰键、组合用法全部讲透。

---

## 一、三个核心键

| 键 | 英文 | 含义 |
|---|---|---|
| `G` | **G**rab | 移动（抓取） |
| `R` | **R**otate | 旋转 |
| `S` | **S**cale | 缩放 |

操作流程是统一的：

1. 选中物体
2. 按 G/R/S
3. 鼠标移动调整
4. **左键确认** 或 **右键/Esc 取消**

---

## 二、轴向约束

按完 G/R/S 之后**立即按 X / Y / Z**，可以把变换限制在单一轴上：

| 组合 | 作用 |
|---|---|
| `G X` | 只沿 X 轴移动 |
| `G Y` | 只沿 Y 轴移动 |
| `G Z` | 只沿 Z 轴移动 |
| `R X` | 只绕 X 轴旋转 |
| `S Y` | 只沿 Y 轴缩放 |

### 排除某个轴：Shift + 轴

`G Shift+Z` 的意思是"**除了 Z 轴以外的平面**"——即 XY 平面。

| 组合 | 作用 |
|---|---|
| `G Shift+Z` | 在 XY 平面上移动（Z 不变） |
| `G Shift+X` | 在 YZ 平面上移动 |
| `S Shift+Y` | 在 XZ 平面上缩放 |

---

## 三、局部坐标轴：连按两次

普通的 `G X` 约束到**全局 X 轴**。按两次 `G X X` 会约束到**物体的局部 X 轴**。

这在物体已经旋转过后特别有用。比如一把旋转了 30° 的尺子，你想沿它自己的长边移动：`G X X`。

---

## 四、精确数值输入

变换时可以直接敲数字：

| 按键序列 | 作用 |
|---|---|
| `G Z 2 Enter` | 沿 Z 轴上移 2 米 |
| `G X -1.5 Enter` | 沿 X 轴左移 1.5 米 |
| `R Y 90 Enter` | 绕 Y 轴旋转 90° |
| `R Z -45 Enter` | 绕 Z 轴旋转 -45° |
| `S 2 Enter` | 整体放大 2 倍 |
| `S X 0.5 Enter` | X 方向压扁一半 |

### 支持数学表达式

在数值输入栏可以写公式：

- `G Z 1/3` → 移动 0.333
- `R Z 360/8` → 旋转 45°
- `S 2*0.707` → 缩放到 1.414

---

## 五、慢速与精确修饰键

在变换**过程中**按住以下键：

| 修饰键 | 作用 |
|---|---|
| **Shift** | **慢速模式**：鼠标移动幅度变小，精细调整 |
| **Ctrl** | **吸附模式**：按整数/固定步长移动 |
| **Shift + Ctrl** | 更精细的吸附 |

**最常用的是 Ctrl**：
- `G Ctrl` → 以 1 单位为步长移动
- `R Ctrl` → 以 5° 为步长旋转
- `S Ctrl` → 以 0.1 为步长缩放

在做网格对齐时，Ctrl 几乎是必按的。

---

## 六、移动详解（G）

### 沿距离移动
- `G` → 鼠标自由拖
- `G X 5` → 沿 X 移动 5 米

### 沿法线方向移动（仅在某些工具下）
- 编辑模式里 `G G` 是**边滑移**或**顶点滑移**，完全不同的功能，后面讲

### 随机移动（菜单）
- 菜单 `物体` → `变换` → `随机化变换`

---

## 七、旋转详解（R）

### 默认旋转
- `R` → 绕当前视角方向旋转（屏幕坐标系）
- `R X` → 绕全局 X 轴
- `R X X` → 绕局部 X 轴

### 追踪旋转（Trackball）
按两次 `R R` 进入**追踪球模式**，可以像推球一样自由旋转物体。

### 按度数旋转
- `R Z 90` → 绕 Z 旋转 90°
- `R Z -90` → 反方向

---

## 八、缩放详解（S）

### 默认缩放
- `S` → 各方向等比缩放
- `S 2` → 放大到 2 倍
- `S 0.5` → 缩小到一半
- `S -1` → **镜像**（翻转）

### 单轴缩放
- `S X 2` → 只在 X 方向拉伸
- `S Z 0` → Z 方向压扁到 0（变成一个平面，有点粗暴但有用）

### 沿 2 个轴缩放
- `S Shift + Z` → XY 平面缩放，Z 不变
- 典型用法：把一个方块往外"摊"开

---

## 九、轴心点对变换的影响

还记得 2.3 节讲的**轴心点（Pivot Point）**吗？它决定旋转和缩放**绕什么旋转、以什么为基准缩放**。

### 六种轴心点

位置在 3D 视图头部栏中间的下拉框：

| 模式 | 行为 |
|---|---|
| **边界框中心** | 选中所有物体的外包盒中心 |
| **中位点** | 默认，所有原点的平均位置 |
| **各自原点** | 每个物体绕自己转 |
| **3D 游标** | 绕游标转 |
| **活动元素** | 绕激活项转 |

### 实战例子

选 5 个立方体一起按 `R` 旋转：

- **中位点**：它们会像一组绕共同中心转
- **各自原点**：每个立方体原地自转
- **3D 游标**：它们绕着游标画圈

---

## 十、清空变换

| 快捷键 | 作用 |
|---|---|
| `Alt + G` | 清空位置（回到原点） |
| `Alt + R` | 清空旋转 |
| `Alt + S` | 清空缩放（回到 1） |

**注意**：清空不是删除，只是把数值归零。

---

## 十一、应用变换

有时候你想**把当前变换"烧进"物体**，让它成为新的"起点"。例如：

- 一个立方体被缩放成 `(2, 2, 2)`，你想让它变成 `(1, 1, 1)` 但外观不变
- 旋转过的物体想把当前姿态设为"无旋转"

### 应用变换快捷键

- `Ctrl + A` → 弹出应用菜单
  - **位置**：把当前位置设为 `(0,0,0)`（物体不动）
  - **旋转**：把当前旋转角度设为 0
  - **缩放**：把缩放设为 1
  - **全部变换**：一次应用三个

### 什么时候要应用缩放

**几乎所有修改器都要求缩放应用为 1**，否则会出现倒角宽度不一致、镜像错位等奇怪问题。养成习惯：加修改器前先 `Ctrl + A` → 缩放。

---

## 十二、重复上一次操作

- `Shift + R` → 重复上一次操作

在连续做相同旋转时很省事。比如每按一次 `Shift + R` 就再旋转 45°。

---

## 十三、"上次操作"面板

3D 视图左下角有一个小折叠面板"**上次操作**"（或 F9 调出）。它显示你最近一次操作的参数，可以**事后调整**！

例如：你 `G Z 2` 移动了 2 米，但觉得 2.5 更合适。展开左下角的面板，修改 Z 值为 2.5，物体实时更新。

**F9**：重新展开最近一次操作的面板。

---

## 十四、变换时的视图反馈

在变换过程中，屏幕上会显示：

- **顶部**：精确数值（如 `D 2.34`）
- **中央**：虚线连接到轴心
- **底部状态栏**：提示可用的修饰键

如果看不到数值显示，检查偏好设置 → 界面 → 显示 → 运行模式中是否启用了数值叠加层。

## 动手练习 3.2

### 练习 1：精准移动
1. 默认立方体
2. `G Z 3 Enter` → 沿 Z 向上 3 米
3. `G X 2 Enter` → 沿 X 向右 2 米
4. 侧栏 N 确认位置是 `(2, 0, 3)`

### 练习 2：旋转组合
1. `Alt + G` 清空位置
2. `R X 45 Enter`
3. `R Z 30 Enter`
4. 看看侧栏里旋转值

### 练习 3：Ctrl 吸附
1. `Alt + R` 清空旋转
2. 按 `R Z` 开始旋转
3. 按住 `Ctrl` 拖动，你会看到旋转值按 5° 跳变
4. 放到 90° 左键确认

### 练习 4：缩放镜像
1. 选中立方体
2. `S X -1 Enter`
3. 物体被 X 方向翻转
4. **注意**：这里会有一个"反转"警告，因为缩放为负数可能让法线方向翻转

### 练习 5：F9 调整
1. `G Z 1 Enter`
2. 按 `F9`
3. 修改 Z 值为 `2.5`
4. 物体实时移动

### 练习 6：应用变换
1. `S 2 Enter` → 放大 2 倍
2. 看侧栏 N → 缩放是 `(2, 2, 2)`
3. `Ctrl + A` → 缩放
4. 再看侧栏 → 缩放变为 `(1, 1, 1)`，但物体尺寸没变
