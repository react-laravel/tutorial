# 3.4 复制、关联与父子关系

> 复制是加速建模的关键。Blender 提供了多种复制方式，每种适用不同场景。父子关系则让多个物体可以作为整体运动。

---

## 一、三种复制方式

| 快捷键 | 名称 | 说明 |
|---|---|---|
| `Shift + D` | **普通复制（Duplicate）** | 独立的新物体 |
| `Alt + D` | **关联复制（Linked Duplicate）** | 共享网格数据 |
| `Ctrl + C / Ctrl + V` | **剪贴板复制** | 跨文件复制 |

### 1. 普通复制：Shift + D

按 `Shift + D` 后：
- 立刻创建一个完全独立的副本
- 副本进入 `G`（移动）模式，直接拖动到位置
- 左键确认或 `Esc` 留在原地

**特点**：副本和原物体没有任何关联。改一个不会影响另一个。

### 2. 关联复制：Alt + D

按 `Alt + D`：
- 创建一个新物体
- **但这个新物体和原物体共享同一份网格数据**
- 在编辑模式里改任何一个，另一个同步变化
- 物体变换（位置、旋转、缩放）仍然独立

**典型用例**：
- 对称物体的两半
- 场景中的相同道具（所有窗户、所有栏杆）
- 想批量修改的物体

**好处**：省内存，修改一处多处同步。

**坏处**：有时候你以为在改 A，结果 B 也被改了，容易意外。

### 3. 剪贴板：Ctrl + C / Ctrl + V

- `Ctrl + C` 复制
- `Ctrl + V` 粘贴

**特点**：
- 剪贴板独立于场景，可以跨 .blend 文件使用
- 复制的是**完整的物体**
- 注意：这会**替换系统剪贴板内容**（不过 Blender 用的是自己的剪贴板文件，不影响系统）

---

## 二、让关联复制的变成独立的

如果你发现不小心用 Alt+D 关联了两个物体，但后来想让它们独立：

1. 选中要独立的那个
2. 菜单 `物体` → `关系` → **令单一化**
3. 选 "**物体与数据**"
4. 现在它有独立的网格了，改不影响原版

**快捷键**：`U`（在 3D 视图中）

---

## 三、阵列复制（用修改器）

如果你想**按规律复制一排**（比如一排栏杆、楼梯），比起手动复制 100 次，用**阵列修改器**更好。详见第 5 章。

---

## 四、父子关系（Parent）

父子关系让**子物体跟随父物体移动**。父动子也动，但子动不影响父。

### 生活类比

想象把一个苹果放在盘子上：
- 盘子 = 父
- 苹果 = 子
- 你移动盘子，苹果跟着走
- 你只拿起苹果，盘子不动

### 设置父子关系

1. 先选 **子物体**
2. 再 `Shift + 点击` 选 **父物体**（此时父物体是激活项）
3. 按 `Ctrl + P`
4. 在弹出菜单中选择父级类型：
   - **物体（Object）**：最常用，简单跟随
   - **物体（保持变换）**：设为父时保持当前世界位置
   - **骨架变形**：绑定骨骼用
   - **顶点 / 顶点（三角形）**：跟随特定顶点
   - **骨骼 / 骨骼相对**：绑到某根骨头

**新手阶段只用"物体"**。

### 解除父子关系

- 选中子物体，`Alt + P`
- 菜单选项：
  - **清除父级**：完全解除，子物体可能跳回原位置
  - **清除并保持变换**：保持当前世界位置解除
  - **清除父级反向**：清除父级矩阵

---

## 五、父子关系在大纲视图中的样子

父子关系会让大纲视图出现**层级缩进**：

```
Cube (父)
└─ Sphere (子)
   └─ Cone (子的子)
```

可以**无限嵌套**父子。

---

## 六、父子 vs 集合 vs 链接

这三个概念容易混：

| 概念 | 作用 | 区别 |
|---|---|---|
| **父子关系** | 变换跟随 | 只影响位置/旋转/缩放的继承 |
| **集合（Collection）** | 组织分类 | 只是"分组显示"，不影响变换 |
| **关联复制** | 数据共享 | 共享网格/材质，但变换独立 |

可以同时存在：一个物体可以既有父级，又属于某集合，又是关联复制的其中之一。

---

## 七、按 Esc 保留原地副本

`Shift + D` 或 `Alt + D` 后按 Esc：
- 副本被创建
- 但**留在原位置**（和原物体完全重合）
- 你需要手动挪开

有时候这不是你想要的——看起来像没复制一样。但如果你马上想做别的事（比如直接进编辑模式改副本），这是合理的。

---

## 八、实战：用 Alt+D 做对称建模

1. 建一个半边角色身体
2. `Alt + D` 复制，按 `Esc` 留在原位
3. `S X -1 Enter` → X 方向镜像
4. 现在你有两半，共享同一份网格
5. 编辑模式里改一半，另一半自动镜像更新

*（更常见做法是用"镜像修改器"，见第 5.2 节）*

---

## 九、批量设置父级

选中多个子物体，最后加选父物体，`Ctrl + P` → 物体。所有选中的（除激活项之外）都会变成激活项的子级。

---

## 十、父级的"初始偏移"

当你设置父级时，Blender 会自动计算子物体相对父物体的**偏移矩阵**，保证设父级前后子物体**看起来在原地没动**。

这个偏移是一次性的，之后子物体跟随父物体相对移动。

如果你不想要这个自动偏移：选 `Ctrl + P` → **物体（无反向）**。

---

## 十一、吸附到活动项

配合吸附，你可以让一个物体精确对齐到另一个物体的原点：

1. 打开吸附（`Shift + Tab`）
2. 吸附目标设为"**活动项**"
3. 先选中要移动的物体
4. `Shift + 点击` 目标物体（变为激活项）
5. 按 `Shift + S` → "选中项到活动项"

---

## 十二、链接（Link）跨文件资源

除了关联复制，Blender 还支持**跨文件链接**：

- `文件` → `关联`：从另一个 .blend 文件引入物体
- 引入的物体**锁定**，不能直接编辑
- 原文件改了，你这里会同步更新

适合团队协作和资产管理，新手阶段不用学。

---

## 动手练习 3.4

### 练习 A：三种复制对比
1. 添加一个立方体
2. `Shift + D`，往 X 正方向移动 3 米
3. `Alt + D`，往 Y 正方向移动 3 米
4. 现在场景有 3 个立方体
5. 选中第一个（原版），`Tab` 进入编辑模式
6. 按 `G Z 2` 移动几个顶点
7. `Tab` 退出
8. **观察**：只有第一个和第三个（关联复制的）变了；第二个独立没变

### 练习 B：令单一化
1. 接上面的场景
2. 选中第三个（关联复制的）
3. 按 `U` → "物体与数据"
4. 再进入编辑模式改一个顶点
5. 这次只有第三个变了

### 练习 C：父子关系
1. 添加两个物体：A 立方体和 B 球
2. 选中 B
3. `Shift + 点击` A（A 激活）
4. `Ctrl + P` → 物体
5. 现在移动 A，B 跟着走
6. 只移动 B，A 不动

### 练习 D：层级
1. 接上面
2. 再加一个锥体 C
3. 选中 C，`Shift + 点击` B
4. `Ctrl + P` → 物体
5. 现在 A → B → C 是三级父子
6. 移动 A，B 和 C 都跟着
7. 移动 B，只有 C 跟着

### 练习 E：解除父子
1. 选中 B
2. `Alt + P` → 清除父级
3. 现在 A 和 B 独立，但 C 还是 B 的子级
