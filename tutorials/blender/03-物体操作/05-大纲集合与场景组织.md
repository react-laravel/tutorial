# 3.5 大纲、集合与场景组织

> 场景里物体多起来之后，管理就成了真问题。本节讲如何用大纲视图和集合（Collection）把场景整理得井井有条。

---

## 一、大纲视图再认识

右上角的**大纲视图（Outliner）**是场景的"文件资源管理器"。每个物体都会出现在这里，按层级排列。

### 大纲视图的显示模式

左上角有一个下拉选择：

| 模式 | 作用 |
|---|---|
| **视图层（View Layer）** | 默认，显示当前视图层的所有东西 |
| **场景（Scene）** | 所有场景对象 |
| **Blender 文件** | 文件内所有数据块 |
| **孤儿数据** | 没有用户的悬空数据 |
| **数据 API** | 底层 Python 数据 |

**新手阶段保持默认的"视图层"即可**。

---

## 二、集合（Collection）是什么

集合是**物体的分组容器**。你可以把它理解为"文件夹"——把相关的物体放一起。

### 集合的用途

- **分类组织**：把椅子、桌子、地板分组
- **统一控制显示**：一键隐藏一个集合里所有物体
- **渲染控制**：某些集合不参与渲染
- **引用场景**：多个场景共用一个集合

### 集合和物体的区别

- **物体**：场景里的实体
- **集合**：物体的容器
- 一个物体可以属于**多个集合**
- 集合可以嵌套集合（子集合）

---

## 三、创建与管理集合

### 新建集合

几种方式：

1. 大纲视图里**右键空白** → "新建集合"
2. 选中物体，按 `M` → "新集合"
3. 场景属性里点 "+" 按钮

新集合默认为当前选中集合的子级。

### 移动物体到集合

- **方法 1**：选中物体，按 `M`，弹出菜单选择目标集合
- **方法 2**：在大纲视图里直接**拖拽**物体到目标集合
- **方法 3**：选中物体，右键 → "移动到集合"

### 复制物体到集合（Linked）

- 按 `Shift + M` 可以把物体**链接**到另一个集合（同时存在于两个集合）

---

## 四、集合的可见性控制

大纲视图每行有几个图标：

| 图标 | 含义 |
|---|---|
| **👁 眼睛** | 视口中是否可见（临时显示/隐藏） |
| **📷 相机** | 渲染时是否可见 |
| **🔘 圆圈** | 选择遮罩（是否可被选中） |
| **🔒 锁** | 锁定变换 |

点击集合行的眼睛图标可以**一键隐藏整个集合**。相机图标可以**排除渲染**。

### 过滤器

大纲视图右上角的**漏斗图标**可以控制显示哪些类型的图标。如果你没看到相机图标或眼睛图标，去漏斗里开启。

---

## 五、集合的快捷键

| 快捷键 | 作用 |
|---|---|
| `M` | 移动到集合 |
| `Shift + M` | 链接到集合（保留原集合） |
| `Ctrl + G` | 创建新集合（把选中物体加入） |
| `H` | 隐藏选中 |
| `Alt + H` | 显示所有 |
| `Shift + H` | 隐藏未选中（只显示选中） |

---

## 六、层（Collection）vs 旧式层（Layers）

Blender 2.79 及以前用"**Layer**"系统（20 个层），类似 Photoshop 的图层。2.8+ 改用集合，完全替代了层。

如果你找到一些老教程提到"层"，对应到新版本就是"集合"。

---

## 七、场景（Scene）

一个 .blend 文件可以有**多个场景**。场景之间完全独立：不同物体、不同相机、不同世界设置。

### 新建场景

- 顶部栏右上角的场景下拉框 → "+"
- 可以选"新建"、"复制设置"、"完全复制"、"关联复制"

### 什么时候用多场景

- 同一 .blend 文件里做多个版本
- 动画和静帧分离
- 每个场景对应不同的输出

**新手阶段一个场景足够**。

---

## 八、视图层（View Layer）

视图层是场景内部的"**渲染层**"。同一个场景可以有多个视图层，每个视图层可以包含不同的集合。

### 用途

- 做合成时分层渲染（前景/背景分开）
- 不同视图层使用不同的渲染设置
- 光照分层（只受某些灯影响）

**新手阶段不用管**。保持单一视图层即可。

---

## 九、命名规范

物体多了之后，默认的 `Cube.001` `Cube.002` 根本分不清。**养成给物体命名的习惯**。

### 如何重命名

1. 大纲视图**双击**物体名
2. 或者选中物体后按 `F2`
3. 输入新名字 → `Enter`

### 推荐命名规范

- **前缀分类**：`Chair_Leg_01`、`Light_Key`、`Camera_Main`
- **统一风格**：全用英文下划线或中文都可以，不要混
- **体现层级**：`Table_Top`、`Table_Leg_01`、`Table_Leg_02`

### 批量重命名

菜单：`物体` → `批量重命名`（快捷键 `Ctrl + F2`），支持：
- 添加前缀/后缀
- 查找替换
- 序号递增

超实用！

---

## 十、隐藏与显示技巧

### 临时隐藏

| 快捷键 | 作用 |
|---|---|
| `H` | 隐藏选中 |
| `Shift + H` | 隐藏未选中（只看选中） |
| `Alt + H` | 显示全部 |

`H` 和 `Alt + H` 是建模时常用的——复杂场景里只显示你正在改的部分。

### 永久禁用视图/渲染

大纲视图中：
- 眼睛图标：临时显示/隐藏
- 显示器图标（需要在漏斗里开启）：视口禁用
- 相机图标：渲染禁用

**区别**：
- 隐藏（眼睛）：随时可切换，保存时是隐藏状态
- 视口禁用：从 viewport 完全移除，不参与编辑
- 渲染禁用：渲染时不出现

---

## 十一、孤儿数据

数据在 Blender 里是独立的。删掉物体后，它的网格数据不一定立刻释放。

**查看孤儿数据**：大纲视图切到"孤儿数据"模式，会列出所有无用户的数据块。

**清理孤儿**：菜单 `文件` → `清理` → `清理未使用的数据块`。

**保存时自动清理**：偏好设置 → 保存和加载 → "清理未使用的数据"（按需开启）。

---

## 十二、场景层级最佳实践

### 推荐组织方式

```
场景集合
├─ 角色（Characters）
│  ├─ 主角
│  └─ 配角
├─ 环境（Environment）
│  ├─ 地面
│  ├─ 建筑
│  └─ 植被
├─ 道具（Props）
│  ├─ 桌椅
│  └─ 装饰
├─ 灯光（Lights）
│  ├─ 主光
│  ├─ 辅光
│  └─ 轮廓光
└─ 相机（Cameras）
```

每个大集合下再用子集合细分。这样你可以：
- 临时隐藏整类（比如隐藏所有灯光调试材质）
- 快速定位想找的东西
- 交付时按集合导出

---

## 十三、保存与打开

### 保存

| 快捷键 | 作用 |
|---|---|
| `Ctrl + S` | 保存 |
| `Ctrl + Shift + S` | 另存为 |
| `F2`（某些版本） | 重命名物体 |

### 保存时的自动备份

保存后 Blender 会在同目录生成 `.blend1` 文件——这是**上一次保存的备份**。手贱改坏了当前文件可以用 `.blend1` 恢复。

### 打包资源

如果你的 .blend 引用了外部贴图，打包后发给别人会找不到图。解决：

菜单 `文件` → `外部数据` → `打包资源`

Blender 会把所有引用的贴图嵌入 .blend 文件里，一个文件走天下。

## 动手练习 3.5

### 练习 A：建立场景结构
1. 新建场景
2. 删除默认立方体
3. 创建一个集合叫 "家具"
4. 添加立方体，`M` 移到"家具"集合
5. 把立方体重命名为 "桌子"
6. 再加一个立方体，叫 "椅子"，也放进家具集合
7. 创建一个集合叫 "灯光"
8. 把场景的点光源 `M` 到 "灯光"集合
9. 再加一个平面作地面，新建集合 "环境"，放进去

### 练习 B：集合显示控制
1. 大纲视图里点 "家具" 集合的眼睛图标 → 所有家具消失
2. 再点一下 → 恢复
3. 点相机图标 → 看起来没变化
4. 按 `F12` 渲染，结果没有家具（因为渲染禁用了）
5. 恢复相机图标

### 练习 C：批量重命名
1. 选中所有家具物体
2. `Ctrl + F2` → 添加前缀 "Prop_"
3. 看大纲里的名字变成 `Prop_桌子`、`Prop_椅子`

### 练习 D：隐藏技巧
1. 选中 "桌子"
2. `Shift + H` → 只显示桌子，其他都藏了
3. `Alt + H` → 全部恢复

### 练习 E：保存
1. `Ctrl + S`
2. 保存到 `练习3.5.blend`
3. 关闭 Blender
4. 重新打开文件，确认场景结构保留
