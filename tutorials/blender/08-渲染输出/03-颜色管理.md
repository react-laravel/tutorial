# 8.3 颜色管理与视图变换

> 同一个场景用不同的"视图变换"能得到完全不同的效果。新手最容易忽视这里，但专业出图必须懂。

---

## 一、为什么需要颜色管理

现实世界的光的亮度范围是**天文级别**的：
- 月光 ≈ 0.001 lux
- 室内 ≈ 100 lux
- 阳光 ≈ 100,000 lux

而显示器只能显示有限的亮度（约 0–1 的范围）。**把高动态范围压进低动态范围**就是颜色管理要做的事。

---

## 二、Blender 的颜色管理流程

```
渲染结果（线性、HDR）
  ↓ 视图变换
显示器（sRGB、LDR）
```

渲染引擎算出来的数据是**线性 HDR**（高动态范围）。"视图变换"把它映射到显示器可显示的范围。

---

## 三、视图变换选项

渲染属性 → 颜色管理 → **视图变换**：

### 标准（Standard）

- 简单的 sRGB 曲线
- 超过 1 的地方直接裁剪（**纯白过曝**）
- 鲜艳颜色容易"烧掉"

**不推荐**。新手的"过曝"问题大多是这个造成的。

### Filmic

- Blender 3.x 之前的默认
- 模拟电影胶片的响应曲线
- 保留高光和低光细节
- 看起来"电影感"

**老项目推荐用**。

### AgX（Blender 5.x 默认）

- 新一代色彩管理
- 类似 Filmic 但色彩更准确
- 鲜艳颜色不会"飘移"
- 高光柔和

**推荐默认使用**。

### Raw

- 不做任何处理
- 直接显示线性数据
- **只调色的中间步骤用**，最终出图别用

### False Color

- 假色图
- 显示曝光分布（紫=暗，红=过曝）
- **调光时用来检查曝光**

---

## 四、看点（Look）

渲染属性 → 颜色管理 → **看点**：

在视图变换基础上再叠加一层"风格"：

### AgX 看点

- Base Contrast（基础对比）
- Punchy（增强对比）
- Medium High Contrast
- Very High Contrast
- Very Low Contrast

### Filmic 看点

- Very Low / Low / Base / High / Very High Contrast
- 对比度可调

**新手用 Base（基础）或 Medium**。

---

## 五、曝光和伽玛

渲染属性 → 颜色管理：

### 曝光（Exposure）

调整整体亮度。单位是**档（EV）**。
- +1 = 亮一倍
- -1 = 暗一半
- 范围一般 -10 到 +10

### 伽玛（Gamma）

调整中间调的对比度。
- 1.0 = 原始
- > 1 = 中间调变亮
- < 1 = 中间调变暗

---

## 六、实战：用 False Color 检查曝光

### 步骤

1. 视图变换切到 **False Color**
2. 渲染预览模式
3. 看画面的颜色分布

### 颜色含义

| 颜色 | 亮度 | 含义 |
|---|---|---|
| 紫/黑 | 0 | 纯黑（信息丢失） |
| 蓝 | 0.1 | 暗部 |
| 青 | 0.3 | 中偏暗 |
| 绿 | 0.5 | 中间调（理想皮肤） |
| 黄 | 0.7 | 中偏亮 |
| 橙 | 0.9 | 亮部 |
| 红 | 1.0+ | 过曝（信息丢失） |

### 使用方法

- 主体应该在**绿色**附近
- 大面积的红色 = 过曝，降低曝光
- 大面积的紫色 = 欠曝，提高曝光

调整完后切回 **AgX** 看效果。

---

## 七、色彩空间（Color Space）

每张贴图加载时会有一个"颜色空间"设置：

| 空间 | 用途 |
|---|---|
| **sRGB** | 基础色贴图、带颜色的图 |
| **Non-Color** / 非彩色 | 粗糙度、金属度、法线、高度 |
| **Linear Rec.709** | HDR 数据 |
| **XYZ** | 特殊广色域 |

**规则**：
- **有颜色含义的图** → sRGB
- **当数据用的图** → 非彩色

错误的设置会让材质看起来不对。

---

## 八、显示器的色彩

渲染属性 → 颜色管理 → **显示设备**：

- **sRGB**：绝大多数显示器
- **Display P3**：苹果新款，广色域
- **Rec.709**：HDTV

**99% 的情况选 sRGB**。

---

## 九、输出文件的颜色空间

### PNG / JPEG

- 输出时自动做视图变换
- 所以你在 Blender 里看到什么，PNG 里就是什么

### OpenEXR

- **不做视图变换**
- 保留线性数据
- 用于后期处理（DaVinci Resolve / Nuke / Fusion）
- 在那些软件里再做色彩变换

**流程**：
- 专业流程：EXR 渲染 → 后期软件调色 → 导出 PNG/MP4
- 快速流程：直接 PNG，Blender 内完成

---

## 十、HDR 显示器与 HDR 输出

如果你有 HDR 显示器：
- Blender 内看 HDR 需要特殊配置
- 输出 HDR 图像用 EXR
- 目前 HDR 输出的生态还不完善

新手不用管。

---

## 十一、参考图对比法

调色的时候：
1. 渲染你的场景
2. 旁边放一张参考图（同类作品）
3. 对比**整体亮度**、**对比度**、**色调**
4. 调整直到接近

这是最实用的"找感觉"方法。

---

## 十二、视图变换的常见错误

### 错误 1：用 Standard 出现过曝

- 切到 AgX 就行

### 错误 2：材质看起来太"灰"

- 可能是颜色空间设错了（贴图该 sRGB 结果用了非彩色）
- 或者视图变换是 Raw

### 错误 3：渲染里的蓝色变紫

- 老的 Filmic 有这个问题
- 换 AgX 就修了

### 错误 4：黑色细节全丢

- Standard 的"死黑"
- 换 AgX 或 Filmic，或把曝光调 +1

---

## 十三、查看直方图

### 图像编辑器显示

1. 渲染结果在图像编辑器里
2. `N` 打开侧栏
3. **范围** 标签页
4. 可以看到直方图、RGB 通道、Alpha

### 直方图判读

- 所有像素集中在左边 → 欠曝
- 所有像素集中在右边 → 过曝
- 均匀分布 → 曝光合理

---

## 十四、完整的颜色工作流

1. **调材质**：视图变换保持 AgX，材质不会"看起来黄"
2. **调光**：False Color 检查曝光
3. **出图**：切回 AgX，看点 Base
4. **渲染**：PNG 16 位
5. **后期微调**：Photoshop / Affinity Photo / 免费的 GIMP

---

## 动手练习 8.3

### 练习 A：四个视图变换对比
1. 场景有强光（日光或面光 2000W）
2. 渲染预览
3. 分别切到：Standard / Filmic / AgX / Raw
4. 对比画面的高光、阴影、色彩

### 练习 B：False Color 检查
1. 视图变换 → False Color
2. 看主体是什么颜色
3. 调整曝光让主体在绿色区域
4. 切回 AgX

### 练习 C：曝光调整
1. 渲染一次
2. 曝光 +1 → 再渲染
3. 曝光 -1 → 再渲染
4. 对比

### 练习 D：贴图颜色空间
1. 加载一个 PBR 贴图套装
2. basecolor 故意改成 "非彩色" → 颜色不对
3. 改回 sRGB → 恢复正常
4. roughness 故意改成 sRGB → 材质变化
5. 改回非彩色
