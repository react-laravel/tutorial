# 8.4 输出静帧与动画

> 从"在视口看到"到"得到一张图或一段视频"是本章的最后一步。本节讲具体操作。

---

## 一、两种输出方式

- **静帧（Still）**：一张图片
- **动画（Animation）**：连续的帧

两者的参数和流程不同，本节分别讲。

---

## 二、静帧输出

### 快捷键

`F12` → 渲染当前帧

### 流程

1. 调好场景、灯光、相机
2. `F12` 渲染
3. 渲染窗口打开，显示结果
4. **重要**：渲染完成不会自动保存
5. 手动在渲染窗口：**图像** → **另存为**（`Alt + S`）
6. 选格式、输入文件名

### 保存格式选项

常用：
- PNG（带 Alpha）
- JPEG（小）
- OpenEXR（HDR）

---

## 三、查看上次渲染

`F11` 或 图像编辑器切到 "Render Result"。

多次渲染之间切换用渲染窗口里的 `J` 键切换插槽。

### 插槽

- 默认 8 个插槽（`J` 循环切换）
- 插槽 1、插槽 2、插槽 3...
- 切换插槽再 `F12` 不会覆盖前一次

这在对比不同参数、不同布光时非常有用。

---

## 四、渲染图层和合成（预告）

Blender 有内置的合成（Compositor）：

- 视口顶部切换到 "合成"
- 启用 "使用节点"
- 对渲染结果做后期（色彩、模糊、辉光...）
- 合成后的结果才是最终输出

这里不深入，知道有这个功能即可。

---

## 五、动画输出

### 动画的前提

场景里要有**关键帧**。简单动画：
1. 选相机
2. 第 1 帧 `I` → 位置
3. 时间线拖到第 60 帧
4. 移动相机
5. `I` → 位置
6. 播放看动画

### 帧率

输出属性 → 格式 → **帧率**：
- **24 fps**：电影
- **30 fps**：标准视频
- **60 fps**：游戏和流畅动作
- **12 fps**：动画工作

**常用 24 或 30**。

### 帧范围

输出属性 → 帧范围：
- 起点：1
- 终点：根据动画时长决定（24fps × 5 秒 = 120 帧）

---

## 六、动画输出为视频

### 输出设置

输出属性 → 输出：
- **文件路径**：`//animation.mp4`
- **文件格式**：**FFmpeg 视频**

### FFmpeg 子选项

展开文件格式下的 "编码"：
- **容器**：MPEG-4（常用）
- **视频编码器**：H.264
- **输出质量**：高质量 / 中等 / 低
- **编码速度**：良好
- **音频编码器**：AAC（如果有声音）

### 渲染动画

`Ctrl + F12` → 开始渲染动画。

- 每渲染完一帧自动保存
- 会持续显示进度
- 可以 `Esc` 取消

---

## 七、输出为 PNG 序列（推荐）

专业流程**不直接输出 MP4**，而是输出 PNG 序列：

### 为什么

- **中断可续**：渲染到一半停电，重开只需从中断处继续
- **坏帧可重**：发现第 53 帧有问题，只重渲那一帧
- **后期灵活**：可以对每帧单独处理
- **质量最高**：没有视频压缩

### 设置

输出属性 → 输出：
- **路径**：`//frames/`
- **格式**：PNG
- **颜色**：RGBA
- **颜色深度**：16

### 渲染

`Ctrl + F12`

完成后文件夹里会有：
- `0001.png`
- `0002.png`
- `0003.png`
- ...

---

## 八、PNG 序列合成为视频

### 方法 1：Blender 视频序列编辑器（VSE）

1. 新建窗口 → 视频编辑
2. `Shift + A` → 图像/序列 → 选全部 PNG
3. 设置输出格式为 FFmpeg 视频 H.264
4. `Ctrl + F12` 输出视频

### 方法 2：用外部工具

- **FFmpeg 命令行**：

```
ffmpeg -framerate 24 -i %04d.png -c:v libx264 -pix_fmt yuv420p output.mp4
```

- **DaVinci Resolve**（免费）：导入 PNG 序列为剪辑，直接导出

## 九、渲染耗时估算

### 计算公式

```
总时间 ≈ 单帧渲染时间 × 帧数
```

### 估算方法

1. 渲染一帧，看耗时（比如 30 秒）
2. 动画 240 帧
3. 预计 30 × 240 = 7200 秒 = **2 小时**

### 加速方法

- 降低采样数（用降噪补）
- 降低分辨率
- 简化场景
- 用 GPU
- 用持久数据（Cycles）

## 十、渲染农场

复杂项目渲染时间长怎么办？

### 本地多机

- 一台主机 + 几台辅助机
- Blender 自带**网络渲染**（旧，已弃用）
- 第三方：**Flamenco**（Blender 官方新方案）

### 在线渲染农场

- **Sheepit**：免费，靠社区积分
- **RenderStreet**：付费，快
- **Rebusfarm**：付费，专业

新手不需要这些。

## 十一、预览动画 vs 最终渲染

### 预览动画

- `Alt + A` 或时间线播放键：视口播放（不渲染，只看关键帧和动画）
- 可以 "Play Animation" 但可能卡
- 简化视口显示可以提速

### OpenGL 渲染（视口渲染）

- 视图菜单 → 视口渲染动画
- 使用当前视口模式（实体/材质预览）
- **很快**，但不是最终效果
- 适合给客户看动画的节奏

### 最终渲染

- `Ctrl + F12`
- 使用所选渲染引擎
- 出成品文件

---

## 十二、节省时间的技巧

### 集合隐藏

- **视口可见** vs **渲染可见** 是两个开关
- 可以让某些物体在视口看不见但参与渲染（反之亦然）
- 大纲视图里每个物体有"电视"图标（视口可见）和"相机"图标（渲染可见）

### 物体简化

- 渲染属性 → **简化**
- **视口**：减少细分表面、粒子数
- **渲染**：不影响最终出图
- 视口卡的时候很有用

### 区域渲染

- 相机视图里 `Ctrl + B` 框出区域
- 只渲染框选的部分
- 调材质、局部细节时快

取消区域：`Ctrl + Alt + B`

---

## 十三、批量渲染多个相机

### 方法 1：手动切换

1. 每个相机单独设激活
2. 分别 `F12`

### 方法 2：用脚本或动画

- 相机切换动画：Marker 绑定相机
- 时间线 → Marker → Bind Camera to Markers
- 渲染时自动按 Marker 切换相机

进阶技巧，新手了解即可。

---

## 十四、断点续渲

### Cycles 持久数据

渲染属性 → 性能 → 使用持久数据 ✅

- 渲染第一帧后缓存场景数据
- 后续帧更快

### 帧范围分段

- 动画太长可以分段
- 第一次渲染 1–50
- 第二次渲染 51–100
- 文件名自动递增不会覆盖

---

## 十五、输出检查清单

出图前最后检查：
- [ ] 分辨率设置对了吗？
- [ ] 输出路径对了吗？
- [ ] 文件格式对了吗（PNG vs JPEG vs EXR）？
- [ ] 透明背景开还是关？
- [ ] 视图变换是 AgX 吗？
- [ ] 帧范围对吗？
- [ ] 渲染采样够吗？
- [ ] 降噪开了吗？
- [ ] 相机是不是激活相机？
- [ ] 不该显示的物体隐藏了吗？

## 动手练习 8.4

### 练习 A：静帧输出
1. 场景任选
2. `F12` 渲染
3. 渲染窗口 `Alt + S` 保存为 PNG
4. 找到保存的文件

### 练习 B：渲染插槽
1. 渲染一次（插槽 1）
2. 改变某个灯光的强度
3. 渲染窗口 `J` 切到插槽 2
4. 再 `F12`
5. `J` 回到插槽 1 对比

### 练习 C：动画输出 PNG 序列
1. 相机加位移动画，1 到 48 帧
2. 输出格式 PNG
3. 路径 `//test_frames/`
4. `Ctrl + F12`
5. 看文件夹里的 PNG 序列

### 练习 D：PNG 序列合成视频
1. 用练习 C 的 PNG
2. 打开视频序列编辑器
3. `Shift + A` → 图像/序列 → 全选 PNG
4. 输出格式 FFmpeg → H.264
5. `Ctrl + F12` 输出视频

### 练习 E：区域渲染
1. 相机视图 `Ctrl + B` 框一小块
2. `F12` → 只渲染那一块
3. `Ctrl + Alt + B` 取消
