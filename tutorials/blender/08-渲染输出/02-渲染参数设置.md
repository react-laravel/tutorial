# 8.2 渲染参数设置

> 渲染参数决定了"多快"和"多好"。本节讲两大引擎最常用的参数，以及怎么取舍。

---

## 一、渲染属性面板在哪里

属性编辑器（右侧那一排小图标）→ **相机图标**（最上面那一个）。这就是渲染属性面板。

面板分为若干折叠组：
- 渲染引擎
- 采样
- 光线追踪（Cycles 独有）
- 光照探针（EEVEE 独有）
- 胶片
- 颜色管理
- 输出

---

## 二、输出分辨率

属性编辑器 → **输出属性**（打印机图标）→ 格式：

### 常用分辨率预设

| 用途 | 分辨率 | 宽高比 |
|---|---|---|
| 1080p 视频 | 1920 × 1080 | 16:9 |
| 4K 视频 | 3840 × 2160 | 16:9 |
| YouTube 竖屏 | 1080 × 1920 | 9:16 |
| Instagram 方图 | 1080 × 1080 | 1:1 |
| 打印 A4（300dpi）| 3508 × 2480 | √2 |
| 电影感 | 2560 × 1080 | 2.37:1 |

### 百分比

**百分比**参数可以按比例缩放：
- 预览 25%（更快）
- 最终 100%

渲染 2K 但平时用 25% 预览，速度很快。

---

## 三、帧范围

输出属性 → 帧范围：
- **帧起点**：动画起始帧
- **帧终点**：动画结束帧
- **步进**：每隔多少帧渲染一次

静帧渲染时这些参数无意义，用 `F12` 渲染当前帧即可。

---

## 四、EEVEE Next 采样

渲染属性 → **采样**：

### 视口

- **采样数**：视口预览的最大采样（默认 16）
- **抗锯齿**：自动抗锯齿的多重采样

### 渲染

- **采样数**：最终出图的采样（默认 64）
- 数值越高越平滑，但到达一定程度后收益递减

### 建议值

| 场景 | 视口 | 渲染 |
|---|---|---|
| 简单静物 | 16 | 64 |
| 复杂材质 | 32 | 128 |
| 体积光、景深 | 64 | 256 |

---

## 五、Cycles 采样

渲染属性 → **采样**：

### 视口

- **最大采样**：默认 1024
- **降噪阈值**：达到阈值就停
- 开启**视口降噪**更舒服

### 渲染

- **最大采样**：默认 4096
- **降噪阈值**：默认 0.01
- 大多数情况到不了最大采样，降噪阈值先触发

### 建议值

| 场景 | 渲染采样 | 备注 |
|---|---|---|
| 产品静物 | 128–256 | 开降噪 |
| 室内 | 512–1024 | 全局光多 |
| 焦散 | 1024–4096 | 很慢 |
| 动画单帧 | 64–128 | 配合降噪 |

---

## 六、降噪参数

渲染属性 → 采样 → **降噪**：

- **视口降噪**：勾选（预览用）
- **渲染降噪**：勾选（出图用）
- **降噪器**：OpenImageDenoise 或 OptiX
- **输入通道**：RGB / RGB + 反照率 / RGB + 反照率 + 法线
  - 通道越多越准，默认推荐**反照率 + 法线**

---

## 七、光线反弹（Cycles）

渲染属性 → 光线追踪 → **光线路径**：

| 类型 | 默认 | 说明 |
|---|---|---|
| 总最大 | 12 | 总上限 |
| 漫射 | 4 | 物体表面间的互反射 |
| 光泽 | 4 | 反射表面间反射 |
| 透射 | 12 | 玻璃类 |
| 体积 | 0 | 烟雾等 |
| 透明 | 8 | Alpha 透明 |

### 什么时候改

- **玻璃杯水**：透射调到 32
- **镜子房间**：光泽调到 16
- **加速渲染**：所有值 ÷ 2

---

## 八、胶片设置

渲染属性 → **胶片**：

### 曝光

曝光调整整体亮度。单位是档（EV）。

- 0 = 原始
- +1 = 亮一倍
- -1 = 暗一半

比直接改光源能量方便。

### 透明背景

**透明** 勾选后：
- 渲染输出背景透明
- PNG 导出时保留 Alpha
- HDRI 依然照亮，但不显示为背景

---

## 九、颜色管理

渲染属性 → **颜色管理**：

| 参数 | 作用 | 推荐 |
|---|---|---|
| **视图变换** | 最终显示方式 | AgX（默认）或 Filmic |
| **观察设备** | 显示器类型 | sRGB |
| **曝光** | 显示亮度 | 0 |
| **伽玛** | 显示对比度 | 1 |
| **看点** | 风格预设 | 无 |

**视图变换重要**：
- **AgX**：Blender 5.x 新默认，色彩最自然
- **Filmic**：老默认，电影感
- **标准**：最原始，容易过曝

**新手用 AgX 就对了**。

---

## 十、输出格式

输出属性 → **输出**：

### 文件路径

- 默认 `//tmp\`（`//` 表示相对于 .blend 文件）
- 改成自己想要的路径

### 文件格式

| 格式 | 位深 | 用途 |
|---|---|---|
| **PNG** | 8/16 位 | 常用，支持 Alpha |
| **JPEG** | 8 位 | 最小，无 Alpha |
| **OpenEXR** | 32 位浮点 | 后期调整空间大 |
| **TIFF** | 8/16 位 | 印刷行业 |
| **MP4** | 视频 | 动画输出 |
| **WebM** | 视频 | 网页 |

**推荐**：
- 静帧：**PNG 16 位** 或 **OpenEXR**
- 动画：先出**PNG 序列**，后期再合成视频
- 快速预览：JPEG

### 颜色深度和 Alpha

- 深度：8 / 16 位
- 颜色：RGB 或 RGBA
- 压缩：PNG 的压缩率

---

## 十一、PNG 序列 + 后期合成

专业流程：
1. 渲染输出 PNG 序列（一帧一张图）
2. 出错只需重渲坏帧
3. 用 Blender 视频编辑器或 DaVinci Resolve 合成视频

**直接输出 MP4** 的问题：
- 渲染中断就废了
- 一帧坏就全坏
- 适合快速预览

---

## 十二、性能优化技巧

### Cycles

- **自动图块**：自动按系统优化
- **使用持久数据**：多帧渲染时缓存，加速后续帧
- **简化**：视口模式下减少修改器级别、粒子数

### EEVEE Next

- **烘焙辐照度和反射探针**（复杂场景）
- **减少采样**，降噪补
- **关闭屏幕空间反射**（如果不需要）

### 通用

- **预览时用低分辨率**（25%）
- **最终出图前关掉多余物体**（用集合隐藏渲染）
- **隐藏渲染图标**（相机图标）控制物体参不参与渲染

---

## 十三、批量渲染快捷键

- `F12`：渲染当前帧
- `Ctrl + F12`：渲染动画
- `F11`：显示上次渲染结果
- 渲染窗口里 `J` 切换插槽（可以对比两次渲染）

---

## 十四、典型配置示例

### 快速预览

```
引擎：EEVEE Next
采样：视口 16，渲染 32
分辨率：50%
视图变换：AgX
```

### 静物出图

```
引擎：Cycles
采样：渲染 256
降噪：OpenImageDenoise
设备：GPU
分辨率：100%（1920×1080）
视图变换：AgX
```

### 动画出图

```
引擎：EEVEE Next
采样：渲染 64
分辨率：100%（1920×1080）
输出：PNG 序列
视图变换：AgX
帧范围：1–250
```

## 动手练习 8.2

### 练习 A：分辨率与百分比
1. 场景随意
2. 输出 1920×1080
3. 改百分比 25%
4. `F12` 看结果尺寸变化
5. 改回 100%

### 练习 B：Cycles 采样对比
1. Cycles，采样 16 → 渲染一次（噪点严重）
2. 采样 128 → 渲染一次
3. 采样 128 + 降噪 → 再渲染
4. 对比三者

### 练习 C：AgX vs 标准
1. 一个有强光的场景
2. 视图变换 "标准" → 容易过曝
3. 视图变换 "AgX" → 保留高光细节
4. 对比

### 练习 D：渲染动画到 PNG 序列
1. 简单的旋转动画（几帧）
2. 输出格式 PNG
3. 输出路径 `//render/`
4. `Ctrl + F12` 出动画
5. 文件夹里一堆 PNG
