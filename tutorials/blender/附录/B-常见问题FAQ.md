# 附录 B · 常见问题 FAQ

> 新手经常遇到的问题和解决方法。遇到问题先查这里再去问人。

---

## 一、界面和启动

### Q：打开 Blender 是英文，怎么切中文？

A：编辑 → 偏好设置 → 界面 → 语言 → 简体中文。

### Q：界面乱了怎么办？

A：文件 → 默认 → 加载出厂设置。

### Q：Blender 启动很慢？

A：
1. 检查 `Addons` 里是否加载了太多插件
2. 显卡驱动是否最新
3. 启动文件过大（清理 .blend 启动文件里的物体）

### Q：字体太小看不清？

A：偏好设置 → 界面 → **分辨率缩放** 调到 1.2 或 1.5。

---

## 二、视图操作

### Q：按中键没反应？

A：
1. 确认鼠标中键能用（中键 = 滚轮按下）
2. 笔记本没有中键？偏好 → 输入 → **模拟 3 键鼠标**（Alt + 左键代替中键）

### Q：视图转丢了，看不到东西？

A：
- `Home` 聚焦所有物体
- 或 `Num .` 聚焦选中

### Q：相机视图看不到任何东西？

A：
- 相机位置和方向不对
- 按 `Num 0` 进入相机视图
- 侧栏 `N` → 视图 → **相机到视图** 再调整

### Q：正交视图和透视视图切换？

A：`Num 5`。

---

## 三、选择和变换

### Q：按 A 全选没反应？

A：鼠标要在 3D 视图里。

### Q：`G X 5` 为什么不移动？

A：可能当前"变换方向"不是全局。按 `,` 切换到全局，或直接用 `G Shift + X`（约束到 YZ）也许是你要的。

### Q：复制之后原点位置不对？

A：`Shift + D` 复制保留原点在原位置。手动移动后原点仍跟着物体。如需重设 → 右键 → **设置原点** → 几何中心。

### Q：点线面切不过去？

A：要**在编辑模式里**按 `1 / 2 / 3`。物体模式这些键是集合切换。

---

## 四、建模

### Q：挤出后按 Esc 怎么消不掉？

A：Esc 只取消移动，但挤出已经发生了（产生了几何）。需要再按 `Ctrl + Z` 完全撤销。

### Q：模型看起来"黑面"？

A：法线反了。编辑模式 `A` 全选 → `Shift + N` 重算法线。

### Q：平滑后边缘糊成一团？

A：
- 细分表面修改器会把锐边吃掉
- 解决：加更多环切在锐边附近
- 或者用**自动平滑（Smooth by Angle）** 而非普通平滑

### Q：按 Tab 进不了编辑模式？

A：选中的物体必须是网格类型。灯光、相机、骨骼有自己的编辑模式。

### Q：布尔修改器结果很糟糕？

A：
- 两个物体必须都是**封闭的网格**（没有洞）
- 检查法线方向
- 应用所有变换 `Ctrl + A`
- 合并顶点 `M → 按距离`

## 五、材质和贴图

### Q：材质预览模式看不到材质？

A：
- 顶部切换到"材质预览"而不是"实体"
- 或"渲染预览"更准

### Q：贴图加载后物体是粉色？

A：图像路径丢失。文件 → 外部数据 → **查找丢失的文件**。或打开图像节点重新指定。

### Q：贴图拉伸变形？

A：UV 没展开或展开不当。编辑模式 `A` 全选 → `U` → 智能 UV 投影。

### Q：法线贴图不起作用？

A：
- 颜色空间必须是 "非彩色（Non-Color）"
- 必须经过"法线贴图节点"再连到 BSDF
- 不能直接连

### Q：材质"太亮"总过曝？

A：渲染属性 → 颜色管理 → 视图变换 → **AgX**。

## 六、灯光和渲染

### Q：场景完全黑？

A：
- 没开灯？`Shift + A` → 灯光
- 切到"渲染预览"才能看到灯光效果
- 世界属性的环境色是否为 0

### Q：渲染结果全白？

A：
- 灯太亮
- 或视图变换是 "标准"（换 AgX）

### Q：Cycles 渲染特别慢？

A：
- 偏好设置 → 系统 → 启用 GPU
- 渲染属性 → 设备 → GPU 计算
- 降低采样 + 开降噪

### Q：EEVEE 的玻璃不透明？

A：
- 材质的"混合模式"改成 **Alpha 混合** 或 **不透明/透明**
- 打开"屏幕空间折射"

### Q：动画渲染中断了怎么办？

A：
- 如果是 PNG 序列，只需改帧起点继续渲
- 如果直接输出 MP4，整个视频废了

## 七、文件和路径

### Q：发给别人的 .blend 文件贴图丢了？

A：文件 → 外部数据 → **打包所有到 .blend**。

### Q：相对路径和绝对路径？

A：
- `//foo.png` 是相对路径（相对于 .blend 文件）
- `/Users/.../foo.png` 是绝对路径
- 推荐用相对路径（.blend 文件移动到别的电脑仍然能找到贴图）

### Q：Blender 崩溃了文件没保存？

A：文件 → 恢复 → **恢复上次会话** 或 **恢复自动保存**。
偏好 → 保存&加载 里可以调整自动保存间隔。

## 八、性能

### Q：视口变卡？

A：
- 关闭修改器的视口显示图标（保留渲染）
- 隐藏不需要的物体 `H`
- 用局部视图 `/`
- 降低细分表面的视口级别

### Q：文件越来越大？

A：
- 清理未使用数据：文件 → 清理 → 递归清除未使用数据
- 压缩保存（偏好里开）

### Q：某些物体不参与渲染？

A：大纲里每个物体有两个眼睛图标：
- **视口可见**（眼睛）
- **渲染可见**（相机）
  确保渲染可见开着。

## 九、常见错误信息

### "Cannot edit data from shared library"

A：物体是链接来的外部资源，不能直接编辑。右键 → **本地化** 或改为"附加"。

### "No valid data: No active camera"

A：场景没有激活相机。选一个相机 `Ctrl + Num 0`。

### "Out of memory"

A：场景太大或采样太高。简化场景、降低分辨率、用降噪。

### "Missing textures"

A：贴图路径失效。文件 → 外部数据 → 查找丢失的文件。

## 十、版本和兼容

### Q：新版本的文件能在旧版本打开吗？

A：**不能**（大多数情况下）。Blender 新版文件不向下兼容。

### Q：旧版本的文件能在新版本打开吗？

A：**通常能**，但可能有小问题（某些节点变了、某些参数默认值变了）。

### Q：Blender 5.x 和 4.x 有什么主要区别？

A：
- 5.x 默认 **AgX** 色彩空间
- 界面和图标微调
- EEVEE Next 更成熟
- 一些节点名称或位置变动
- 5.x 对硬件要求略高

## 十一、学习相关

### Q：应该先学建模还是动画？

A：**先建模**。动画需要有东西可以动。

### Q：一定要学节点吗？

A：**必须**。做材质、后期、程序化都要。先学着色器节点，再学几何节点。

### Q：需要什么样的电脑？

A：
- 最低：8GB 内存 + 集显（EEVEE 可以，Cycles 非常慢）
- 推荐：16GB+ 内存 + NVIDIA 3060 以上
- 专业：32GB+ + 3070 以上

### Q：Mac 能用 Blender 吗？

A：能。Apple Silicon（M1/M2/M3/M4）有 Metal 后端，速度很快。

### Q：每天练多久合适？

A：1–2 小时效果最好。超过容易烧掉热情。周末可以 4 小时。

## 十二、调试思路

当你发现"我做的和教程不一样"：

1. **截图** 两者界面对比
2. 检查**当前模式**（物体 / 编辑 / 姿态）
3. 检查**选中的物体**是否正确
4. 检查**坐标原点**是否归位
5. 检查**修改器**顺序
6. 检查**节点连接**是否正确
7. 检查**材质/贴图**是否正确分配
8. **保存当前，重启** Blender（有时就是 bug）
9. 用 `Ctrl + Z` 一步步回退
