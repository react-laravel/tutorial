# 附录 A · 快捷键速查表

> Blender 的快捷键非常多。本表只列出**最常用**的。完整列表可查官方手册。

---

## 一、通用

| 快捷键 | 作用 |
|---|---|
| `Ctrl + S` | 保存 |
| `Ctrl + Shift + S` | 另存为 |
| `Ctrl + O` | 打开 |
| `Ctrl + N` | 新建 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` | 重做 |
| `F3` | 搜索命令 |
| `F1` | 打开手册 |
| `Ctrl + 空格` | 编辑器全屏切换 |
| `F11` | 显示上次渲染结果 |
| `F12` | 渲染当前帧 |
| `Ctrl + F12` | 渲染动画 |

---

## 二、视图导航

| 快捷键 | 作用 |
|---|---|
| `中键` 拖 | 旋转视图 |
| `Shift + 中键` 拖 | 平移视图 |
| `Ctrl + 中键` 拖 | 缩放视图 |
| `滚轮` | 缩放 |
| `Num 1` | 前视图 |
| `Ctrl + Num 1` | 后视图 |
| `Num 3` | 右视图 |
| `Ctrl + Num 3` | 左视图 |
| `Num 7` | 顶视图 |
| `Ctrl + Num 7` | 底视图 |
| `Num 5` | 正交/透视切换 |
| `Num 0` | 相机视图 |
| `Ctrl + Num 0` | 激活相机为选中 |
| `Ctrl + Alt + Num 0` | 相机对齐到视图 |
| `Num .` | 聚焦到选中 |
| `Home` | 聚焦所有 |
| `/` | 局部视图（隔离选中） |

---

## 三、选择

| 快捷键 | 作用 |
|---|---|
| `左键` | 选择 |
| `Shift + 左键` | 加选/取消 |
| `A` | 全选 |
| `Alt + A` | 全部取消 |
| `Ctrl + I` | 反选 |
| `B` | 框选 |
| `C` | 圆形选 |
| `L` | 关联选（鼠标位置下的连通部分） |
| `Alt + 左键` | 边循环选（编辑模式） |
| `Ctrl + 左键` | 最短路径选（编辑模式） |

---

## 四、变换（G / R / S）

| 快捷键 | 作用 |
|---|---|
| `G` | 移动 |
| `R` | 旋转 |
| `S` | 缩放 |
| `G X` / `R Y` / `S Z` | 限定轴向 |
| `G Shift + X` | 除 X 外（在 YZ 平面） |
| `G` → 数字 → 回车 | 精确移动距离 |
| `R X 45` | 绕 X 轴 45° |
| `Ctrl + G` | 捕捉移动（贴附） |
| `G G` | 边滑移（编辑模式） |
| `Alt + G` | 清除位置 |
| `Alt + R` | 清除旋转 |
| `Alt + S` | 清除缩放 |

---

## 五、物体模式

| 快捷键 | 作用 |
|---|---|
| `Shift + A` | 添加物体 |
| `X` 或 `Delete` | 删除 |
| `Shift + D` | 复制 |
| `Alt + D` | 关联复制（共享网格） |
| `Ctrl + P` | 设父级 |
| `Alt + P` | 清父级 |
| `Ctrl + J` | 合并选中物体 |
| `M` | 移到集合 |
| `H` | 隐藏选中 |
| `Alt + H` | 显示所有隐藏 |
| `Shift + H` | 隐藏其他 |
| `Tab` | 切换编辑模式 |
| `Ctrl + A` | 应用变换菜单 |
| `Ctrl + L` | 关联菜单（材质、数据等） |

---

|---|---|

|---|---|

## 十一、节点编辑器

| 快捷键 | 作用 |
|---|---|
| `Shift + A` | 添加节点 |

| `Ctrl + Shift + T` | 批量 PBR（Node Wrangler） |
| `Ctrl + Shift + 左键` | 查看节点输出（视口预览） |
| `M` | 静音节点 |
| `X` | 删除节点 |
