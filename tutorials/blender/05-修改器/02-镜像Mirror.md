# 5.2 镜像 Mirror

> 做对称物体时，镜像修改器让你只建半边，另一半自动生成。角色、车辆、建筑，几乎所有对称物都会用到它。

---

## 一、镜像的原理

镜像修改器：选择一个坐标轴作为"镜面"，把网格的另一半自动镜像出来。

**默认镜像物体的原点，沿 X 轴**。

---

## 二、基本使用

1. 选中物体
2. 扳手 → 添加修改器 → 生成 → **镜像**
3. 默认启用 X 轴镜像
4. 进入编辑模式，在 +X 一侧建模
5. -X 一侧会实时同步出现

---

## 三、关键参数

### 坐标轴（Axis）
勾选 X / Y / Z 决定沿哪个轴镜像。多个轴可以同时勾，会得到多方向对称（比如雪花、车轮）。

### 镜像物体（Mirror Object）
默认镜像是相对于**自身原点**。如果你想相对于另一个物体镜像，把那个物体拖到这里。

### 二分（Bisect）
镜像前先把另一边切掉。这对处理已经跨越了对称面的几何很有用。

### 翻转（Flip）
配合二分使用，翻转保留哪一边。

### 合并（Merge）
**非常重要**！勾选后，镜面处的两边顶点会自动合并成一个。如果不勾，中线上会有**双倍点**，看起来连上了但其实是分开的。

阈值控制合并的距离，默认 0.001 米即可。

### 裁剪（Clipping）
在编辑模式里**阻止顶点跨过对称面**。勾上以后，你拖动中线附近的顶点时它们不会穿过 X=0，从而保证对称性不被破坏。

**强烈建议勾选**。

### 镜像 U/V
如果模型有 UV，可以让镜像后的 UV 也跟着翻转。

---

## 四、实战：做对称人物

1. `Shift + C` 游标归零
2. 添加一个立方体作为身体雏形
3. 进入编辑模式
4. 选 X<0 的一半（框选左半）
5. `X → 顶点` 删除
6. 退出编辑模式
7. 添加镜像修改器，X 轴，勾选"合并"和"裁剪"
8. 再进入编辑模式，你会看到左半被自动镜像回来
9. 只编辑右半，左半自动同步

---

## 五、镜像的陷阱

### 陷阱 1：原点偏了

镜像是相对于**物体原点**进行的。如果原点不在 X=0，镜像结果会跑偏。

**解决**：
- `Shift + S → 游标到世界原点`
- `物体 → 设置原点 → 原点到 3D 游标`

### 陷阱 2：忘了勾选"合并"

中线附近有裂缝或光照不连续 → 检查是否勾选合并。

### 陷阱 3：顶点跨过中线

手动拖顶点超过 X=0 → 出现交叉 → 勾选"裁剪"可以防止。

### 陷阱 4：已经歪斜的物体

如果物体本身有旋转，镜像可能不沿世界 X 轴。先 `Ctrl + A → 旋转` 应用旋转。

---

## 六、镜像多个轴

勾选多个轴会产生更复杂的对称：

- **只 X**：左右对称（最常见）
- **只 Z**：上下对称
- **X + Z**：四重对称
- **X + Y + Z**：八重对称，雪花、宝石

---

## 七、使用另一个物体作为镜像中心

比如你要让物体绕一个特定点镜像：

1. 添加一个**空物体**到镜像中心
2. 把这个空物体拖到修改器的"镜像物体"槽
3. 现在镜像以空物体为中心

这对处理不方便调整原点的物体很有用。

---

## 八、镜像 vs 关联复制 + S -1

老方法：`Alt + D` 关联复制，`S X -1` 镜像。它能模拟镜像效果，但：
- 中线不会合并
- 没有自动裁剪
- 是物体层级而不是几何层级

**新手建议用镜像修改器，省心又强大**。

---

## 九、应用镜像

建模结束后通常要应用镜像：

1. 确认模型已经完成
2. 点镜像修改器的 `⁝` → 应用
3. 现在左右两边变成实实在在的几何

**注意**：应用后如果还想对称编辑，可以开启"X 轴对称"（编辑模式里：网格 → 对称编辑 → X 轴）。

---

## 十、X 轴对称（编辑模式）

这是另一种镜像方式，不是修改器：

1. 进入编辑模式
2. 菜单 `网格 → 对称编辑` 或者 3D 视图头部栏找"对称"按钮
3. 勾选 X
4. 编辑一个顶点时，对称位置的顶点自动同步

**区别**：
- 对称编辑只在编辑模式中起作用，不创建新几何
- 镜像修改器实际创建镜像几何

对称编辑适合已经对称的模型继续编辑；镜像修改器适合只建半边。

---

## 动手练习 5.2

### 练习 A：基础镜像
1. 默认立方体
2. `Tab`，选 X<0 的半边所有点 → `X → 顶点`
3. `Tab` 退出
4. 加镜像修改器，勾"合并"和"裁剪"
5. 再 `Tab` 进入编辑，修改右半，看左半同步

### 练习 B：三轴对称
1. 立方体
2. 删一个角（选 X>0, Y>0, Z>0 的顶点，删除）
3. 加镜像修改器，勾 X/Y/Z 全部
4. 看立方体重新被镜像补全（8 个角）

### 练习 C：相对另一个物体镜像
1. 加一个空物体到 `(2, 0, 0)`
2. 加一个立方体到 `(4, 0, 0)`
3. 给立方体加镜像修改器
4. 镜像物体槽里选刚才的空物体
5. 立方体的镜像出现在 `(0, 0, 0)` 附近

### 练习 D：组合细分
1. 立方体
2. 删一半
3. 先加镜像
4. 再加细分表面 2 级
5. **顺序一定是镜像在上**
