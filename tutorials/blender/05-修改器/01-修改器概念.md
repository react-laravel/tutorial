# 5.1 修改器是什么

> 修改器是 Blender 最强大的功能之一。掌握它，你的建模效率会提升一个档次。

---

## 一、修改器的核心概念

**修改器（Modifier）**：一种**非破坏性**的几何变换——它在显示/渲染时对你的网格应用某种规则，但不改变原始几何数据。

### 非破坏性 vs 破坏性

| 类型 | 说明 | 例子 |
|---|---|---|
| **破坏性** | 操作立刻"烧进"网格，不可逆 | 编辑模式里的挤出、移动、删除 |
| **非破坏性** | 作为独立规则存在，可随时调整或删除 | 修改器（镜像、细分、阵列...） |

### 修改器的好处

1. **可撤销**：不喜欢就删掉修改器，原网格完好
2. **可调参**：随时改参数，效果实时更新
3. **省工作量**：一个修改器顶十次手动操作
4. **可叠加**：多个修改器可以组合成复杂效果

---

## 二、怎么打开修改器面板

1. 选中一个网格物体
2. 属性编辑器 → 点 **扳手图标** 🔧
3. 看到一个空面板（第一次打开）
4. 点击 **"添加修改器"** 按钮
5. 选择要加的修改器类型

---

## 三、修改器分类

修改器分为 4 大类：

### 1. 修改（Modify）
- 数据层面的修改
- 如：UV 投影、网格缓存

### 2. 生成（Generate）
- **最常用的类别**
- 创建新的几何体
- 如：阵列、倒角、布尔、镜像、细分、实体化

### 3. 变形（Deform）
- 改变顶点位置但不增加面
- 如：弯曲、扭曲、平滑、浪、晶格

### 4. 物理（Physics）
- 模拟类
- 如：布料、流体、碰撞、粒子

**新手阶段重点关注"生成"类**。

---

## 四、修改器堆栈（Stack）

修改器是**按顺序**应用的，从上到下叠加。这个顺序被称为"**修改器堆栈**"。

### 顺序很重要

```
原始网格 → [修改器1] → [修改器2] → [修改器3] → 最终显示
```

前一个修改器的输出是后一个的输入。**顺序改变，结果可能完全不同**。

### 例子：镜像 + 细分

- 顺序 A：镜像在上，细分在下 ✅ 正确
- 顺序 B：细分在上，镜像在下 ❌ 会在中线出现裂缝

原因：先细分会让中线的顶点离开对称位置，再镜像时就合不上了。

---

## 五、调整顺序

每个修改器面板右上角有一个 `⁝` 下拉菜单（或箭头），里面有：

- **上移**：把这个修改器往上移
- **下移**
- **应用**
- **复制**
- **删除**

也可以直接**拖动**修改器的标题条调整顺序。

---

## 六、应用修改器：Apply

点修改器的 `⁝` → **应用**。

### 应用的含义

- 修改器的效果被**写入网格**
- 修改器本身消失
- 原来的非破坏性变成破坏性
- 不可撤销（除了 `Ctrl + Z`）

### 什么时候应用

- 修改器确定了，要导出模型到其他软件
- 要继续在编辑模式里手动改
- 清理工程文件

### 什么时候**不**应用

- 还在调参数的过程中
- 还需要修改器的灵活性
- 复杂堆栈，应用后无法回头

**建议**：应用前先 `Shift + D` 复制一份物体作为备份，免得后悔。

---

## 七、修改器的显示图标

每个修改器右上角有几个小图标：

| 图标 | 作用 |
|---|---|
| **📷 相机** | 是否在**渲染**时生效 |
| **🖥 显示器** | 是否在**视口**中显示 |
| **◼ 编辑模式** | 是否在**编辑模式**中显示效果 |
| **◇ 笼子** | 编辑时是否显示修改器效果的"笼"子 |

可以临时关闭某些图标来比较"原网格"和"修改器后"的差异。

---

## 八、修改器不可见的情况

有时候你加了修改器但看不到效果：

### 检查清单

- [ ] 显示器图标开启了吗？
- [ ] 对于细分表面：数值 > 0 吗？
- [ ] 对于镜像：有轴开启吗？
- [ ] 对于布尔：对象选择了吗？
- [ ] 修改器顺序正确吗？

---

## 九、修改器是数据流

你可以把修改器看作一条"数据管道"：

```
[顶点/边/面数据] → 修改器 1 → 修改器 2 → ... → [最终几何]
```

这种设计让工作流非常灵活。你可以随时：
- 禁用某个修改器看看效果
- 调整中间某个参数
- 删除某个修改器
- 插入新的修改器

对于习惯"一步到位"的新手，这种思维需要适应。

---

## 十、常用修改器速览

本章后续节会详讲这几个：

| 修改器 | 用途 |
|---|---|
| **镜像** | 对称物体，只建半边 |
| **细分表面** | 让硬表面变圆滑 |
| **阵列** | 重复排列 |
| **布尔** | 挖洞、相加、相交 |
| **实体化** | 给平面加厚度 |
| **倒角** | 全局倒角 |
| **简易形变** | 弯曲、扭曲、锥化 |
| **晶格** | 用低模控制高模变形 |

---

## 十一、修改器的限制

修改器不是万能的：

1. **有些操作不能用修改器做**：手动雕刻细节、UV 展开、材质分配
2. **性能开销**：复杂的修改器堆栈会让视口变慢
3. **顺序敏感**：错误的顺序会得到错误结果
4. **应用后不可逆**：应用是单向操作

---

## 十二、查看修改器效果的快捷键

- `Ctrl + 1/2/3`：为选中物体添加"**细分表面**"修改器并设为 1/2/3 级（最快加细分的方法）

---

## 动手练习 5.1

### 练习 A：加个细分看看
1. 默认立方体
2. 属性编辑器 → 扳手 → 添加修改器 → 生成 → **细分表面**
3. 调整"视口"滑块从 0 到 3
4. 看立方体从方到圆的过程
5. 关闭显示器图标，看立方体恢复原状

### 练习 B：修改器顺序
1. 新立方体
2. 加**细分表面**修改器
3. 加**镜像**修改器
4. 看效果怎么样（中线应该有问题）
5. 把镜像拖到细分上面
6. 现在正常了

### 练习 C：应用
1. 新立方体
2. 加细分表面 2 级
3. 点 `⁝` → 应用
4. `Tab` 进入编辑模式
5. 原本平滑的几何变成真实的高模多面

### 练习 D：快捷键加细分
1. 选中一个立方体
2. 按 `Ctrl + 2` → 瞬间加了 2 级细分表面
