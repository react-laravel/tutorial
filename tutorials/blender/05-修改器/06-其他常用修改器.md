# 5.6 其他常用修改器

> 除了前面讲过的镜像、细分、阵列、布尔，Blender 还有一堆常用修改器。这节一口气过一遍新手应该知道的。

---

## 一、实体化 Solidify

### 作用

给一个**没有厚度的平面**或**开口网格**加上实际厚度。

### 典型场景

- 平面转"薄板"（比如纸、瓷砖）
- 开口容器转实体（比如杯子、花瓶）
- 布料转硬壳

### 参数

- **厚度（Thickness）**：0.01~0.1 常见
- **偏移（Offset）**：厚度分布在原面的哪一侧
  - `-1`：完全向内（原面在外）
  - `0`：原面居中
  - `1`：完全向外（原面在内）
- **均匀厚度**：避免在弯曲处厚度不均
- **填充边界**：给开口处加盖

### 实战：做一个圆盘

1. 添加**圆环**网格（30 段）
2. 面模式全选 → `F` 填充（变成一个圆面）
3. 加实体化，厚度 0.1
4. 得到一个圆盘

---

## 二、倒角修改器 Bevel (Modifier)

### 作用

给整个模型的边**自动加倒角**。和 `Ctrl + B` 工具的区别：
- 工具：手动选边
- 修改器：一次性处理所有边

### 关键参数

- **宽度（Width）**
- **段数（Segments）**
- **限制方法（Limit Method）**：
  - 无：所有边都倒角
  - 角度：只倒大于指定角度的锐边（默认 30°）
  - 权重：只倒标记了"倒角权重"的边
  - 顶点组：只倒属于某个顶点组的边

### 经典用法：全局微倒角

给所有物体一个统一的 0.01 米微倒角：

1. 加倒角修改器
2. 宽度 0.01，段数 2
3. 限制：角度 30°
4. 所有锐边自动有了微倒角

这能显著提升真实感，几乎没性能成本。

---

## 三、简易形变 Simple Deform

### 作用

对物体进行全局**弯曲 / 扭曲 / 锥化 / 拉伸**。

### 类型

- **扭曲（Twist）**：绕轴旋转
- **弯曲（Bend）**：像拱桥
- **锥化（Taper）**：一端大一端小
- **拉伸（Stretch）**：沿轴拉长

### 参数

- **轴**：X / Y / Z
- **量（Angle/Factor）**：变形强度
- **限制**：只变形某段区域

### 实战：做一条弯的管子

1. 立方体 `S X 5` 拉长
2. 环切 10 条增加几何密度
3. 加简易形变 → 弯曲 → Z 轴 → 90°
4. 管子弯成 1/4 圆

### 实战：扭曲柱子

1. 立方体 `S Z 3` 拉高
2. 环切 20 条加密
3. 加简易形变 → 扭曲 → Z 轴 → 360°
4. 柱子扭成麻花

---

## 四、晶格 Lattice

### 作用

用一个**低分辨率的格子**（晶格物体）控制高分辨率的网格变形。

### 流程

1. `Shift + A` → 晶格 → 创建一个晶格
2. 晶格默认是 2×2×2 的空笼子
3. 在晶格物体属性里提高分辨率（比如 3×3×3）
4. 给目标物体加晶格修改器
5. 指定晶格物体
6. 选晶格，`Tab` 进入编辑模式
7. 拖动晶格的顶点 → 目标物体跟着变形

### 典型用例

- 让角色弯曲
- 快速整体变形
- 动画中的"squash & stretch"

---

## 五、收缩包裹 Shrinkwrap

### 作用

让一个网格**吸附到另一个网格的表面**。

### 用途

- 贴图投影用
- 高模 → 低模的包裹
- 让布料贴合身体
- 做浮雕

---

## 六、拆边 Edge Split

### 作用

把某些边"**断开**"，让着色时产生锐利边。

老版本 Blender 用这个做锐边，现在被"按角度平滑"取代了，但在某些工作流中仍然有用。

---

## 七、Remesh（重构网格）

### 作用

**重建一个全新的、拓扑不同的网格**，保持大致形状。

### 模式

- **块**：用方块拼出形状（像素风）
- **光滑**：球形近似
- **锐利**：保留更多角
- **体素**：基于体素的重建

### 用途

- 雕刻后重拓扑
- 把复杂布尔结果简化
- 创造像素/体素风格

---

## 八、变形修改器（Deform 类）总览

除了上面讲的，还有：

| 修改器 | 作用 |
|---|---|
| **弯曲（Cast）** | 把物体拉向球/圆柱形状 |
| **曲线（Curve）** | 让物体沿曲线弯曲 |
| **钩子（Hook）** | 用空物体拉拽部分顶点 |
| **激光束（Laser Beam）** | 切割效果 |
| **波（Wave）** | 波浪效果 |
| **平滑（Smooth）** | 全局平滑几何 |

---

## 九、生成修改器（Generate 类）总览

| 修改器 | 作用 |
|---|---|
| **装饰布（Decimate）** | 减面，保留大致形状 |
| **遮罩（Mask）** | 用顶点组隐藏部分几何 |
| **多重分辨率（Multires）** | 类似细分但支持雕刻 |
| **表层（Skin）** | 把骨架转成有体积的皮肤 |
| **焊接（Weld）** | 按距离合并顶点 |
| **线框（Wireframe）** | 把面变成框架线 |

### Decimate（减面）特别有用

从网络下载的模型面数太多？加一个 Decimate 修改器，调比例到 0.1 → 面数剩下 10%，一键减面。

---

## 十、修改器快捷键总结

| 快捷键 | 作用 |
|---|---|
| `Ctrl + 1` | 加/修改细分修改器为 1 级 |
| `Ctrl + 2` | 2 级 |
| `Ctrl + 3` | 3 级 |
| `Ctrl + A` + 应用 | 应用修改器（部分情况下） |

## 动手练习 5.6

### 练习 A：实体化
1. 添加平面
2. 加实体化，厚度 0.1
3. `Tab` 看里面真的有了立体

### 练习 B：弯曲管
1. 立方体 `S X 5`
2. 加 20 条环切（加密几何）
3. 加简易形变 → 弯曲 → Z → 90
4. 管子弯成直角

### 练习 C：扭曲塔
1. 立方体 `S Z 4`
2. 加 30 条环切
3. 加简易形变 → 扭曲 → Z → 180
4. 再加细分表面 2 级
5. 得到一座扭曲的塔

### 练习 D：Decimate
1. 添加一个 UV 球，分段 64（高精度）
2. 加 Decimate 修改器
3. 比例从 1 调到 0.1
4. 看状态栏面数减少

### 练习 E：全局倒角
1. 立方体
2. 加倒角修改器
3. 宽度 0.02，段数 2，限制=角度 30°
4. 所有边自动微倒角
