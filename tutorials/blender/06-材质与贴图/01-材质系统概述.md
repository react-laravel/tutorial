# 6.1 材质系统概述

> 你已经会做模型了，但它们都是灰色的。本章让模型"穿上衣服"——学习 Blender 的材质和贴图系统。

---

## 一、材质是什么

**材质（Material）**：描述一个物体"**如何与光线交互**"的数据集合。

它决定物体的：
- 颜色（基础色）
- 金属性
- 粗糙度（光滑还是磨砂）
- 透明度
- 发光
- 凹凸细节
- ......

材质不是贴图，但材质可以使用贴图。

---

## 二、基于物理的渲染（PBR）

Blender 5.x 使用**基于物理的渲染（PBR）** 理念。核心思想是：材质参数尽量符合真实世界的物理规律，这样光照起来更自然。

### PBR 的关键参数

- **基础色（Base Color）**：固有色，不受光照影响
- **金属度（Metallic）**：是金属还是非金属（二元）
- **粗糙度（Roughness）**：表面微观凹凸，决定高光锐利还是模糊
- **IOR（折射率）**：透明物体的折射强度
- **法线（Normal）**：表面的虚拟凹凸

**PBR 的最大好处**：在不同光照下都能看起来正确。而老式的"非 PBR"材质需要针对不同场景调不同参数。

---

## 三、材质的层级结构

在 Blender 里，材质附在物体上分几个层级：

```
物体
└─ 材质槽（Material Slot）
   └─ 材质（Material）
      └─ 着色节点树（Shader Node Tree）
         └─ 节点们（基础 BSDF + 贴图 + 数学...）
```

### 材质槽

一个物体可以有**多个材质槽**——不同的面可以用不同的材质。比如一辆车：车漆、玻璃、轮胎各是一个材质槽。

### 材质本身

一个材质槽指向一个材质。同一个材质可以被多个物体共享（节省工作量）。

### 节点树

材质的实际定义是一个**节点图**——由输入节点、逻辑节点、输出节点组成。节点可以是简单的常数，也可以是复杂的数学运算。

---

## 四、打开材质属性

1. 选中物体
2. 属性编辑器 → 点**红白球图标** 🔴
3. 看到材质属性面板

### 第一次添加材质

面板最上方有 "+ 新建" 按钮。点它会：
1. 创建一个新材质
2. 分配给当前物体
3. 默认加入一个 **Principled BSDF** 节点作为起点

---

## 五、材质槽界面

材质属性面板顶部有一个列表，显示所有材质槽。

### 关键按钮

- **+ 号**：添加新材质槽
- **- 号**：删除选中槽
- **⋮ 菜单**：复制、粘贴、全部链接等
- **分配（Assign）**：把选中槽的材质分配给编辑模式下选中的面
- **选择（Select）**：选中所有使用这个材质槽的面

### 分配多个材质

流程：

1. 添加第一个材质槽，创建材质 A
2. 再按 + 添加第二个槽，创建材质 B
3. 进入编辑模式，面模式
4. 选中你想用 B 的面
5. 点击材质槽列表里选中 B
6. 点 "分配（Assign）" 按钮
7. 这些面变成了 B 材质

## 六、材质预览模式

要看到材质效果，需要把 3D 视图切换到**材质预览**或**渲染**模式。

3D 视图右上角 4 个小球图标：

| 图标 | 模式 | 说明 |
|---|---|---|
| 线框 | Wireframe | 只看线框 |
| 实体 | Solid | 默认，灰色填充 |
| 材质预览 | Material Preview | **看材质** |
| 渲染 | Rendered | 最终渲染效果 |

快捷键 `Z` 弹出饼菜单可以快速切换。

### 材质预览 vs 渲染预览

- **材质预览**：使用内置 HDRI 环境光，快速、粗略展示材质
- **渲染预览**：使用当前场景的灯光/环境，实时路径追踪（或 EEVEE Next 实时）

新手通常用**材质预览**调材质，因为它不受场景灯光影响，更稳定。

---

## 七、材质的命名

默认命名是 `Material`、`Material.001` 等。一定要**重命名**：

- 点材质名字区域 → 双击 → 输入新名
- 建议命名：`M_木头_深色`、`M_金属_拉丝`、`M_玻璃_透明`

---

## 八、材质的共享与链接

### 共享材质

多个物体使用**同一个材质**的好处：
- 只要改一次，所有用的物体都更新
- 节省内存和文件大小

设置：
1. 选中要接收材质的物体
2. 材质属性 → 点材质下拉 → 选已有的材质

### 令单一化（Make Single User）

如果你想让一个材质"断开"共享，变成独立的：
- 点材质旁边的"数字"（表示被多少用户共享）
- 或者菜单 → 对象 → 关系 → 令单一化 → 材质

---

## 九、材质 vs 纹理 vs 贴图

这三个概念容易混：

- **材质（Material）**：整个"怎么渲染"的定义
- **纹理（Texture）**：一种图像/程序化数据源
- **贴图（Map）**：通常指一张具体的位图图像

简单说：**材质可以包含多个纹理，一张贴图是一种纹理**。

---

## 十、复制材质到其他物体

### 方法 1：Ctrl + L 链接

选择多个物体，最后选中有材质的源物体（激活），按 `Ctrl + L` → 链接材质。

所有选中物体使用源物体的材质。

### 方法 2：在材质列表里选

给新物体添加槽，从下拉里选已有的材质。

---

## 十一、删除未使用的材质

场景里有很多"孤儿材质"（没人用）？

菜单 `文件 → 清理 → 未使用数据块` → 清理。

---

## 十二、材质工作流推荐

### 新手阶段

1. 所有物体都用**单一 Principled BSDF**
2. 调基础色、金属度、粗糙度
3. 不碰节点编辑器

### 熟练后

1. 基础色换成图像纹理
2. 添加法线贴图、粗糙度贴图
3. 用节点组合复杂效果

### 进阶

1. 程序化纹理（用节点生成图案）
2. 复杂节点逻辑（混合、遮罩、投影）
3. 着色组和节点组

## 动手练习 6.1

### 练习 A：第一个材质
1. 默认立方体
2. 切到 3D 视图的**材质预览**模式（右上角 4 球图标第 3 个）
3. 材质属性 → 点"+ 新建"
4. 立方体变成灰白色（默认材质）
5. 展开"**表面**" → 基础色 → 改成红色
6. 立方体变红

### 练习 B：多材质槽
1. 同一个立方体，`Tab` 进入编辑模式
2. 材质属性 → 再点 + 添加第二个槽 → 新建 → 改成绿色
3. 面模式选 3 个面
4. 列表里选第二个槽 → 点"分配"
5. 这 3 个面变绿，其他还红
6. `Tab` 退出查看

### 练习 C：材质共享
1. 添加第二个立方体
2. 材质属性 → 下拉里选第一个物体的红材质
3. 两个立方体共享同一个材质
4. 改材质颜色，两个同时变

### 练习 D：重命名
1. 双击红材质名字 → 改为 `M_红色基础`
2. 双击绿材质 → `M_绿色点缀`

### 练习 E：预览模式切换
1. 按 `Z` 弹出饼菜单
2. 选 "材质预览" → 看材质
3. `Z` → "实体" → 灰色
4. `Z` → "渲染" → 实时渲染（如果场景有灯）
