# 6.4 UV 展开入门

> 想给模型贴图？你必须先"展开 UV"——把 3D 表面摊平到一张 2D 图上。UV 展开是建模里最让新手困惑的话题之一，本节帮你破除迷雾。

---

## 一、UV 是什么

想象你有一个纸盒子。如果你把胶水撕开，把它**摊平**在桌上，你会得到一个十字形的平面——这就是纸盒子的"**展开图**"。

**UV** 就是 3D 模型的展开图。
- **U** 和 **V** 是 2D 坐标，类似 X 和 Y（用 U/V 是为了不和 3D 的 X/Y/Z 混淆）
- UV 空间是一个 `0-1` 的正方形
- 模型上每个顶点有一个对应的 UV 坐标

有了 UV，你就可以把一张 2D 图片"**映射**"到 3D 表面。

---

## 二、为什么要 UV 展开

贴图是 2D 的，模型是 3D 的。不展开 UV，Blender 就不知道图片的哪一部分对应模型的哪一部分。

---

## 三、打开 UV 编辑器

### 方法 1：切到 UV 编辑工作区

顶部标签点 **"UV 编辑"** → 屏幕左半变成 UV 编辑器，右半是 3D 视图。

### 方法 2：手动分屏

在任意编辑器左上角切换到 **UV 编辑器**。

---

## 四、默认物体的 UV

Blender 里创建的基础网格（立方体、球、柱）已经有**默认 UV**。不用你手动展，Blender 自动做好了。

### 查看默认 UV

1. 选中一个立方体
2. `Tab` 进入编辑模式
3. `A` 全选所有面
4. 切到 UV 编辑工作区
5. 左侧 UV 编辑器显示默认 UV 布局

---

## 五、UV 展开的基本流程

对于自己建的模型（不是内置的），你需要**手动展 UV**：

1. 进入编辑模式
2. **标记接缝**：选中一些边作为"剪刀线"
3. `A` 全选所有面
4. `U` 弹出展开菜单 → **展开**
5. 在 UV 编辑器查看结果，可能需要调整

---

## 六、标记接缝（Mark Seam）

### 什么是接缝

想象要把一个立方体摊平。你必须先用剪刀剪开某些边——这些"剪刀线"就是接缝。

### 操作

1. 编辑模式，边模式
2. 选择要作为接缝的边
3. 菜单 `边 → 标记缝合边`
4. 接缝变成**红色**

### 清除接缝

- 选中边 → `边 → 清除缝合边`

### 接缝原则

- 把接缝藏在视觉不明显的地方（背面、内侧）
- 复杂物体要切够多的接缝，避免 UV 拉伸
- 简单物体少切接缝，保持 UV 完整

---

## 七、展开方式（U 键菜单）

进入编辑模式，按 `U` 弹出菜单：

| 方式 | 说明 |
|---|---|
| **展开（Unwrap）** | **最常用**，遵循接缝的算法展开 |
| **智能 UV 映射** | 算法自动选接缝并展开 |
| **灯泡投影** | 球面投影 |
| **圆柱投影** | 柱面投影 |
| **立方投影** | 6 面分开投影 |
| **从视图投影** | 按当前视角投影 |
| **重置** | UV 还原成每面一个正方形 |

### 展开（Unwrap）

最重要的一个。算法：
1. 读取你标记的接缝
2. 沿接缝"剪开"几何
3. 把各个 UV 岛屿摊平到 0–1 空间
4. 尝试保持面积比例

### 智能 UV 映射

对规则形状很好用。菜单会弹出一个参数面板：

- **角度限制**：相邻角度 > 此值才切开（默认 66°）
- **边距**：UV 岛屿之间的间隔

适合快速处理硬表面物体，不用手动标接缝。

---

## 八、UV 编辑器里的操作

UV 展开后，在 UV 编辑器里可以手动调整：

- **G** 移动
- **R** 旋转
- **S** 缩放
- **A** 全选
- **B** 框选
- **L** 选中 UV 岛屿

和 3D 视图的操作几乎一致。

### 常见调整

- 重叠的 UV → 手动分开
- 某些岛屿变形 → 手动重排
- 让重要部分占据更大的 UV 空间（提高贴图分辨率）

---

## 九、棋盘格检查（Test Grid）

UV 是否变形？用**棋盘格贴图**测试。

### 步骤

1. 给物体一个材质
2. 材质里添加图像纹理节点
3. 点"新建"，选择"**UV 栅格**"或"颜色栅格"
4. 把图像连到 BSDF 的基础色
5. 3D 视图切到材质预览

现在物体表面有棋盘格。**观察**：

- 方格**均匀** → UV 好
- 方格**扁平或拉长** → UV 有拉伸
- 方格**重叠** → UV 叠在一起

---

## 十、常见展开流程

### 立方体

已经自动展开了，不用做。

### 球体

1. 编辑模式
2. `A` 全选
3. `U` → 展开（或球面投影）

### 柱体

1. 选侧面一条竖边
2. 标记接缝
3. `A` → `U` → 展开

### 人物

复杂得多，通常需要：
- 头部切一圈
- 躯干前后各一个接缝
- 四肢各一条
- 手/脚单独处理

---

## 十一、UV 岛屿

展开后，UV 会被分成若干**独立的区块**，每一块叫一个"**UV 岛屿**"。

### 选岛

- `L` 悬停某个岛点 `L` 选整个岛
- 或者用 `Alt + 左键` 点边界

### 打包岛屿

菜单 `UV → 打包岛屿`：自动把所有岛屿塞进 0–1 空间，最大化利用。

参数：
- **边距（Margin）**：岛屿之间的最小距离
- **旋转**：允许旋转以节省空间

---

## 十二、UV 布局导出

如果你想用外部软件（Photoshop、Substance Painter）画贴图：

菜单 `UV → 导出 UV 布局` → 保存为 PNG 或 SVG。

你会得到一张空白的 UV 展开图，可以在 PS 里按照这个布局画贴图。

---

## 十三、UV 的尺寸问题

UV 是从 0 到 1 的空间，不管你贴图是 512x512 还是 4096x4096。

- 想要贴图细节多的部分 → UV 占更多面积
- 背面/不显眼处 → UV 占更少面积

### 自动根据面积调整

菜单 `UV → 平均岛屿比例`：让 UV 岛屿的大小和 3D 面积成正比，避免某些部分拉伸。

---

## 十四、紧贴边距（Pack Islands）

让 UV 岛屿紧凑排列：

菜单 `UV → 打包岛屿`（快捷键在某些版本中是 `Ctrl + P` 或相关）

---

## 动手练习 6.4

### 练习 A：测试立方体默认 UV
1. 默认立方体
2. 材质：添加图像纹理，新建 "UV 栅格"，连到基础色
3. 材质预览模式
4. 看 → 每个面都有一个完整的棋盘格，说明默认 UV 是每面一个完整区域

### 练习 B：手动展开立方体
1. 立方体，`Tab`
2. 边模式，选 4 条竖边（立方体的 4 条边）
3. `边 → 标记缝合边`
4. `A` → `U` → 展开
5. 切到 UV 编辑工作区看结果
6. 应该看到一个"十字形"展开

### 练习 C：智能 UV
1. 添加猴头 Suzanne
2. `Tab`，`A` 全选
3. `U` → 智能 UV 映射 → 确认
4. 看 UV 编辑器的结果——复杂但自动

### 练习 D：棋盘检查
1. 对猴头应用 UV 栅格贴图
2. 材质预览
3. 旋转观察：
   - 均匀的方格 = 好
   - 拉伸的 = 需要调整

### 练习 E：调整 UV
1. UV 编辑器里选一个岛屿 `L`
2. `G` 移动它
3. `S` 缩放它
4. 看 3D 里贴图对应位置变化

### 练习 F：立方投影
1. 一个立方体
2. `U` → 立方投影
3. 和默认 UV 对比结果
