# 6.3 节点编辑器入门

> Principled BSDF 能解决很多需求，但真正强大的是**节点系统**。节点让你像搭积木一样组合复杂效果——混合材质、程序化纹理、数学运算……

---

## 一、节点是什么

**节点（Node）**：一个"功能方块"，有输入和输出。多个节点通过线连接，组成数据流——这叫**节点图（Node Graph）**。

---

## 二、打开节点编辑器

有两种方式：

### 方法 1：切到着色工作区

顶部标签点 **"着色（Shading）"** → 下半部分自动变成节点编辑器。

### 方法 2：手动改编辑器类型

任意编辑器左上角的图标 → 切换为 **Shader 编辑器**。

---

## 三、认识 Shader 编辑器

打开后会看到两个默认节点：

```
[Principled BSDF]  →  [材质输出]
```

- **Principled BSDF**：你之前用的"万能材质"的本体
- **材质输出**：最终结果，把 BSDF 的输出连到这里才会生效

### 连线

每个节点左侧是**输入**（圆圈），右侧是**输出**（圆圈）。拖动一个输出到另一个输入 → 创建连线。

### 断开连线

- 按住 `Ctrl` + 左键拖动画过一条线 → 切断
- 或者拉着线把它拖回"空"位置

---

## 四、节点编辑器的操作

基本和 3D 视图类似：

| 操作 | 快捷键 |
|---|---|
| 平移 | 中键拖动 |
| 缩放 | 滚轮 |
| 选中节点 | 左键 |
| 移动节点 | `G` |
| 复制节点 | `Shift + D` |
| 删除节点 | `X` |
| 添加节点 | `Shift + A` |
| 全选 | `A` |
| 框选 | `B` |
| 对齐到选中节点 | `Num .` |

---

## 五、Shift + A 添加节点菜单

按 `Shift + A` 弹出菜单，分类如下：

| 分类 | 包含 |
|---|---|
| **输入（Input）** | 几何体、纹理坐标、颜色常数、数学常数 |
| **输出（Output）** | 材质输出、灯光输出、AOV |
| **着色器（Shader）** | Principled BSDF、漫反射、光泽、发射、混合... |
| **纹理（Texture）** | 图像纹理、噪波、砖块、棋盘、渐变... |
| **颜色（Color）** | 混合、变亮、反转、HSV... |
| **矢量（Vector）** | 凹凸、法线贴图、映射、变换 |
| **转换器（Converter）** | 颜色转灰度、数学、组合/分离... |
| **脚本（Script）** | OSL 脚本 |
| **组（Group）** | 自定义节点组 |

---

## 六、六大核心节点类型

### 1. Principled BSDF

万能着色器。已经讲过。

### 2. 图像纹理（Image Texture）

读取一张图片作为输入数据。

- **颜色输出**：图像的 RGB 数据
- **Alpha 输出**：图像的透明通道

### 3. 纹理坐标（Texture Coordinate）

告诉纹理"如何贴"到模型上。

- **UV**：使用模型的 UV 展开（推荐）
- **生成的**：自动按包围盒生成（适合临时测试）
- **物体**：按物体空间
- **相机**：按相机空间
- **窗口**：按屏幕空间
- **反射**：按反射方向（做镜面贴图）

### 4. 映射（Mapping）

调整 UV 的缩放、偏移、旋转。

- **位置**：UV 在 X/Y 方向的移动
- **旋转**：UV 旋转
- **缩放**：UV 拉伸（> 1 = 缩小纹理，< 1 = 放大纹理）

### 5. 材质输出（Material Output）

节点图的终点。连到它的内容就是最终显示的材质。

### 6. 混合着色器（Mix Shader）

把两个着色器按比例混合。

- **因子（Fac）**：0 完全用第一个，1 完全用第二个

---

## 七、最经典的节点流

### 流 1：用一张图做基础色

```
纹理坐标 → 映射 → 图像纹理 → Principled BSDF (基础色)
```

这是最基本的"贴图应用"。

### 流 2：贴图 + 粗糙度贴图

```
纹理坐标 → 映射 ┬→ 图像纹理 1 (彩图) → Principled (基础色)
                 └→ 图像纹理 2 (粗糙度图) → Principled (粗糙度)
```

### 流 3：法线贴图

```
图像纹理 (法线图) → 法线贴图节点 → Principled (法线)
```

法线贴图需要经过"**法线贴图**"节点转换一次才能用。

---

## 八、Node Wrangler 插件

**Node Wrangler** 是一个内置插件（偏好设置启用），大幅提升节点编辑效率。

### 启用

偏好设置 → 插件 → 搜索 "Node Wrangler" → 勾选

### 关键快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Shift + T` | **一键导入 PBR 贴图**（这是神器） |
| `Ctrl + T` | 添加"纹理坐标 + 映射 + 图像纹理"三件套 |
| `Ctrl + Shift + 左键点节点` | 连到材质输出预览（查看中间结果） |
| `Shift + 拖动两个节点` | 混合它们 |

### Ctrl + Shift + T 用法

1. 选中 Principled BSDF 节点
2. `Ctrl + Shift + T`
3. 弹出文件浏览器
4. 选中一组 PBR 贴图（通常是 basecolor.png + normal.png + roughness.png + metallic.png...）
5. Node Wrangler 自动识别类型并连好

这比手动加节点快 10 倍。

### Ctrl + T 用法

1. 选中 Image Texture 节点
2. `Ctrl + T`
3. 自动添加 Texture Coordinate + Mapping 并连好

---

## 九、节点预览

在节点编辑器的顶部工具栏，或右键菜单，可以开启**"预览"模式**——每个节点旁边显示它输出的结果小图。

对于复杂图形，预览非常有用。

---

## 十、分组节点

选中几个节点，按 `Ctrl + G` → 打包成一个**节点组**。节点组有自己的输入和输出，可以像函数一样复用。

- 进入组：`Tab`
- 退出组：`Tab`

---

## 十一、数学节点

**矢量 → 数学**、**转换器 → 数学** 提供各种数学运算：

- 加减乘除
- 最大值/最小值
- 幂、对数、正弦
- 取模、绝对值
- ...

数学节点是实现复杂程序化效果的基础。

---

## 十二、颜色节点

- **Mix RGB**：混合两种颜色（或两张贴图）
- **亮度 / 对比度**：调整亮度
- **色相 / 饱和度**：调整 HSV
- **反转**：反色
- **渐变**：颜色分布映射

---

## 十三、节点图的组织

当节点变多时：

### 框架（Frame）
选中节点按 `Ctrl + J` 打包进一个框架，加标签。

### 重排版
- `G` 移动
- 边对齐手动
- 保持输入在左、输出在右

### 注释
框架可以改颜色和加标签，方便区分。

---

## 十四、常见节点组合示例

### 1. 砖墙

```
纹理坐标 → 映射 → 砖块纹理 → Principled (基础色)
```

Blender 内置 "砖块纹理" 节点可以直接生成砖块图案。

### 2. 噪波 + 颜色渐变

```
纹理坐标 → 噪波纹理 → 颜色渐变 → Principled (基础色)
```

做大理石、烟雾效果。

### 3. 金属 + 锈迹

```
图像纹理 (锈蚀遮罩) ┬→ 混合 RGB ← 金属色
                    │     ↓
                    └→ 混合 RGB ← 锈色
                          ↓
                     Principled (基础色)
```

这种节点组合让金属和锈共存。

## 动手练习 6.3

### 练习 A：认识节点
1. 默认立方体 → 新材质
2. 切到"着色"工作区
3. 看到 Principled BSDF + 材质输出 两个节点
4. 按 `G` 移动节点位置
5. 按 `Shift + A` 添加一个噪波纹理
6. 把噪波的颜色输出连到 BSDF 的基础色
7. 看立方体变成噪点图案

### 练习 B：混合两个着色器
1. 清空节点，只留输出
2. `Shift + A` → 着色器 → Principled BSDF（红色）
3. `Shift + A` → 着色器 → Principled BSDF（蓝色）
4. `Shift + A` → 着色器 → 混合着色器
5. 把两个 BSDF 分别连到混合的两个 Shader 输入
6. 混合输出连到材质输出
7. 调 Fac 从 0 到 1，看立方体颜色过渡

### 练习 C：Node Wrangler 基础
1. 确认已启用 Node Wrangler 插件
2. 选中 Principled BSDF
3. `Ctrl + Shift + 左键` 点击 BSDF → 它被连到材质输出
4. `Ctrl + Shift + 左键` 点击某个噪波纹理 → 输出临时替换为噪波
5. 再 `Ctrl + Shift + 左键` 点 BSDF → 恢复

### 练习 D：框架
1. 选中几个节点
2. `Ctrl + J` → 创建框架
3. 展开框架属性，改颜色和标签
