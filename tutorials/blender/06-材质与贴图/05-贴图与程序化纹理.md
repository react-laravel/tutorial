# 6.5 贴图应用与程序化纹理

> 本节讲如何在 UV 展开的基础上应用真实的贴图，以及 Blender 内置的"程序化纹理"——不需要 UV 和图片就能生成图案。

---

## 一、两种纹理来源

- **图像纹理（Image Texture）**：用一张真实图片
- **程序化纹理（Procedural Texture）**：用数学算法生成图案

两者各有优劣：

| 特性 | 图像纹理 | 程序化纹理 |
|---|---|---|
| 真实感 | 高 | 中 |
| 文件大小 | 大 | 0 |
| 分辨率限制 | 有 | 无（任意放大） |
| 编辑灵活 | 需外部软件 | 改参数即可 |
| 需要 UV | 是 | 通常不需要 |

---

## 二、图像纹理节点

### 使用流程

1. 材质 → 节点编辑器
2. `Shift + A` → 纹理 → **图像纹理**
3. 点"打开"加载一张图片
4. 连接**颜色输出**到 Principled BSDF 的基础色
5. 确认物体有正确的 UV

### 纹理坐标

默认情况下，图像纹理使用物体的 UV。如果你想用其他坐标：

1. `Shift + A` → 输入 → 纹理坐标
2. 把想用的坐标（UV / 生成的 / 物体...）连到图像纹理的 **矢量（Vector）** 输入

### 映射节点

想调整贴图的大小/位置/旋转：

1. `Shift + A` → 矢量 → **映射（Mapping）**
2. 放在纹理坐标和图像纹理之间
3. 调映射节点的"缩放"来重复贴图：缩放 = 2 → 贴图重复两次

### Node Wrangler 的快捷

选中图像纹理节点，`Ctrl + T` → 自动加上纹理坐标 + 映射并连好。

---

## 三、PBR 贴图套件

一组真实的 PBR 贴图通常包含：

| 文件 | 用途 | 连接到 |
|---|---|---|
| **basecolor.png** | 固有色 | BSDF 基础色 |
| **roughness.png** | 粗糙度 | BSDF 粗糙度 |
| **metallic.png** | 金属度 | BSDF 金属度 |
| **normal.png** | 法线贴图 | 经过法线节点 → BSDF 法线 |
| **height.png** | 高度/位移 | BSDF 位移（Cycles 才真位移） |
| **ao.png** | 环境光遮蔽 | 乘到基础色 |

### 颜色空间设置

贴图要设置正确的**颜色空间**，否则会不准：

| 贴图类型 | 颜色空间 |
|---|---|
| basecolor | **sRGB**（默认） |
| roughness | **非彩色（Non-Color）** |
| metallic | **非彩色** |
| normal | **非彩色** |
| height | **非彩色** |
| ao | 可以 sRGB 或非彩色 |

**非彩色数据**是指"这张图不是要当颜色看，而是当数据用"。

---

## 四、法线贴图连接

法线贴图不能直接连，需要经过**法线贴图节点**：

```
图像纹理 (法线图, 非彩色) → 法线贴图节点 → Principled BSDF (法线输入)
```

法线贴图节点有一个 "Space" 参数，默认 "切线空间（Tangent Space）" —— 保持默认即可。

---

## 五、Ctrl + Shift + T（神器）

回顾一下：Node Wrangler 启用后，选中 Principled BSDF 按 `Ctrl + Shift + T`，弹出文件浏览器。

选中一组 PBR 贴图（比如从 Polyhaven 下载的包）：

- `xxx_diff.png`
- `xxx_rough.png`
- `xxx_nor.png`
- `xxx_metal.png`

插件会自动：
1. 加载所有贴图
2. 识别类型（根据文件名关键词）
3. 设置正确的颜色空间
4. 连接到 BSDF 对应输入
5. 加上纹理坐标 + 映射

**这个功能节省的时间不是一点点**。

## 六、免费 PBR 贴图资源

- **Poly Haven**（polyhaven.com）：高质量 CC0 资源
- **Ambient CG**（ambientcg.com）：大量 CC0 PBR 套装
- **Texture.com**：老牌免费资源站
- **Textures for free**：综合站

下载的一套贴图解压后放到一个文件夹，就可以用 `Ctrl + Shift + T` 一键导入。

## 七、程序化纹理总览

不用 UV、不用图片，全靠算法。Blender 内置的程序化纹理节点：

### 噪波纹理（Noise）
生成无规律的噪点图案。参数：
- **比例（Scale）**：图案大小
- **细节（Detail）**：细节层数
- **粗糙度**
- **扭曲**

用途：大理石、云朵、随机表面、作为其他效果的"种子"。

### 砖块纹理（Brick）
规则砖块图案。参数：
- **色调 1/2**：砖的颜色
- **灰泥色**：缝隙颜色
- **行高 / 列宽**：砖的形状
- **偏移**：错缝

用途：墙壁、路面。

### 棋盘纹理（Checker）
棋盘格图案。只有两种颜色。

### Voronoi
随机"碎片"图案——类似被撞碎的玻璃、细胞、皮肤纹理。

### 波纹（Wave）
波浪、纹理线条。适合做木头纹、水面。

### 渐变（Gradient）
简单的渐变。常作为其他效果的"蒙版"。

### 魔法（Magic）
迷幻的抽象图案。艺术用。

---

## 八、程序化纹理示例

### 木纹

```
纹理坐标 → 映射（缩放 Z=10） → 波纹纹理 → ColorRamp → 基础色
```

ColorRamp 用于把波纹的灰度映射为深浅木色。

### 金属划痕

```
纹理坐标 → 噪波 → ColorRamp（极端对比） → 粗糙度
```

噪波作为粗糙度，让金属表面有随机磨损。

### 随机颜色变化

```
物体信息（随机输出） → ColorRamp → 基础色
```

让每个物体在阵列中有随机颜色。

---

## 九、ColorRamp（颜色渐变）

**ColorRamp 是程序化纹理的最佳拍档**。它把一个 0–1 的值映射为颜色。

### 用法

1. `Shift + A` → 转换器 → 颜色渐变
2. 把任何"值"连到它的输入（比如噪波的 Fac 输出）
3. 拖动色块调整颜色分布
4. 输出连到想要的地方

### 例子

把噪波的灰度图变成"只有两种颜色的斑点"：
- 色块 1 @ 0 位置：红色
- 色块 2 @ 0.5 位置：红色（突变）
- 色块 3 @ 0.5 位置：绿色
- 色块 4 @ 1 位置：绿色

---

## 十、MixRGB（颜色混合）

在两种颜色/纹理之间混合。

### 混合模式

- **混合（Mix）**：线性插值
- **相乘**：叠加明暗
- **加法** / **减法**
- **屏幕** / **覆盖**
- **变亮** / **变暗**

和 Photoshop 的图层混合模式类似。

### 用法示例

```
纹理 A → MixRGB ← 纹理 B
        ↓ (Fac 由遮罩控制)
      → 基础色
```

---

## 十一、凹凸 vs 法线

两种模拟凹凸的方式：

### 凹凸（Bump）

- 用灰度图，亮 = 凸，暗 = 凹
- 简单但效果弱
- 节点：`Shift + A` → 矢量 → 凹凸

```
灰度图 → 凹凸节点 → BSDF 法线
```

### 法线贴图（Normal Map）

- 用 RGB 编码的法线方向
- 效果更强更真实
- 节点：`Shift + A` → 矢量 → 法线贴图

```
法线图 → 法线贴图节点 → BSDF 法线
```

PBR 贴图套件里通常有法线图。凹凸作为备选。

---

## 十二、实战材质配方（完整节点图）

### 木地板

```
1. 加载 basecolor 贴图（sRGB） → 基础色
2. 加载 roughness 贴图（非彩色） → 粗糙度
3. 加载 normal 贴图（非彩色） → 法线贴图节点 → 法线
4. 加载 ao 贴图 → 与 basecolor 相乘 → 基础色
5. 映射节点：缩放 (2, 2, 1) 让木板重复
```

### 生锈的金属

```
1. 两份 PBR 贴图：干净金属 + 锈迹
2. 噪波作为遮罩（Fac）
3. MixRGB 混合两张 basecolor → 基础色
4. 同样混合 roughness → 粗糙度
5. 混合 normal → 法线
```

### 程序化大理石

```
1. 波纹纹理（Wave Texture）
2. 噪波（Noise）扭曲波纹的坐标
3. ColorRamp 映射成白色到灰色
4. 输出到基础色
5. 粗糙度 0.1
```

---

## 十三、烘焙贴图（预告）

把程序化材质或复杂节点图"**烘焙**"到一张实际图片上，可以：
- 导出到游戏引擎
- 简化渲染性能
- 减少材质复杂度

烘焙位置：渲染属性 → 烘焙。需要 Cycles 引擎。

新手阶段不用深入，知道有这个技术即可。

## 动手练习 6.5

### 练习 A：加载一张贴图
1. 从网上找一张无版权的木纹图
2. 立方体，新材质
3. 节点编辑器 `Shift + A` → 图像纹理 → 打开文件
4. 颜色输出连到 BSDF 基础色
5. 材质预览
6. 加一个映射节点，调缩放改变贴图密度

### 练习 B：Node Wrangler 批量
1. 从 Poly Haven 下载一套 PBR 木头贴图（diff/rough/nor/ao）
2. 放到一个文件夹
3. 物体加新材质
4. 选中 BSDF，`Ctrl + Shift + T`
5. 全选所有贴图 → 打开
6. 节点自动生成

### 练习 C：程序化木纹
1. 新材质
2. `Shift + A` → 纹理 → 波纹
3. `Shift + A` → 转换器 → 颜色渐变
4. 波纹 Fac → 渐变输入
5. 调渐变为两种木色
6. 渐变颜色 → BSDF 基础色
7. 看到程序化木纹

### 练习 D：噪波大理石
1. 新材质
2. `Shift + A` → 噪波纹理，细节调到 15
3. `Shift + A` → 颜色渐变
4. 噪波 Fac → 渐变
5. 调渐变为灰色到白色
6. 输出到基础色，粗糙度 0.1
7. 大理石效果完成

### 练习 E：凹凸
1. 先完成练习 C 的木纹
2. `Shift + A` → 矢量 → 凹凸
3. 波纹的 Fac → 凹凸的 Height
4. 凹凸的 Normal 输出 → BSDF 法线
5. 渲染预览看凹凸细节
