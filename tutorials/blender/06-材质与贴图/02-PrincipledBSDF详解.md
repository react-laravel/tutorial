# 6.2 Principled BSDF 逐参数详解

> **Principled BSDF（原理化 BSDF）** 是 Blender 的"万能材质"。99% 的真实世界材质都可以用它调出来。本节把每个参数讲清楚。

---

## 一、什么是 Principled BSDF

**BSDF**：双向散射分布函数（Bidirectional Scattering Distribution Function）。一个数学模型，描述光线如何和表面交互。

**Principled BSDF**：迪士尼在 2012 年提出的 Principled BRDF 模型的 Blender 版本。它把多个 BSDF 组合成一个"大而全"的材质节点，参数直观、易用、物理合理。

---

## 二、Principled BSDF 的参数分类

Blender 5.x 的 Principled BSDF 把参数分成几组：

### 基础（Base）
- 基础色、金属度、粗糙度、IOR、Alpha

### 次表面（Subsurface）
- 用于皮肤、蜡、玉等半透明物体

### 金属（Metallic）
- 金属专用的边缘色调

### 镜面（Specular）
- 非金属的反光细节

### 传输（Transmission）
- 玻璃、水等透明物体

### 涂层（Coat）
- 清漆层（车漆、指甲油）

### 光泽（Sheen）
- 绒面效果（布料、尘埃）

### 自发光（Emission）
- 物体自己发光

---

## 三、基础色（Base Color）

物体的固有颜色。

### 正确用法

- **日常物体**：选中度饱和度的颜色
- **纯白**：避免（基本没有纯白物体）
- **纯黑**：避免（黑色物体也有 5% 左右的反射）
- **金属**：金属的基础色应该接近"金属本身的色调"（金、铜、铝）

### 颜色选择建议

| 材质 | 推荐基础色（HEX） |
|---|---|
| 白墙 | #E0E0E0（不是纯白） |
| 深色木头 | #5A3A1F |
| 浅色木头 | #B08050 |
| 金 | #FFD700 |
| 铜 | #B87333 |
| 铝 | #C0C0C0 |
| 钢 | #8C8C8C |
| 皮肤（亚洲人） | #D4A878 |
| 叶子（绿植） | #3A5F2E |

---

## 四、金属度（Metallic）

**二元概念**：一个材质要么是金属（1），要么不是（0）。

### 为什么不能是 0.5？

真实世界没有"半金属"。0.5 在物理上没有意义。**要么 0 要么 1**。

### 例外
- 铁锈：可以用 0.3–0.7 模拟（因为锈是非金属覆盖金属）
- 但这种情况应该用纹理遮罩，而不是统一值

### 金属和非金属的视觉区别

- **非金属（0）**：高光是白色（反射环境光的颜色），漫反射是基础色
- **金属（1）**：高光带基础色（金色金属的高光偏金），没有漫反射

---

## 五、粗糙度（Roughness）

表面的**微观不平度**。

### 数值含义

- **0**：镜面，完美反射（镜子）
- **0.1**：高度抛光（抛光金属、光滑玻璃）
- **0.3**：轻度磨砂（哑光塑料）
- **0.5**：磨砂（砂纸）
- **0.7**：很粗糙（布料、粗水泥）
- **1**：完全无反射（粉笔、极度磨砂）

### 影响什么

- 0：高光是一个锐利的点
- 0.5：高光是一个模糊的大区域
- 1：几乎看不到高光

### 真实世界参考

| 物体 | 粗糙度 |
|---|---|
| 镜子 | 0 |
| 抛光大理石 | 0.05 |
| 新地板蜡 | 0.1 |
| 塑料按键 | 0.3 |
| 皮革 | 0.5 |
| 磨砂木头 | 0.7 |
| 水泥 | 0.9 |

---

## 六、IOR（折射率）

**折射率（Index of Refraction）**：光通过物体时的偏折程度。

### 常用值

| 物体 | IOR |
|---|---|
| 空气 | 1.0 |
| 冰 | 1.31 |
| 水 | 1.33 |
| 酒精 | 1.36 |
| 塑料 | 1.45 |
| 玻璃 | 1.5 |
| 水晶 | 1.55 |
| 玉 | 1.6 |
| 蓝宝石 | 1.77 |
| 钻石 | 2.42 |

**非金属材质都有一个 IOR**。Blender 默认是 1.45（塑料/皮肤的平均值）。

对非透明物体，IOR 主要影响**边缘的反光强度**——较高的 IOR 让斜视角的反光更强。

---

## 七、Alpha（透明度）

- **1** = 完全不透明
- **0** = 完全透明

单独调 Alpha 会让整个物体半透明（像玻璃）。但真正的玻璃不用 Alpha，用**传输**。

### Alpha 的典型用途

- 带孔的叶子（结合贴图，叶子形状部分 alpha=1，外部 alpha=0）
- 镂空图案（网布、栅栏）

### 渲染设置要求

使用 Alpha 时需要在材质属性里设置：
- **混合模式（Blend Mode）** → Alpha 混合 / Alpha 剪切

---

## 八、次表面散射（Subsurface Scattering, SSS）

光进入物体后在内部散射再出来。

### 典型 SSS 材质

- **皮肤**：耳朵背光时透光的红色
- **蜡烛 / 肥皂**
- **玉 / 大理石**
- **叶子背光时的半透**
- **牛奶 / 果冻**

### 参数

- **权重（Weight）**：SSS 的强度（0~1）
- **半径（Radius）**：RGB 三个通道散射的距离（皮肤的红通道大）
- **比例（Scale）**：总体散射距离

### 皮肤示例值

- 权重：0.2
- 半径：(1.0, 0.2, 0.1) — 红比绿蓝更远
- 比例：0.002

---

## 九、传输（Transmission）

真正的透明物体（玻璃、水、钻石）。

### 参数

- **权重（Weight）**：透明的比例，0=不透明，1=全透
- 配合 IOR 使用

### 做玻璃

```
基础色：#FFFFFF（略带蓝或绿）
金属度：0
粗糙度：0（镜面）
IOR：1.5
传输：1.0
```

### 做水

```
基础色：#FFFFFF
金属度：0
粗糙度：0
IOR：1.33
传输：1.0
```

### 做毛玻璃

```
传输：1.0
粗糙度：0.3（提高粗糙度让透视模糊）
```

---

## 十、涂层（Coat）

模拟**透明清漆层**——比如车漆上覆盖的清漆、指甲油。

### 参数

- **权重**：清漆层强度
- **粗糙度**：清漆本身的粗糙度
- **IOR**：清漆的折射率（通常 1.5）
- **色调**：清漆带的淡色

### 用法

主体是磨砂塑料 + 清漆 = 车漆光泽感。

---

## 十一、光泽（Sheen）

表面的**边缘柔光**——布料、灰尘、天鹅绒的特征。

### 参数

- **权重**：光泽强度
- **粗糙度**：光泽的分布
- **色调**：光泽带的颜色

### 用法

做布料时权重 0.5 左右，让边缘有一圈柔和的反光。

---

## 十二、自发光（Emission）

让物体**自己发光**。

### 参数

- **颜色（Color）**：发光颜色
- **强度（Strength）**：发光亮度（0~1000+）

### 用法

- **屏幕/霓虹灯**：颜色饱和，强度 2–10
- **灯泡内部**：颜色暖黄，强度 50–100
- **假太阳**：颜色白黄，强度 500+

自发光物体在 EEVEE 和 Cycles 都可以作为光源（需要 Cycles 的"发光"功能开启）。

---

## 动手练习 6.2

### 练习 A：金属度 0 vs 1 对比
1. 两个立方体并排
2. 给两个加相同的红色基础材质
3. 一个金属度 0，一个金属度 1
4. 看差异——金属的高光是红色，非金属的高光是白色

### 练习 B：粗糙度扫描
1. 排列 5 个球
2. 分别给粗糙度 0、0.25、0.5、0.75、1
3. 材质预览模式
4. 观察高光从锐利到模糊到消失的过程

### 练习 C：做一个玻璃杯
1. 添加经纬球，`S Z 1.5` 拉长
2. 新材质：
   - 传输 1
   - 粗糙度 0.05
   - IOR 1.5
3. 背景换成有环境贴图的 → 看到折射效果

### 练习 D：自发光
1. 立方体 → 材质
2. 展开发射，颜色选蓝色，强度 5
3. 渲染预览模式
4. 看到立方体像灯一样亮着

### 练习 E：配方练习
1. 建 6 个球，每个用一个不同的配方（金、木头、塑料、玻璃、橡胶、陶瓷）
2. 对比它们的视觉差异
