# 9.1 实战一：马克杯

> 这是你的第一个完整作品。马克杯难度适中，涵盖：添加物体、修改器、基础材质、布光、渲染。全程约 30 分钟。

---

## 一、成品预览

我们要做的是：
- 一个陶瓷马克杯（圆柱体 + 手柄）
- 放在一个平面桌上
- 面光照明
- EEVEE Next 出图

---

## 二、准备场景

### 清空默认场景

1. 新建文件 `File → New → General`
2. 选中默认立方体 `X` 删除
3. 保留默认灯和相机（稍后调）

### 设置单位

1. 属性编辑器 → 场景属性
2. 单位 = 公制
3. 长度 = 厘米

马克杯高度大约 10 cm。

---

## 三、建模：杯身

### 步骤 1：添加圆柱并调整尺寸

1. `Shift + A` → 网格 → 圆柱（默认参数即可）
2. 用 `S` 缩放到大致合适的大小（杯子半径约 4 cm，高约 10 cm）
3. 具体做法：`S Shift+Z 0.4` 回车（XY 方向缩小），再 `S Z 0.5` 回车（Z 方向调高度）
4. 也可以在侧栏 `N` → 项目 → 尺寸里直接输入数值

### 步骤 2：删除顶面

1. `Tab` 进入编辑模式
2. `3` 面选择模式
3. 选中顶面（杯口朝上的那个圆面）
4. `X` → 面

### 步骤 3：挖空内部

1. `2` 边选择模式
2. `Alt + 左键` 点击顶部边缘 → 选中顶部循环边
3. `E` 挤出 → `S` 缩放到 0.9 左右 → 回车（生成杯壁内圈）
4. `E` 再挤出 → `Z` → 往下约 `-9`（cm）→ 回车（生成杯壁内壁）

现在杯子内部有一个凹陷。

### 步骤 4：底部加厚

底部留一些厚度（约 0.5–1 cm），不要戳穿。

查看底部：`Num 1` 前视图 → 看杯壁内部是否够厚。

---

## 四、建模：手柄

### 步骤 1：回到物体模式

`Tab` 回到物体模式。

### 步骤 2：添加圆环

1. `Shift + A` → 网格 → 圆环（默认参数）
2. 用 `S` 缩放到合适大小（手柄的整体大小约为杯身的一半）

### 步骤 3：调整手柄位置和朝向

1. `R X 90`（让手柄立起来）
2. `G X 0.05`（移到杯子侧面）
3. 高度合适为止

### 步骤 4：缩放椭圆

手柄不是正圆：
1. `Tab` 编辑模式
2. `A` 全选
3. `S Z 0.7` 压扁一点

### 步骤 5：手柄融入杯身（布尔或手动）

**简单做法**：直接摆，手柄和杯身交叉但是不合并。视觉上看不出来。

**进阶做法**：
1. 选手柄 → 添加布尔修改器 → 并集 → 对象选杯身
2. 应用修改器
3. 合并顶点

新手先用简单做法。

---

## 五、建模：平滑

### 自动平滑

1. 选中杯身（回到物体模式）
2. `右键` → **着色 Smooth by Angle**（Blender 5.x）
3. 默认角度 30°
4. 曲面变平滑，边缘保留锐度

对手柄做同样操作。

### 添加细分表面

1. 选杯身
2. 属性编辑器 → 修改器 → 添加修改器 → **细分表面**
3. 视图级别 2，渲染级别 2
4. 杯子变得更圆润

同样对手柄。

---

## 六、建模：桌面

1. `Shift + A` → 网格 → 平面
2. `S 0.5`（缩小到 50 cm）
3. `G Z -0.05`（如果杯子底部不是 0，调整到平面贴紧杯底）

杯子应该站在桌面上。

---

## 七、材质：杯子（陶瓷）

### 添加材质

1. 选杯身
2. 属性编辑器 → 材质（红球图标）
3. **新建** → 命名为 "Ceramic"

### 调参数

Principled BSDF：
- **基础色**：白色或淡色
- **金属度**：0
- **粗糙度**：0.3
- **IOR**：1.45

渲染预览模式看效果。

### 同一材质给手柄

1. 选手柄
2. 材质 → **浏览材质**（小球图标）→ 选择 "Ceramic"
3. 手柄和杯身用同一个材质

---

## 八、材质：桌面

1. 选平面
2. 新材质 → 命名 "Table"
3. 基础色：深棕色（像木头）
4. 粗糙度：0.6

想更真实可以加木纹 PBR 贴图（参考 6.5）。

---

## 九、布光

### 删除默认灯

选默认 Point Light → `X`。

### 添加面光作为主光

1. `Shift + A` → 灯光 → 面光
2. 位置：`(2, -2, 3)`
3. 旋转：让它指向杯子（选灯再 Shift 点杯子 → `Ctrl + Shift + C` → 阻尼跟踪）
4. 尺寸：1.5 m
5. 能量：300 W
6. 颜色：暖白

### 添加辅光

1. `Shift + A` → 面光
2. 位置：`(-2, -1, 2)`
3. 指向杯子
4. 尺寸：2 m
5. 能量：80 W
6. 颜色：淡蓝

### 环境光

1. 世界属性 → 颜色 → 灰色
2. 强度 0.3

提供基础亮度。

---

## 十、相机

1. 选相机
2. 位置：`(0.3, -0.3, 0.15)`
3. `Num 0` 进入相机视图
4. `N` → 视图 → 勾选"相机到视图"
5. 中键调整让杯子居中偏一点（应用三分法）
6. 取消勾选

### 相机参数

- 焦距：50 mm
- 景深：不开（简单场景）

---

## 十一、渲染设置

### 引擎

渲染属性 → EEVEE Next。

### 采样

- 视口 16
- 渲染 64

### 颜色管理

- 视图变换：**AgX**
- 看点：Base Contrast

### 输出

- 分辨率：1920 × 1080
- 格式：PNG
- 路径：`//mug_render.png`

---

## 十二、渲染与调整

1. `F12` 渲染
2. 看结果
3. 不满意的地方：
   - 太暗？主光 +100
   - 太亮？主光 -100
   - 杯子偏了？调相机
   - 材质太亮？降低粗糙度

反复微调。

---

## 十三、保存

1. `Ctrl + S` 保存 .blend 文件
2. 渲染窗口 `Alt + S` 保存 PNG

---

## 十四、扩展：给杯子加细节

### 杯口的内壁

1. 编辑模式
2. 选杯口内圈的边
3. 倒角 `Ctrl + B` 加一点圆角
4. 增强真实感

### 杯底的商标

1. 在平面上加一个小字（`Shift + A` → 文本）
2. 贴到杯底

### 杯子里装液体

1. 在杯子内部加一个圆柱
2. 调整高度（模拟液面）
3. 材质：棕色 + 透射 0.9（咖啡）

---

## 动手练习 9.1

整个本节就是一个大练习！完成后挑战：

1. 换一个陶瓷颜色（蓝色、红色）
2. 把杯子放在木纹桌面上（加 PBR 木纹贴图）
3. 换一个相机角度（俯视 45°）
4. 增加景深让背景虚化
