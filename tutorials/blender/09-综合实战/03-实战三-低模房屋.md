# 9.3 实战三：低模房屋

> 本章最大的综合实战。涉及：场景组织、布尔、集合、多材质、三点布光、Cycles 出图。全程约 2 小时。

---

## 一、成品预览

一栋低模风格的小房子：
- 墙体（带窗户和门洞）
- 坡屋顶
- 烟囱
- 门和窗户
- 草地地面
- 一棵树
- 天空 HDRI
- 夕阳灯光氛围

---

## 二、低模风格的要点

**低模（Low Poly）**：

- 每个物体面数少
- 用纯色而非贴图
- 平面阴影可以，也可以用平滑
- 材质对比强烈
- 风格化、卡通

---

## 三、准备

新建场景 → 删除默认立方体 → 公制单位（米）。

---

## 四、场景组织：集合

先规划集合结构：

```
Scene
├── House（集合）
│   ├── Walls
│   ├── Roof
│   ├── Door
│   ├── Windows
│   └── Chimney
├── Environment（集合）
│   ├── Ground
│   ├── Tree
│   └── Rocks
├── Lights（集合）
│   └── Sun
└── Camera
```

### 创建集合

1. 大纲视图 → 右键 Scene → New Collection
2. 命名 "House"
3. 同样创建 "Environment"、"Lights"

---

## 五、建模：墙体

### 步骤 1：基础立方体

1. `Shift + A` → 立方体
2. 缩放到 `(2, 1.5, 1.2)`
3. `G Z 1.2`（底部在地面）
4. `Ctrl + A` → 所有变换
5. 移到 House → Walls 集合（拖拽或 `M`）

### 步骤 2：开窗户洞（布尔）

1. `Shift + A` → 立方体（这是窗户的"挖洞工具"）
2. 尺寸 `(0.1, 0.6, 0.6)`（比墙厚一点）
3. 位置：`(1.0, 0.4, 1.3)`（外凸出墙壁）
4. 回到墙壁 → 布尔修改器 → 差集 → 对象选这个立方体
5. 墙上出现洞

### 步骤 3：再开一个窗户

复制窗户挖洞工具 `Shift + D`，放到另一侧。墙布尔用这两个工具的并集，需要把两个洞工具组合：

- 简单做法：一个物体只做一个布尔洞。再加第二个布尔修改器。
- 或者先把两个挖洞工具用"联合"布尔合并成一个，再差集。

### 步骤 4：开门洞

同样方法，立方体 0.8 × 0.2 × 1.8，位置在正面。

### 步骤 5：应用布尔

1. 确认所有洞都对
2. 布尔修改器 → 应用
3. 把挖洞工具们删掉

---

## 六、建模：屋顶

坡屋顶。

### 步骤 1：基础立方体

1. `Shift + A` → 立方体
2. 位置：`(0, 0, 2.6)`（墙顶上方）
3. 缩放：`(2.2, 1.8, 0.3)`

### 步骤 2：塑形成坡顶

1. `Tab` 编辑模式
2. `2` 边选择模式
3. 选顶部两条边（分别在 Y 轴两侧）
4. `S Y 0.05` → 把它们拉近

等等，更简单的方法是：

1. 选立方体，`Tab` 编辑
2. 选顶面（`3` 面模式）
3. `S Y 0.1` 把顶面压扁成一条线

屋顶就成尖脊状。

### 步骤 3：移到 Roof 集合

`M` → Roof。

---

## 七、建模：烟囱

1. `Shift + A` → 立方体
2. 缩放 `(0.2, 0.2, 0.6)`
3. 放屋顶一侧，`(0.5, 0, 3.0)`
4. 移到 Chimney 集合

---

## 八、建模：门

1. `Shift + A` → 立方体
2. 缩放 `(0.75, 0.05, 1.7)`
3. 放到门洞位置
4. 稍微往外凸一点
5. 移到 Door 集合

### 门把手

1. `Shift + A` → UV 球
2. 缩放到 0.05
3. 放在门的一侧
4. 父级到门 `Ctrl + P`

---

## 九、建模：窗户

### 窗框

1. `Shift + A` → 立方体
2. 缩放 `(0.05, 0.7, 0.7)`（略大于窗户洞）
3. 放到窗户位置
4. 挤出内部，做出"相框"效果：
   - Tab 编辑
   - 选前面
   - Inset `I` 0.05
   - Extrude `E` 往里 0.1

### 玻璃

1. 在窗框里加一个平面作为玻璃
2. 薄薄的一片

复制到另一个窗户位置。

---

## 十、建模：地面

1. `Shift + A` → 平面
2. `S 20`（20 米）
3. 移到 Environment → Ground

---

## 十一、建模：树

### 简单低模树

树干：
1. `Shift + A` → 圆柱
2. 缩放 `(0.15, 0.15, 1.5)`
3. 位置 `(-3, 2, 0.75)`

树冠：
1. `Shift + A` → IcoSphere
2. 细分 2
3. 缩放 1.2
4. 位置在树干顶部

### 低模风格的粗糙感

1. 树干和树冠都 `Tab` 编辑
2. 选所有顶点
3. **网格 → 变换 → 随机化** (vertices)
4. 数量 0.05 – 0.1
5. 让形状不规则

复制几棵树，散布在四周。

---

## 十二、材质

低模风格用纯色。

### 添加材质列表

- Walls：米色 `#D4C8A0`
- Roof：深红 `#8B3A2C`
- Door：木棕 `#7B4A2C`
- Windows：浅蓝玻璃 `#A0C8E0`，透射 0.8
- Chimney：灰砖 `#606060`
- Ground：草绿 `#5A8C3A`
- Tree Trunk：棕 `#5B3B1C`
- Tree Foliage：深绿 `#3A6B2A`

所有材质都是 Principled BSDF，基础色纯色，粗糙度 0.6（除了玻璃）。

### 快速批量

1. 每个物体右键 → 分配材质
2. 或者选物体 + 材质浏览器选已有材质

---

## 十三、布光：夕阳

### 删除默认灯

### 添加日光

1. `Shift + A` → 灯光 → 日光
2. 位置不重要
3. 旋转：`R Y 60`（低角度，模拟黄昏）
4. 再 `R Z 45`
5. 强度：3
6. 颜色：金黄（`#FFC080`）
7. 角度：2°（柔和阴影）

移到 Lights 集合。

### 环境光（HDRI）

1. 世界属性 → 颜色 → 环境纹理
2. 加载一张傍晚 HDRI（比如 `venice_sunset_1k.hdr`）
3. 强度 0.5

### 补光

阴影一侧加一个面光作为辅光：

1. `Shift + A` → 面光
2. 位置在阴影侧
3. 冷色 `#8090A0`
4. 能量 50
5. 尺寸 5 m

---

## 十四、相机

1. 选相机
2. 焦距 35 mm
3. `Num 0` 进相机视图
4. `N` → 相机到视图
5. 调到能看到房屋 + 一棵树 + 地面 + 天空的角度
6. 稍微俯视
7. 取消相机到视图

### 三分法

构图参考线开启 → 三分法。让房屋在左 1/3 交点。

---

## 十五、渲染设置

### 引擎

Cycles。

### 采样

- 视口 32
- 渲染 256
- 降噪 OpenImageDenoise

### 设备

GPU 计算（如果有）。

### 颜色管理

- 视图变换 AgX
- 看点 Base Contrast

### 输出

- 1920 × 1080
- PNG 16 位
- 路径 `//house.png`

---

## 十六、渲染与调整

`F12` 看结果。

常见问题：
- 太黄？日光颜色更白
- 阴影太硬？日光角度加大
- 某个物体看不到？检查材质颜色和灯光
- 玻璃不对？检查 IOR 1.45 和粗糙度

反复调整直到满意。

---

## 十七、保存作品

- `Ctrl + S` 保存 .blend
- 渲染窗口 `Alt + S` 保存 PNG
- 可以输出 4K 版：分辨率改 3840×2160 再 `F12`

---

## 十八、扩展：做成动画

### 简单相机环绕

1. 第 1 帧：相机在正面，`I` 插入位置和旋转
2. 第 120 帧：相机在侧面，再 `I`
3. 第 240 帧：回到正面，再 `I`
4. 设帧范围 1–240
5. `Ctrl + F12` 出动画

---

## 动手练习 9.3

整个本节是一个长练习。进阶挑战：

1. 给房屋加围栏
2. 加几块石头散在地上

5. 做一个昼夜循环动画
