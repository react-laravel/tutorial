# 9.2 实战二：小木桌

> 比马克杯难一个档次。涉及：挤出 / 环切 / 倒角 / 阵列 / 镜像 / PBR 贴图。全程约 1 小时。

---

## 一、成品预览

一张普通的木制小桌：
- 桌面（带倒角的矩形）
- 四条桌腿
- 桌腿间的横梁
- 木纹材质
- HDRI 环境光

---

## 二、准备

新建场景，删除默认立方体，设置单位为公制（米）。

---

## 三、建模：桌面

### 步骤 1：基础立方体

1. `Shift + A` → 网格 → 立方体
2. 操作面板：尺寸 1 米

### 步骤 2：调整为桌面形状

1. `S` 缩放到 0.8 × 0.8 × 0.03
2. 或分别：`S X 0.8`、`S Y 0.8`、`S Z 0.03`
3. 应用变换 `Ctrl + A` → 所有变换

### 步骤 3：抬高

1. `G Z 0.74`（桌面底部在 74 cm）

### 步骤 4：倒角

1. `Tab` 编辑
2. `A` 全选
3. `Ctrl + B` 倒角
4. 鼠标拖动到约 1 cm
5. 滚轮增加段数到 3
6. 确认

桌面边缘变得圆润。

### 步骤 5：平滑着色

1. `Tab` 回物体模式
2. 右键 → Smooth by Angle

---

## 四、建模：桌腿

### 步骤 1：第一条腿

1. `Shift + A` → 网格 → 立方体
2. 操作面板：尺寸 0.1
3. `S Z 7.4`（拉长到 74 cm）
4. 应用缩放 `Ctrl + A`

等等，这样做会很胖。重新来：

1. `Shift + A` → 立方体
2. `S` 缩放到 `(0.03, 0.03, 0.37)`
3. `Ctrl + A` → 应用缩放
4. `G` 移到桌面下方一角，比如 `(0.35, 0.35, 0.37)`

### 步骤 2：用镜像快速做其他三条

**方案 1：纯镜像**

1. 选桌腿
2. 添加修改器 → 镜像
3. 勾选 X 和 Y 轴
4. 一条腿变四条

但有个问题：镜像需要一个"原点"。如果桌腿的原点不在中心，镜像会错位。

**方案 2：桌腿父级到桌面**

1. 选桌腿，Shift 选桌面
2. `Ctrl + P` → 对象
3. 桌腿变成桌面的子物体
4. 给**桌腿**加镜像修改器
5. 镜像参考桌面的原点（镜像修改器的"镜像对象"设为桌面）

这样四条腿围绕桌面中心对称。

---

## 五、建模：横梁

横梁连接桌腿，增加稳定性。

### 步骤 1：加一个立方体

1. `Shift + A` → 立方体
2. 缩放到 `(0.32, 0.02, 0.02)`（长度、宽度、厚度）
3. 放到两条腿之间，`(0, 0.35, 0.6)`（桌面下方、前侧）

### 步骤 2：镜像 Y 轴

- 镜像修改器，只勾 Y 轴
- 前后各一根横梁

### 步骤 3：另一方向的横梁

- 复制这个物体 `Shift + D`
- `R Z 90` 旋转 90°
- 位置改到 `(0.35, 0, 0.6)`

或者用另一个立方体 + 镜像 X 轴。

---

## 六、建模细节：桌腿倒角

1. 选一条桌腿（注意，镜像是虚拟副本，你改的是源）
2. `Tab` 编辑
3. `A` 全选
4. `Ctrl + B` 倒角 → 约 0.003，段数 2
5. `Tab` 回物体

镜像修改器实时更新。

---

## 七、材质：木纹 PBR

### 准备贴图

从 Poly Haven 或 Ambient CG 下载一套**木头 PBR 贴图**（diff + rough + nor + ao）。

### 应用到桌面

1. 选桌面
2. 新建材质 "Wood"
3. 切到节点编辑器
4. 选 Principled BSDF
5. `Ctrl + Shift + T`（Node Wrangler）
6. 全选下载的贴图 → 打开
7. 自动生成节点图

### 调整映射

1. 选映射节点
2. 缩放 X, Y = 2（让木纹更细）

### UV 展开

1. 选桌面 `Tab`
2. `A` 全选
3. `U` → **智能 UV 投影**
4. 岛边距 0.05

不 UV 展开的话贴图可能拉伸。

### 桌腿和横梁同材质

选每一条腿 → 材质 → 浏览 → 选 Wood。

或者全选（桌腿 + 横梁 + 桌面）→ 最后选桌面 → `Ctrl + L` → 链接材质。

---

## 八、地板

1. `Shift + A` → 平面
2. `S 5`（5 米大）
3. 新材质"Floor"：稍深的棕色，粗糙度 0.7

或者加另一套 PBR 贴图（比如水泥、瓷砖）。

---

## 九、布光：HDRI 环境

### 下载 HDRI

从 Poly Haven 下载一张 2K 室内 HDRI（比如 `photo_studio_01_2k.exr`）。

### 应用

1. 世界属性 → 颜色 → 环境纹理
2. 打开文件
3. 渲染预览 → 场景亮起

### 调强度

背景强度：1.0（根据 HDRI 本身决定）。

### 加主光

HDRI 偏平均，加一盏面光作为主光：

1. `Shift + A` → 灯光 → 面光
2. 位置：`(3, -3, 4)`
3. 指向桌子
4. 能量：500 W
5. 尺寸：2 m

---

## 十、相机

1. 选相机
2. `Num 0` 进相机视图
3. N 面板 → 视图 → 相机到视图
4. 调到能看到整张桌子的角度
5. 焦距 35 mm（稍广角）
6. 取消相机到视图

### 构图

- 桌子不必居中
- 可以让桌子在画面左下或右下
- 留出头上空间

---

## 十一、渲染

### 引擎

Cycles（追求真实的木纹反射）。

### 采样

- 渲染 256
- 降噪：OpenImageDenoise

### 输出

- 1920 × 1080
- PNG
- 视图变换 AgX

`F12` 渲染。

---

## 十二、常见问题

### 木纹方向不对

- 进编辑模式
- 选 UV 编辑器
- 旋转 UV 90°

### 桌腿歪了

- 检查镜像修改器的"镜像对象"
- 或者手动检查每条腿的位置

### 渲染很慢

- 降低采样到 128
- 关闭 HDRI，用面光

---

## 十三、扩展：加桌上物品

- 马克杯（复用 9.1 的）
- 一本书（立方体 + UV 贴图）
- 一盏台灯

把它们都加进场景，构图更丰富。
