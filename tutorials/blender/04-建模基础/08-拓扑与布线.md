# 4.8 拓扑与布线基本原则

> "拓扑"听起来像数学术语，但它其实是建模里的"**怎么布置点线面**"。好的拓扑让你的模型易于编辑、变形、渲染。

---

## 一、什么是拓扑

**拓扑（Topology）**：网格上点线面的**排布方式**。

两个模型可能外观相同，但拓扑完全不同。区别在于：
- 能否正确绑定骨骼
- 能否正确接受细分
- 能否正确贴图
- 能否被别的建模师轻松编辑

---

## 二、好拓扑的特征

### 1. 全部四边面

- 四边面是"最标准"的拓扑单元
- 细分表面在四边面上最干净
- 绑骨骼变形时四边面行为可预期

### 2. 环线贯通

重要的环线（沿物体主要走向的）应该**一路贯通**，不被三角面或 N-gon 打断。

### 3. 密度适中且均匀

- 弯曲处点密集
- 平直处点稀疏
- 避免"**突变**"——相邻区域密度差太大

### 4. 避免极点

**极点（Pole）**：5 条或 3 条边连接的顶点。

- 理想情况下顶点连 4 条边（规则网格）
- 少量 5-pole 和 3-pole 可以接受
- **不要有 6+ pole**

极点不一定"坏"，但多了会影响细分和变形。

---

## 三、坏拓扑的表现

### 1. 三角面堆积

到处都是三角形的模型。细分会产生涟漪，变形会乱跳。

### 2. N-gon（多边面）

5+ 边的面。很多问题：
- 细分表面乱变形
- 法线计算不稳定
- UV 展开可能出错

### 3. 环线断裂

一圈本该连起来的环线中间被其他面切断。

### 4. 扭曲的四边面

四边面的四个顶点不在同一平面上，极度扭曲。

---

## 四、拓扑工具箱

Blender 里与拓扑相关的操作：

### 连接 J

`J` 在两个顶点之间切一条边，把一个面切成两半。

用途：把 N-gon 分解为四边面。

### Dissolve Edges（Ctrl + X）

选中边，`Ctrl + X` → 溶解。邻近面合并。

用途：移除多余环线，简化拓扑。

### Knife（K 键）

**刀具**：手动切线。
- `K` 进入刀具模式
- 点击开始，在面上点击继续切
- `Enter` 确认，`Esc` 取消
- 按 `C` 约束角度（45°）
- 按 `Z` 切穿所有层

用于：精确在某个位置切一条线。

### Triangulate（Ctrl + T）

把 N-gon 或四边面转三角面。

### Quads from Tris（Alt + J）

把三角面合并回四边面。用于修复三角化的模型。

### 边线细分

选中一条边，右键 → 细分，在中间加一个点。

---

## 五、刀具 K 的详细用法

刀具是精确切线的利器：

1. 按 `K`
2. 鼠标变成刀
3. 在面上点第一个点（鼠标会吸附到边或顶点）
4. 在面上点第二个点 → 一条切线出现
5. 继续点更多点形成折线
6. 按 `Enter` 确认

### 修饰键

| 键 | 作用 |
|---|---|
| `C` | 约束到 45° 角 |
| `Z` | 切穿所有几何体（贯穿） |
| `A` | 切换吸附到相交点 |
| `Esc` | 取消 |
| `右键` | 取消当前点，回到上一个 |

## 六、拓扑优化示例

### 例子：四边面包围圆孔

在一个平面上切一个圆孔：

❌ **坏做法**：直接布尔 → 得到一圈三角面/N-gon 围绕圆孔。

✅ **好做法**：
1. 在圆孔位置先做一个正方形区域（4 边面）
2. 在这个区域内切圆
3. 把圆的顶点和方形的边连起来
4. 得到规则的"方→圆"过渡

这种技巧叫"**E 形拓扑**"或"**方环孔**"。

## 七、怎么练习拓扑感

### 推荐练习

1. **重建简单物体**：立方体、柱体、球体
2. **追求全四边**：每个模型最后检查没有三角面和 N-gon
3. **读别人的模型**：下载优秀模型看他们的拓扑
4. **做有机物**：脸、手、树枝 —— 这些最考拓扑

### 评判标准

问自己：
- 环线是否贯通？
- 有没有不必要的三角形？
- 面的密度和曲率匹配吗？
- 如果要绑骨，弯曲处密度够吗？

---

## 八、检查拓扑的工具

### 1. 显示三角面/N-gon

选中 → 菜单 `选择 → 所有按特征 → 面依据 边数`
- 选 "小于 4" → 选中三角面
- 选 "大于 4" → 选中 N-gon

快速找出非四边面。

### 2. 统计信息

叠加层 → 统计信息，开启后 3D 视图左上角显示顶点/边/面数量。

### 3. 布线叠加

叠加层 → 显示网格 → 调整透明度/颜色，更清楚地看到布线。

## 九、低模 vs 高模

两种工作流：

### 低模（Low-poly）

- 几百到几千个多边形
- 用于实时渲染（游戏）
- 细节用法线贴图模拟
- 拓扑追求效率

### 高模（High-poly）

- 几十万到几百万个多边形
- 用于离线渲染或烘焙
- 细节用真实几何
- 拓扑可以松一些（因为不需要变形）

**专业流程**：
1. 先做高模（细节丰富）
2. 做对应的低模（拓扑干净）
3. 把高模细节"烘焙"到低模的法线贴图上
4. 游戏里用低模 + 法线贴图

新手阶段不用管这些，先把单一的"中模"做好即可。

## 十、收尾清理检查清单

模型完成后，跑一遍检查：

- [ ] `A` 全选 → `M → 按距离` 合并重复点
- [ ] `Shift + N` 重算法线
- [ ] 选择 `面依据边数 > 4` 检查 N-gon 并修复
- [ ] 删除松散顶点（`网格 → 清理 → 删除松散`）
- [ ] 应用缩放（`Ctrl + A → 缩放`）
- [ ] 原点设置正确
- [ ] 物体命名清晰

## 动手练习 4.8

### 练习 A：四边面重建
1. 添加立方体
2. 挤出一个面但按 Esc（故意制造问题）
3. 全选 → `M → 按距离` 清理
4. 确认没有重叠

### 练习 B：选所有 N-gon
1. 添加立方体
2. 进入编辑模式
3. 选两个相邻的面，`X → 仅面` 删除
4. 填补边界 `F` → 创建一个 N-gon
5. 菜单 `选择 → 所有按特征 → 面依据边数`，设 "大于 4"
6. N-gon 被选中

### 练习 C：Knife 工具
1. 新立方体
2. `Tab`
3. `K` 启动刀具
4. 在顶面随便点几个点切一条折线
5. `Enter` 确认

### 练习 D：Dissolve
1. 立方体环切 3 条
2. 选中中间那条环线
3. `Ctrl + X` 溶解
4. 环线消失，相邻面合并

### 练习 E：收尾清理
1. 把之前练习做的任意模型打开
2. 跑一遍第十节的清理检查清单
