# 4.2 挤出 Extrude 完全指南

> 挤出是建模中使用最频繁的工具。从一个立方体变出桌子、房子、机器人，几乎都离不开挤出。本节讲清它的所有用法。

---

## 一、什么是挤出

**挤出（Extrude）**：选中一个点/边/面，把它"拉出"新的几何体。新拉出的部分会和原来的部分自然相连。

### 生活类比

想象你有一块橡皮泥做的方形饼干，你用手指拉它表面的一个角，拉出来的部分就是挤出。原来的面还在，新增的点/边/面接在原位置。

---

## 二、基本挤出：E 键

操作步骤：

1. 进入编辑模式
2. 选中要挤出的面（或边、点）
3. 按 `E` 键
4. 鼠标移动 → 新挤出的部分随鼠标移动
5. **左键确认** 或 **Esc 取消移动**

### 关键陷阱：Esc 不等于撤销！

按 `E` 之后再按 `Esc`：
- 挤出**已经发生了**（新的面已经创建）
- 只是"移动"步骤被取消了
- 新挤出的面**停留在原位置**，和原面完全重叠

**结果**：你看起来什么都没发生，但实际上多了一份重叠的面。这是新手最常见的 bug 来源。

**解决办法**：发现挤出后按 Esc 留下重叠，立刻 `Ctrl + Z` 撤销完整的挤出操作。

---

## 三、轴向挤出

和 G/R/S 一样，挤出可以限制到单一轴：

| 组合 | 效果 |
|---|---|
| `E Z 2 Enter` | 沿 Z 轴挤出 2 米 |
| `E X 1.5 Enter` | 沿 X 轴挤出 1.5 米 |
| `E X -1 Enter` | 反向挤出 1 米 |

### 沿法线挤出

默认的 `E` 会沿**选中面的法线方向**挤出。这对曲面物体特别有用——不用管具体轴向，直接往"外"拉就行。

---

## 四、四种挤出方式

按 `E` 后如果不立即移动，注意 3D 视图头部栏出现了多个子选项。或者从菜单 `网格 → 挤出` 看所有类型：

### 1. 挤出区域（Extrude Region）— 默认

最常用。把**整个选中的面集合作为一个整体**挤出，共享新的边。

`E` 就是这个。

### 2. 沿法线挤出（Extrude Along Normals）

每个面沿**自己的法线**单独挤出。适合挤出球面或弯曲表面——直接 E 会让面互相挤压变形，这个会正确地"向外膨胀"。

快捷键：`Alt + E` → 选"沿法线挤出"

### 3. 各面挤出（Extrude Individual Faces）

每个选中的面**独立挤出**，彼此之间不共享新边。挤出后每个面变成一个独立的方块。

快捷键：`Alt + E` → 选"各面挤出"

### 4. 到光标（Extrude to Cursor）

按住 `Ctrl + 右键` 空白处 → 自动创建一个新顶点，和原来的选中点相连。适合快速拉出曲线。

---

## 五、挤出面 vs 挤出边 vs 挤出点

### 挤出面

最常用。挤出一个面会得到一个**柱状延伸**：原面 + 侧面 + 新面。

### 挤出边

选中一条边按 `E` → 拉出一个新的面，新边和原边平行。适合从一条线开始扩展面。

### 挤出点

选中一个点按 `E` → 拉出一个新点，用一条新边连接。适合从头开始画线。

---

## 六、挤出的典型应用

### 做一个柱子

1. 添加平面
2. `Tab` 编辑模式，面模式
3. 选中这个面
4. `E Z 3 Enter` → 沿 Z 挤出 3 米
5. 完成一个立方柱

### 做一个 L 形

1. 从立方体开始
2. 选前面的一个面
3. `E Y -2` → 向 -Y 方向拉出一段
4. 变成 L 形

### 做一个房子外壳

1. 平面作为地基
2. 选面 → 挤出向上作为墙
3. 分几段挤出作为二楼、屋顶

### 画一条自由曲线（挤出点）

1. 添加平面，`Tab` 编辑模式
2. 删掉所有面，只留一个点
3. `E` 挤出新点 → 得到一段线
4. 重复 `E` → 画出一条折线

---

## 七、挤出后的调整

挤出后 3D 视图**左下角**会出现"挤出区域"面板（或按 F9 弹出）。你可以在这里精确调整：

- X/Y/Z 方向上的偏移
- 是否沿法线
- 翻转法线等

---

## 八、连续挤出

挤出之后接着按 `E` 可以继续挤出新段。做台阶、楼梯、章鱼触手很常用：

```
初始面 → E Z 0.5 → E Y 0.5 → E Z 0.5 → E Y 0.5 → ...
```

---

## 九、常见陷阱

### 陷阱 1：E + Esc 的重叠面

已经讲过。解决：发现问题立刻 `Ctrl + Z`。
预防：按 E 之后直接按 `Enter` 或者输入数字，不要按 Esc。

### 陷阱 2：内部面

挤出面时，原来的面其实还在新几何体的"内部"。如果你挤的是一个封闭立方体的一个面，挤出后原面可能成为夹层。

**后果**：
- 渲染时看不到问题
- 但烘焙、导出、贴图时可能出错

**解决**：挤出后检查并删除内部面。

### 陷阱 3：Z 方向反了

`E Z -1` 和 `E Z 1` 是相反方向。如果你挤错了方向，可以：
- 立即 `Ctrl + Z` 撤销
- 或者 F9 面板里改数字的正负号

### 陷阱 4：所选的是 N 边面

挤出 N-gon（多边面）可能产生奇怪的几何。建议先把 N-gon 三角化或转四边面再挤出。

---

## 十、挤出的进阶技巧

### 技巧 1：按数字精确挤出

总是用 `E + 数字` 代替鼠标拖动，精确度高，可重复。

### 技巧 2：先选环再挤出

`Alt + 左键` 先选一圈面，再 E，一次挤一圈，比一个个挤更整齐。

### 技巧 3：配合 S 做锥形

挤出一段后紧接着 `S 0.8` 让新挤出的面缩小 80%。重复几次可以做出锥形（比如火箭弹头）。

### 技巧 4：配合吸附挤出到目标

打开吸附（`Shift + Tab`），设为吸附到顶点，然后挤出时鼠标靠近目标顶点，新面会吸附过去。适合做精确对齐的几何连接。

## 动手练习 4.2

### 练习 A：基础挤出
1. 删除默认立方体
2. 添加平面
3. `Tab` 编辑模式
4. 选中平面的面
5. `E Z 2 Enter` → 拉出一个方柱
6. `Tab` 退出查看

### 练习 B：台阶
1. 新场景
2. 添加立方体，`Tab` 编辑模式
3. 选顶面
4. `E Z 0.5` → `E Y -0.5`
5. 再次选新顶面，重复 3 次
6. 得到一个四级台阶

### 练习 C：曲线（挤出点）
1. 添加平面，`Tab`
2. 面模式，`A` 全选，`X` → 仅面（剩下四个顶点）
3. 再 `X` → 顶点，把其中三个删掉
4. 剩一个点
5. `E` `G` 任意移动画一段线，左键确认
6. 重复 `E` 画出一条曲折的折线

### 练习 D：柱体沿法线挤出
1. 添加一个 UV 球
2. `Tab` 编辑模式
3. 全选面 `A`
4. 菜单 `网格` → `挤出` → "沿法线挤出面"
5. 鼠标上移 → 球变大但不变形
6. 对比按 `E` 直接挤出的效果

### 练习 E：清理重叠面
1. 添加立方体，`Tab`
2. 选一个面，`E` → `Esc`（故意制造重叠）
3. `A` 全选
4. 菜单 `网格` → `清理` → "按距离合并"（旧名 Remove Doubles）
5. 观察状态栏提示合并了多少点
