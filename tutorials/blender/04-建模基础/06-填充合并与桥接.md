# 4.6 填充、合并与桥接

> 本节讲三组"修补"工具——填充补洞、合并顶点、桥接两个开口。它们是清理和连接网格的关键技能。

---

## 一、填充 F 键

选中若干顶点或边按 `F`，Blender 会尝试**创建一个面**把它们填上。

### 规则

- 选中 **2 个顶点** → 创建一条边
- 选中 **3 个顶点** → 创建一个三角面
- 选中 **4 个顶点** → 创建一个四边面
- 选中 **4+ 个顶点** → 创建一个 N 边面（谨慎）

### 典型用例

- 有一个开口的洞，选边界上的点，`F` → 填补

---

## 二、栅格填充：Ctrl + F → 栅格填充

如果一个洞的边数是**偶数**（至少 4 条边），可以用"栅格填充"自动生成**整齐的四边面网格**。

操作：
1. 选中洞的边界环
2. 菜单 `面` → `栅格填充`
3. Blender 自动铺设四边面

F9 面板里可以调：
- **跨度（Span）**：栅格的起始位置偏移
- **偏移（Offset）**：旋转方向

比起简单 `F` 创建 N-gon，栅格填充能保持良好的布线。

---

## 三、桥接 Bridge Edge Loops

**桥接**：在两组独立的开口之间"搭桥"，创建连接的面。

### 操作

1. 选中 **两组平行的边环**（比如两个圆柱的开口）
2. 菜单 `边` → `桥接环线`
3. 两个环之间自动连接成面

### 用途

- 连接两根断开的管子
- 给一个物体加耳朵（在身体和耳根之间桥接）
- 合并两个独立网格
- 做环形结构

### F9 参数

- **段数**：桥接之间加多少段中间面
- **平滑度**：面过渡是否平滑
- **轮廓因数**：桥接形状
- **扭曲**：在连接时旋转一个环

---

## 四、合并顶点 Merge

合并是把多个顶点**变成一个**的操作。

### 按 M → 合并菜单

选中多个顶点按 `M`：

| 选项 | 作用 |
|---|---|
| **到中心** | 合并到几何中心 |
| **到光标** | 合并到 3D 游标位置 |
| **到末端** | 合并到最后选中的那个 |
| **到第一个** | 合并到第一个选中 |
| **到碰撞** | 按距离合并（见下） |
| **按距离** | 自动合并所有距离 < 阈值的顶点 |

### 按距离合并（超重要）

也叫 **Remove Doubles**（老名字）。菜单 `M → 按距离`，或 `网格 → 清理 → 按距离合并`。

**作用**：找到所有距离 < 阈值（默认 0.0001）的顶点对，合并它们。

**典型场景**：
- 挤出时意外制造了重叠点 → 用它清理
- 从外部导入的模型有重复点
- 镜像后中线上的点没合并

养成习惯：**建模结束前按一次 `A` 全选，再 `M → 按距离`**，清理所有重叠点。

---

## 五、合并顶点的快捷键

- `M` → 合并菜单
- `Alt + M` → 老版本的另一个快捷

---

## 六、连接顶点 J

`J` 键：在选中的两个顶点之间**切一条边**（会穿过面创建新顶点）。

### 用途

- 把一个大 N-gon 切成两个四边形
- 在两个顶点之间强制连线
- 改善拓扑

### 操作

1. 选两个顶点
2. `J`
3. 如果它们属于同一个面，这个面被切开，新边连接它们

---

## 七、分离与分割

### 分离 P

把选中的部分**分离成独立物体**。

1. 编辑模式选中要分离的点/边/面
2. 按 `P`
3. 选择：
   - **选中项**：把选中的分出去
   - **按松散部件**：自动按连通块分离
   - **按材质**：按材质分离

分离后立即退出编辑模式能看到新物体。

### 分割 V / Y

**分割**（不是分离）：把选中的边/面从网格里"断开"，但留在同一个物体里。

- `V` → 撕开顶点
- `Y` → 撕开选中的面

断开后，顶点变成多个独立的点，可以分别移动。

---

## 八、填充网格的其他方法

### N 边面填充

选边界 → `F` → 创建 N-gon。简单但拓扑差。

### 三角化 Ctrl + T

把 N-gon 或四边面分解为三角形。用于导出到游戏引擎。

### 反向三角化 Alt + J

把三角面**合并回四边面**。很有用的"修复拓扑"工具。

---

## 九、清理网格的常用操作

菜单 `网格 → 清理`：

| 选项 | 作用 |
|---|---|
| **按距离合并** | 合并靠近顶点（最常用） |
| **删除松散** | 删除没有面的孤立顶点 |
| **有限溶解** | 溶解几乎共面的边，简化 |
| **退化溶解** | 溶解长度为 0 的边 |
| **填补洞** | 自动填补闭合的开口 |
| **分开** | 以某种方式分开网格 |
| **修复元素属性** | 修复异常数据 |

建模完收尾时跑一遍清理对导出很有帮助。

---

## 十、实战：做一个连接管道

1. 添加一个柱体，`Tab` 编辑
2. 选顶面，`X → 面` 删掉（顶部开口）
3. `Tab` 退出
4. 再加一个柱体，把它移到侧面
5. 进入编辑，删掉它的一个侧面环
6. 全选两个物体（物体模式）
7. `Ctrl + J` 合并成一个物体
8. 进入编辑模式
9. 选两个开口的边环
10. `面 → 桥接环线`
11. 两个管子连接起来了

## 动手练习 4.6

### 练习 A：填补
1. 立方体 `Tab`，面模式
2. 选顶面 `X → 仅面` → 顶部有个洞
3. 边模式，选洞边界的 4 条边（`Alt + 左键`）
4. `F` → 填补
5. 也可以再试一次，用"栅格填充"

### 练习 B：桥接
1. 新场景，添加两个柱体
2. 第一个放原位
3. 第二个 `G X 3` 挪到旁边
4. 都进入编辑模式（多物体）
5. 各自选最靠近的一个面，`X → 面` 删除
6. 退出编辑，`Ctrl + J` 合并
7. 再进入编辑，选两个洞的边环
8. `面 → 桥接环线` → 两管连接

### 练习 C：合并
1. 立方体
2. `Tab`，点模式
3. 选两个相邻顶点
4. `M → 到中心` → 它们合并成一个
5. 撤销
6. 选所有点，`M → 按距离` → 应该显示 "0 个顶点被合并"

### 练习 D：Alt+M 反三角化
1. 平面，细分 1 次（`W` 或右键菜单）
2. 三角化（`Ctrl + T`）→ 变成三角面
3. `Alt + J` → 变回四边形

### 练习 E：清理
1. 立方体
2. `Tab`
3. 挤出一次按 Esc（制造重叠面）
4. `A` 全选
5. `M → 按距离`
6. 观察底部状态栏告知合并了多少点
