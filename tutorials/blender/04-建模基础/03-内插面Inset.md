# 4.3 内插面 Inset

> 内插面是在一个面内部"缩出"一个小面的操作。常用于做窗户、按钮、嵌板、浮雕等细节。

---

## 一、什么是内插面

**内插面（Inset）**：在一个已有的面内部，按一定距离缩出一个新的小面。原面被保留，新面和原面之间形成一圈边框。

### 直观理解

想象一张正方形纸，你在中央画一个稍小的正方形——内插就是这个效果，但在 3D 模型上。

### 基本结构

原始面：
```
┌─────────┐
│         │
│         │
│         │
└─────────┘
```

内插后：
```
┌─────────┐
│ ┌─────┐ │
│ │     │ │
│ └─────┘ │
└─────────┘
```

---

## 二、基本操作：I 键

1. 进入编辑模式
2. 面模式（`3`）
3. 选中一个或多个面
4. 按 `I`
5. 鼠标向内移动 → 面缩小
6. 左键确认

### 精确距离

按 `I` 后直接输入数字：
- `I 0.2 Enter` → 内插 0.2 米

---

## 三、整体内插 vs 各面内插

### 整体内插：I 一次

选中多个连续面按 `I`：
- 所有选中面**作为整体**内插
- 形成一个整体的凹槽/框

### 各面内插：I I（按两下）

按 `I` 然后**再按一下 I**：
- 每个选中的面**独立**内插
- 形成多个独立的小框

### 用菜单切换

也可以在按 `I` 后的头部栏里勾选"各面"。

---

## 四、内插的典型应用

### 1. 做窗户

1. 选墙面
2. `I 0.3` 内插一个小面
3. `E Y -0.1` 挤出向里凹 → 窗户的凹陷感

### 2. 做按钮

1. 选一个面
2. `I 0.1`
3. `E Z 0.05` 向外挤一点点 → 突起按钮

### 3. 做嵌板

1. 选一个大面
2. `I 0.15`
3. `E Z -0.02` 向内凹一点点 → 嵌板感

### 4. 做屏幕边框

1. 平板电脑正面
2. `I 0.05` → 屏幕区
3. 给内圈一个暗色材质

---

## 五、内插的参数（F9 面板）

内插之后按 `F9` 或者在左下角面板里可以调：

| 参数 | 作用 |
|---|---|
| **厚度（Thickness）** | 内插的宽度 |
| **深度（Depth）** | 内插同时的 Z 方向偏移（可以做凹/凸） |
| **偏移量相对** | 按比例还是绝对值 |
| **各面** | 独立内插每个面 |
| **边缘比例** | 边缘宽度的不均匀分布 |
| **外框** | 反向内插（扩到外面） |
| **向外插** | 同上 |
| **相对偏移量** | 使用面的比例作为内插尺寸 |

---

## 六、内插的特殊情况

### 内插 N 边面

多边面可以内插，但结果的拓扑结构不一定均匀。建议对 N-gon 先三角化或分割。

### 内插边界面

边界处的面内插时，边界处可能缩不到中心——这是正常的，因为需要保证相邻面不裂开。

### 内插距离过大

如果内插距离 ≥ 面的半径，内插面会**坍缩到中心**变成一个点。

---

## 七、内插 + 挤出组合

**这个组合极其常用**：

1. `I` 内插一个小面
2. `E` 挤出这个小面

用这种两步可以做出：
- 凸起按钮：`I 0.1` → `E Z 0.02`
- 凹陷按钮：`I 0.1` → `E Z -0.02`
- 嵌进去的窗户：`I 0.3` → `E Y -0.1`
- 浮雕装饰：`I 0.05` → `E Z 0.01`

---

## 八、内插的修饰键

内插过程中可以按住以下键：

| 修饰键 | 作用 |
|---|---|
| **Ctrl** | 控制深度（同时 Z 方向偏移） |
| **Shift** | 精细模式 |
| **P** | 切换"单独面" |
| **O** | 切换"外边界" |
| **B** | 切换"边界" |

不常用的修饰键先别管，知道 Ctrl 可以同时做深度就行。

---

## 九、常见问题

### Q1：内插后面变形奇怪
可能是 N-gon 或拓扑问题。用 `J` 键（连接顶点）先整理拓扑。

### Q2：内插距离随机
确认相对/绝对偏移模式。

### Q3：想内插多个独立面但变成了整体
按两次 `I`（`I I`）或在面板里勾"各面"。

### Q4：内插后和挤出效果一样
内插**缩小一个面在原平面上**，挤出**向法线方向拉出**。你可能把它们看成一样的了，其实空间方向不同。

## 动手练习 4.3

### 练习 A：基础内插
1. 默认立方体
2. `Tab` 编辑模式，面模式
3. 选顶面
4. `I 0.3` → 顶面内缩一个小面
5. 看 F9 面板，尝试修改数字

### 练习 B：按钮
1. 新立方体
2. 选顶面
3. `I 0.2` 内插
4. `E Z 0.05` 向上挤 → 按钮完成

### 练习 C：窗户
1. 新立方体作为墙
2. `S X 3` 拉宽
3. `S Z 2` 拉高
4. 选正面一个面
5. `I 0.15` → `E Y -0.05` → 窗户凹陷

### 练习 D：各面内插
1. 添加一个栅格平面（`Shift + A` → 网格 → 栅格，默认 10×10）
2. `Tab` 编辑模式
3. `A` 全选所有面
4. 按 `I I`（两次）→ 每个小面各自内插
5. 得到一个镂空的栅格图案

### 练习 E：组合创建嵌板
1. 新平面
2. 面模式，选面
3. `I 0.1` 大框
4. `I 0.05` 更小的框
5. `E Z -0.02` 凹下去
6. 得到一个装饰嵌板
