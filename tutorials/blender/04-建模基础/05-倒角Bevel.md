# 4.5 倒角 Bevel

> 现实世界里几乎没有绝对锐利的边——所有物体的角都有轻微的倒角（哪怕只有 0.1 毫米）。给模型加倒角是让它"看起来真实"的最便宜的技巧。

---

## 一、什么是倒角

**倒角（Bevel）**：把一条锐利的边/一个尖锐的点"削成"圆弧或斜面。

### 视觉效果

- 锐边：高光是一条**锐利的线**
- 倒角边：高光是一条**柔和的弧**，能"捕捉"到光线

真实世界的物体几乎都有倒角。没有倒角的模型会显得"塑料感"或"CG 感"。

---

## 二、基本操作：Ctrl + B（边倒角）

1. 进入编辑模式
2. 边模式（`2`）
3. 选中一条或多条边
4. 按 `Ctrl + B`
5. 鼠标移动 → 倒角宽度改变
6. **左键确认**
7. 按 `S` 或数字输入精确宽度

### 精确宽度

按 `Ctrl + B` 后：
- 直接输入数字：`Ctrl + B 0.1 Enter` → 倒角 0.1 米

---

## 三、增加段数：滚轮或数字键

倒角过程中**滚动鼠标滚轮**可以增加段数。或者输入数字（但不会被误以为是宽度）：

- 0 段 = 只有一条直的斜面
- 1 段 = 1 道斜面边（2 边）
- 2 段 = 2 道斜面边（3 边）
- 3 段 = 更圆
- 10+ 段 = 几乎是光滑圆弧

### 段数建议

| 用途 | 建议段数 |
|---|---|
| 快速草图 | 0–1 |
| 硬表面细节 | 2–4 |
| 渲染出图 | 5–10 |
| 非常光滑的圆角 | 10+ |

**段数越多越圆，但多边形数量也增加**。按需求平衡。

---

## 四、顶点倒角：Ctrl + Shift + B

选中一个顶点按 `Ctrl + Shift + B`：

- 把一个尖点"切成"一个小面（或圆弧）
- 类似把桌角削圆

适合：做圆角立方体时，直接对顶点倒角比分别处理 3 条边简单。

---

## 五、倒角的形状（Profile）

倒角面板里有一个"**轮廓**"或"形状"参数：

- **0.5**：默认圆弧
- **0.0**：尖锐内凹（像刻出一道槽）
- **1.0**：尖锐外凸

修改这个数值可以得到很多有趣的轮廓。

### 自定义轮廓

F9 面板里展开"**自定义轮廓**"，可以画一条曲线作为倒角截面。可以做出各种装饰线条（踢脚线、画框、装饰条等）。

---

## 六、倒角修改器 vs 倒角工具

Blender 有**两种**倒角方式：

### 工具（Ctrl + B）：在编辑模式里直接操作

- 立即"烧进"几何体
- 不可调
- 精确控制每条边

### 修改器（Modifier）：在物体属性里添加

- 非破坏性
- 可以随时调参数
- 一次给所有锐边加倒角（自动检测）

**推荐流程**：
- 建模时用工具 Ctrl+B 做关键位置的手动倒角
- 最后加一个倒角修改器做一个全局 0.01 米的微小倒角，给所有边一点点"现实感"

---

## 七、倒角的陷阱

### 陷阱 1：重叠边导致问题

倒角的边不能太靠近彼此。如果两条要倒角的边距离 < 倒角宽度，倒角会穿透自己。

### 陷阱 2：非流形边

孤立的边（没有接面，或只连一个面）不能正确倒角。先修复拓扑。

### 陷阱 3：缩放未应用

如果物体缩放不是 `(1,1,1)`，倒角宽度会被缩放影响，结果不对。

**解决**：倒角前先 `Ctrl + A → 缩放`。

### 陷阱 4：N-gon

多边面参与倒角容易产生奇怪几何。先三角化或优化拓扑。

---

## 八、倒角 + 细分表面

经典组合：

1. 低模先建
2. 所有锐利边轻微倒角（Ctrl+B，2 段，宽度 0.02）
3. 加细分表面修改器
4. 倒角充当"控制边"，让细分保持锐利感

这是硬表面建模的基础技巧。

---

## 九、倒角的 F9 参数全解

| 参数 | 含义 |
|---|---|
| **宽度类型** | 偏移方式：偏移、宽度、深度、百分比 |
| **宽度** | 倒角的大小 |
| **段数** | 多少段（决定圆度） |
| **形状** | 轮廓曲度，0–1 |
| **仅材质** | 只对某个材质的边倒角 |
| **钳位偏移** | 防止倒角超出相邻几何 |
| **影响** | 边 / 顶点 |
| **标记锐边** | 倒角后自动标记锐边 |
| **标记接缝** | 倒角后标记 UV 接缝 |
| **不重叠** | 尝试防止重叠 |
| **循环斜接** | 角部的处理方式 |

新手阶段主要调**宽度**和**段数**即可。

---

## 十、倒角的应用场景

### 1. 家具的所有外角

桌子、椅子、沙发的外缘都要倒角。哪怕只有 0.01 米也能让观感立刻改善。

### 2. 电子产品的机壳

手机、电脑、耳机的外壳几乎所有边都有明显的倒角（1–3 毫米）。

### 3. 墙的踢脚线

墙和地面之间通常有一条装饰条。用倒角 + 自定义轮廓可以快速做出。

### 4. 工业零件

机械零件几乎都有"45° 斜边"，这就是段数为 0 的倒角。

---

## 十一、给选中的多条边倒角

可以批量选很多边一起倒角：

1. 选中所有想倒角的边（`Alt + 左键` 环选、`Ctrl + 左键` 路径选）
2. `Ctrl + B` 倒角
3. 所有选中的边一起倒

推荐做法：选中某些连续环线 → 一起倒 → 一致的宽度和段数。

## 动手练习 4.5

### 练习 A：立方体边倒角
1. 默认立方体
2. `Tab` 编辑模式
3. `A` 全选（所有 12 条边）
4. `Ctrl + B`
5. 滚轮加到 3 段
6. 输入 `0.15` → 左键确认
7. 立方体变成圆角方块

### 练习 B：顶点倒角
1. 新立方体
2. `Tab` 编辑模式，点模式
3. 选一个角点
4. `Ctrl + Shift + B`
5. 鼠标移动看这个角被削成三角面或弧形
6. 左键确认

### 练习 C：自定义轮廓（装饰线）
1. 新立方体
2. 选一条上边
3. `Ctrl + B` 加宽度，段数 5 → 左键
4. F9 面板 → 展开"自定义轮廓"
5. 勾选"使用自定义轮廓"
6. 在弹出的曲线编辑器里画一条波浪形
7. 看倒角变成装饰线

### 练习 D：倒角修改器
1. 新立方体
2. 物体属性 → 扳手图标 → 添加修改器 → 生成 → 倒角
3. 调宽度到 0.05，段数 3
4. 所有边自动获得微倒角

### 练习 E：硬表面流程
1. 新立方体
2. `Tab` 编辑模式
3. 选一条边 `Ctrl + B 0.2`，3 段
4. 退出编辑模式
5. 加细分表面修改器，2 级
6. 观察倒角处保持锐利，其他地方变圆
