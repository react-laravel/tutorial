# 4.1 编辑模式与点线面

> 现在我们进入真正的建模世界。这一节讲**编辑模式**的基本概念和三种选择模式，是所有建模工具的前置知识。

---

## 一、什么是编辑模式

在 Blender 里：
- **物体模式（Object Mode）**：把每个模型当成整体来操作——移动、旋转、缩放、复制
- **编辑模式（Edit Mode）**：进入模型内部，编辑构成它的**点、线、面**

**切换快捷键**：`Tab`

选中一个网格物体 → 按 `Tab` 进入编辑模式 → 再按 `Tab` 回到物体模式。

### 进入编辑模式后的变化

- 3D 视图头部栏左上角显示"**编辑模式**"
- 物体变成橙色轮廓 + 黑色点/线/面的网格显示
- 快捷键含义全部变化（`1/2/3` 变成选择模式切换等）
- 工具栏出现新的工具

---

## 二、网格的三个组成部分

一个网格（Mesh）由三种元素构成：

| 元素 | 英文 | 说明 |
|---|---|---|
| **顶点** | Vertex（复数 Vertices） | 空间中的一个点 |
| **边** | Edge | 连接两个顶点的线段 |
| **面** | Face | 由多个边围成的多边形 |

### 层级关系

- **2 个顶点** → 构成 **1 条边**
- **3 个或 4 个边** → 围成 **1 个面**
- **多个面** → 构成 **1 个网格**

### 面的类型

Blender 支持：
- **三角面（Triangle / Tris）**：3 边，最基础
- **四边面（Quad）**：4 边，**最推荐**
- **多边面（N-gon）**：5 边及以上，可能有问题

**为什么推荐四边面？**
- 细分表面修改器对四边面友好
- 循环边自然，方便环切
- 绑定变形不会出怪问题
- 烘焙法线更准

建模高手的一个重要追求是"**全四边面布线**"。新手不用强求，但知道有这个目标。

---

## 三、三种选择模式

进入编辑模式后，按主键盘数字切换：

| 键 | 模式 | 操作对象 |
|---|---|---|
| `1` | **顶点模式** | 单个顶点 |
| `2` | **边模式** | 一条边 |
| `3` | **面模式** | 一个面 |

**注意**：这里的 `1/2/3` 是**主键盘的数字键**，不是小键盘（小键盘 1/3/7 是视图切换）。

### 3D 视图左上角的按钮

除了快捷键，也可以点 3D 视图左上角的三个图标切换。图标从左到右对应 顶点/边/面。

### 组合选择模式

按住 `Shift` 点图标可以**同时启用多个选择模式**。不过新手阶段保持单一模式就够了。

---

## 四、选择操作

### 基础选择

| 操作 | 说明 |
|---|---|
| **左键** | 选中单个 |
| **Shift + 左键** | 加选 / 减选 |
| **A** | 全选 |
| **Alt + A** | 取消全选 |
| **Ctrl + I** | 反选 |
| **B** | 框选 |
| **C** | 刷选 |

### 编辑模式专属选择

| 操作 | 说明 |
|---|---|
| **L** | 选中**鼠标悬停处的连通块**（整个相连的几何体） |
| **Alt + 左键** | 选中**边环 / 面环** |
| **Ctrl + 左键** | 选中**最短路径** |
| **Ctrl + +** | 扩展选择（向外扩一圈） |
| **Ctrl + -** | 收缩选择 |
| **Ctrl + L** | 选中所有**已选中的连通体**的全部 |

这些都非常常用，一定要练熟。

---

## 五、Alt + 左键：环选

这是编辑模式里最强大的选择方式之一。

### 边模式下：边环（Edge Loop）

`Alt + 左键` 一条边 → 选中**一整圈平行的边**。

适合：给圆柱每一圈边做倒角、选中一圈做缩放。

### 边模式下：边链（Edge Ring）

`Ctrl + Alt + 左键` → 选中**垂直于这条边的一圈**。

### 面模式下：面环

`Alt + 左键` 一个面 → 选中**一整排相邻的面**。

### 点模式下

`Alt + 左键` → 选中经过这个点的一圈边上的所有点。

---

## 六、Ctrl + 左键：路径选择

先点一个元素 → `Ctrl + 左键` 另一个元素 → Blender 自动选中两点之间的**最短路径**。

例如：顶点模式下，选中一个角 → `Ctrl + 左键` 另一个角 → 中间一连串顶点都被选中。

---

## 七、隐藏与显示（编辑模式）

编辑模式里的隐藏是临时的，只影响编辑视图，不影响物体模式的显示。

| 快捷键 | 作用 |
|---|---|
| `H` | 隐藏选中的点/边/面 |
| `Shift + H` | 隐藏未选中 |
| `Alt + H` | 显示全部 |

**特别有用**：把外壳隐藏，编辑内部结构。

---

## 八、编辑模式的变换

物体模式的 `G/R/S` 在编辑模式里完全通用，只不过作用对象变成了**点/边/面**：

- `G` → 移动选中点/边/面
- `R` → 旋转选中
- `S` → 缩放选中
- `G X 2` → 沿 X 移动 2 米
- `Alt + G` → 将选中点归零位置（谨慎用，可能坍缩几何）

**注意**：编辑模式里"缩放到 0" 会把选中点/边/面**坍缩为同一个位置**，相当于合并——`S Z 0` 可以快速把一列点压扁成一条水平线。

---

## 九、删除

选中要删的元素，按 `X` 或 `Delete`，弹出菜单选择删除类型：

| 选项 | 作用 |
|---|---|
| **顶点** | 删除顶点，相关边和面也没了 |
| **边** | 删除边，相邻面也没了 |
| **面** | 只删面，边和顶点保留 |
| **仅边和面** | 删除边和面，顶点保留 |
| **仅面** | 只删面 |
| **所有面** | 同上 |
| **仅孤立顶点** | 删除没有连边的顶点 |
| **限制溶解** | 把边变透明但保留顶点 |

### 溶解（Dissolve）vs 删除（Delete）

- **删除**：直接移除，可能留下洞
- **溶解**：移除元素，但**相邻的面会合并填补**，不会留洞

溶解快捷键：`Ctrl + X`

**溶解的典型用例**：清理多余的环形切线、简化网格。

---

## 十、取消切换：Tab 的副作用

在某些特殊场景（如刚添加物体），按 `Tab` 不一定立刻进入编辑模式。Blender 5.x 默认总是进入编辑模式，一般不会有问题。

如果 `Tab` 没反应，检查：
- 是否选中了一个**网格**物体？
- 是否当前是**物体模式**？
- 是否被其他修改器锁定？

---

## 十一、多物体编辑

Blender 支持**同时编辑多个物体**：

1. 物体模式选中多个网格物体
2. `Tab` 进入编辑模式
3. 所有选中物体都变成编辑状态
4. 可以同时操作它们的点/边/面

这在做对称编辑和同步修改时非常方便。

---

## 十二、法线显示（预告）

每个面都有一个"**法线**"——一个垂直于面的方向，代表"面朝外还是朝内"。法线决定了光照和渲染效果。

- 正常的面：法线朝外
- 反转的面：法线朝内（可能显示为黑色或不正确的光照）

编辑模式里可以在 **叠加层（Overlays）** 菜单（3D 视图右上角的两个圆交叠图标）→ **几何体** → **法线** 勾选显示法线。

法线问题的修复方法会在 4.7 节详细讲。

## 动手练习 4.1

### 练习 A：基础切换
1. 默认立方体，`Tab` 进入编辑模式
2. 注意到所有点都被选中（橙色）
3. `Alt + A` 取消全选
4. 按 `1` 切换到顶点模式，左键点一个角 → 选中
5. 按 `2` 切换到边模式，左键点一条边 → 选中
6. 按 `3` 切换到面模式，左键点一个面 → 选中
7. `Tab` 退出编辑模式

### 练习 B：Alt 环选
1. 删除默认立方体，添加一个柱体（保持默认 32 边）
2. `Tab` 进入编辑模式，按 `2` 边模式
3. `Alt + A` 取消全选
4. `Alt + 左键` 点柱体侧面的一条**竖直边** → 选中一整圈竖边
5. `Alt + 左键` 点柱体侧面的一条**水平边** → 选中一圈水平边

### 练习 C：L 键
1. 在同一个柱体里，进入编辑模式
2. `Alt + A` 取消全选
3. 把鼠标悬停在柱体上，按 `L` → 整个柱体被选中

### 练习 D：扩展选择
1. 面模式，选中一个面
2. 按 `Ctrl + +`（主键盘的加号）→ 选择向外扩一圈
3. 再按几次 → 越扩越多
4. `Ctrl + -` → 向内收缩

### 练习 E：删除与溶解
1. 添加一个立方体，进入编辑模式
2. 面模式，选一个面
3. `X` → "仅面" → 留下一个洞
4. `Ctrl + Z` 撤销
5. 边模式，选一条边
6. `Ctrl + X` → 边被溶解，但相邻面合并，没留洞

### 练习 F：多物体编辑
1. 物体模式，添加两个立方体，相距 3 米
2. `Shift + 点击` 同时选中
3. `Tab` 进入编辑模式
4. `A` 全选 → 两个立方体的所有点都选中
5. `S 2` → 两个立方体同时被放大
