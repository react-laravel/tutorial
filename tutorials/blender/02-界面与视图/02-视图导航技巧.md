# 2.2 视图导航技巧

> **这是整个教程最关键的一节**。视图导航不熟，后面每一步操作都会很痛苦。请务必把本节的所有操作练到**不用思考就能做**的地步。

---

## 视图导航的三大核心动作

3D 工作最基本的需求就是"绕着物体看"。Blender 把这拆成三个动作：

| 动作 | 说明 | 生活类比 |
|---|---|---|
| **旋转（Orbit）** | 绕着焦点转圈 | 拿着手机环绕一件物品拍照 |
| **平移（Pan）** | 左右上下移动视图 | 拿着画板左右移动 |
| **缩放（Zoom）** | 拉近拉远 | 相机变焦 |

---

## 一、三键鼠标操作（首选）

| 操作 | 快捷键 |
|---|---|
| **旋转视图** | 按住 **中键（滚轮）** 拖动 |
| **平移视图** | `Shift + 中键` 拖动 |
| **缩放视图** | 滚动滚轮 / `Ctrl + 中键` 拖动 |
| **聚焦到光标位置** | `Alt + 中键 点击` |

### 旋转的焦点在哪？

Blender 默认绕**选中物体的中心**旋转。如果没有选中任何物体，就绕视图中心旋转。

**常见困扰**：你点击空白处不小心取消了选择，然后转视图，结果视图往奇怪的地方跑——这就是焦点丢了。解决办法：选中物体 → 按小键盘 `.` 聚焦回来。

---

## 二、触控板/单键鼠标操作

没有三键鼠标？偏好设置 → 输入 → 勾选 **模拟三键鼠标**，然后用：

| 操作 | 替代方式 |
|---|---|
| 旋转 | `Alt + 左键` 拖动 |
| 平移 | `Shift + Alt + 左键` 拖动 |
| 缩放 | `Ctrl + Alt + 左键` 拖动 |

不过老实说——去买一只真三键鼠标吧，体验天差地别。

### MacBook 触控板手势

macOS 下可启用多点触控：
- 两指拖动 = 旋转
- 两指+Shift = 平移
- 两指捏合 = 缩放

在偏好设置的输入里可以配置。

---

## 三、小键盘预设视角（必背）

| 键 | 作用 |
|---|---|
| `Num 1` | 前视图（-Y 方向看） |
| `Ctrl + Num 1` | 后视图 |
| `Num 3` | 右视图（+X 方向看） |
| `Ctrl + Num 3` | 左视图 |
| `Num 7` | 顶视图（+Z 方向看） |
| `Ctrl + Num 7` | 底视图 |
| `Num 5` | **正交 / 透视切换** |
| `Num 0` | **相机视角** |
| `Ctrl + Num 0` | 将当前选中物体设为相机 |
| `Num .` (小数点) | **聚焦到选中物体** |
| `Num /` | 本地/全局视图切换（只显示选中） |
| `Num 2 / 4 / 6 / 8` | 视图小幅旋转（每按一次转 15°） |
| `Num + / -` | 缩放 |

### 正交 vs 透视

**正交视图（Orthographic）**：平行光投影，没有近大远小。适合精确对齐和建模。

**透视视图（Perspective）**：模拟人眼，近大远小。看起来更自然，但对齐时容易被欺骗。

**建模阶段建议经常在 `Num 5` 切换这两种模式——正交用于对齐，透视用于检查比例是否正常**。

---

## 四、聚焦（Focus）技巧

### 聚焦选中物体：`Num .`（句点）

选中物体后按 `Num .`，视图会对准这个物体并适当缩放。**这个快捷键使用频率极高，必须练到肌肉记忆**。

### 全部显示：`Home`

按 `Home` 键让视图显示场景中**所有物体**。找不到东西时按这个键。

### 框选缩放：`Shift + B`

按 `Shift + B`，鼠标画一个框，Blender 会放大到这个框的区域。在精细建模时很好用。

### 视图到选择：`View` 菜单 → `视图到选择`

和 `Num .` 类似，但可以通过菜单执行（适用于没有小键盘时）。

---

## 五、飞行与行走模式（高阶）

想像玩 FPS 游戏一样在场景里走？

- `Shift + \``（反引号，Tab 键上方）进入**行走模式**
  - `W/A/S/D` 前后左右移动
  - 鼠标控制视角
  - 空格上升，`Ctrl` 下降
  - 左键确认位置，右键/Esc 取消

这对探索大场景非常有用，新手阶段用不到但知道一下。

---

## 六、锁定视图跟随物体

在侧栏（N）→ 视图标签 → **锁定**：

- **到物体**：视图永远围绕某个指定物体旋转
- **到 3D 游标**：围绕 3D 游标旋转
- **相机到视图**：视图移动时相机跟着移动（调构图用）

---

## 七、视图的本地与全局

### 切换到局部视图：`Num /`

选中某个物体按 `Num /`，Blender 会**只显示这一个物体**，隐藏其他所有物体。再按一次回到全局视图。

当你的场景很复杂、想专心调一个物体时，这个功能很贴心。

---

## 八、视图导航的底层逻辑

### "焦点"是什么？

Blender 视图的**旋转中心**称为焦点。它会在以下时刻更新：
1. 选中新物体时
2. 按 `Num .` 聚焦时
3. 按 `Home` 时
4. `Alt + 中键` 点击空间某一点时

**理解焦点可以帮你避开 80% 的"视图失控"问题**。

### 为什么我的视图"飞走了"？

常见原因：
1. 焦点太远 → 按 `Home` 或 `Num .` 拉回来
2. 意外放大到微观尺度 → `Home` 重置
3. 误触了相机模式 → 按 `Num 0` 看看，再退出

---

## 九、3D 光标是旋转中心吗？

**不是**。3D 光标是**添加物体的位置**，而不是旋转的焦点。许多新手误以为游标就是旋转中心，然后发现怎么转都不对——其实这两者完全独立。

不过你可以在侧栏 → 视图标签里勾选 **"围绕 3D 游标"**，强制以游标为旋转中心。

## 动手练习 2.2

这是关键练习，**务必做到不假思索**：

### 基础练习

1. 选中默认立方体
2. 按 `Num 1` 看前视图
3. 按 `Num 3` 看右视图
4. 按 `Num 7` 看顶视图
5. 按 `Num 5` 在正交和透视之间切换
6. 中键拖动自由旋转视图
7. `Shift + 中键` 平移视图
8. 滚轮缩放
9. 按 `Num .` 聚焦回立方体中心

### 进阶练习：迷路救命术

故意把视图搞乱：快速缩放 + 平移 + 旋转，让立方体飞出画面。然后用以下任一方法找回来：

- `Home` 键
- 选中立方体 → `Num .`
- 侧栏（N）→ 视图 → 视图 → 显示全部

**反复练习到直觉**。

### 综合练习

1. 删掉默认立方体（`X`）
2. `Shift + A` → 网格 → **猴头 (Suzanne)**
3. 围绕猴头转一圈，从不同角度看它
4. 按 `Num 1/3/7` 分别看前、右、顶视图
5. 按 `Num 5` 在正交和透视切换
6. `Num /` 进入局部视图
7. 按 `Num 0` 进入相机视角（如果场景还有相机的话）
8. 按 `Num 0` 再按一次退出相机

## 检查你是否学会了

问自己：

- [ ] 我能在 1 秒内从任何视角切到"前视图"吗？
- [ ] 视图转乱了我能立刻找回选中物体吗？
- [ ] 我知道正交和透视的区别吗？
- [ ] 我能流畅地围绕物体自由旋转而不迷失方向吗？

四个问题都能答"是"再进入下一节。
