# 2.3 坐标系、3D 游标与吸附

> 本节讲 Blender 里"位置"的概念。理解了坐标系和 3D 游标，你才能精确地在空间中放置物体。

---

## 一、世界坐标系

Blender 里所有物体都活在一个**三维笛卡尔坐标系**里：

- **X 轴**：红色，左右方向
- **Y 轴**：绿色，前后方向
- **Z 轴**：蓝色，上下方向（**Blender 用 Z 轴作为垂直轴**，这和 Maya/Unity 不同）

**记忆法**：**红X左右，绿Y前后，蓝Z天地**。

坐标 `(0, 0, 0)` 是**世界原点**，在视图中央地板栅格的交叉点。

### 正负方向

- +X：右（默认右视图看的方向是 +X）
- +Y：内（远离默认视角的方向）
- +Z：上

---

## 二、正方向与默认视角的关系

- `Num 1` 前视图：沿 -Y 方向看（你在 +Y，物体在前方）
- `Num 3` 右视图：沿 -X 方向看
- `Num 7` 顶视图：沿 -Z 方向看（你在 +Z，往下看）

这解释了为什么按 `Num 1` 之后，屏幕上的 X 朝右、Z 朝上。

---

## 三、3D 游标（3D Cursor）

3D 游标是一个**红白条纹的十字圈**，默认在世界原点。它有两个作用：

### 作用 1：新物体的出生位置

按 `Shift + A` 添加的任何物体，**都会出现在游标所在位置**。

### 作用 2：变换的参考点

你可以把它设为变换轴心（pivot），让旋转和缩放围绕它进行。

---

## 四、操作 3D 游标

### 快捷键

| 操作 | 快捷键 |
|---|---|
| 游标归零（回到世界原点） | `Shift + C` |
| 游标移动到当前鼠标位置 | `Shift + 右键` 点击 |
| 精确设置游标位置 | 侧栏 N → 视图标签 → 3D 光标 |

### 吸附菜单：`Shift + S`

按 `Shift + S` 弹出一个饼状菜单，里面有各种"吸附/对齐"命令：

| 命令 | 作用 |
|---|---|
| **游标 → 世界原点** | 游标归零（同 `Shift + C`） |
| **游标 → 选中项** | 游标移到所选物体中心 |
| **游标 → 栅格** | 游标吸附到最近的栅格点 |
| **选中项 → 游标** | 把所选物体移到游标位置 |
| **选中项 → 栅格** | 物体吸附到栅格 |
| **选中项 → 活动项** | 所选物体对齐到最后选中的那个 |

**`Shift + S` 是建模时极其常用的快捷键**。务必记住。

---

## 五、轴心点（Pivot Point）

轴心点决定旋转和缩放**围绕哪个点进行**。3D 视图头部栏中间有一个"**变换轴心点**"下拉，或按 `.` (句点，不是小键盘) 弹出饼菜单。

### 六种轴心模式

| 模式 | 说明 |
|---|---|
| **边界框中心（Bounding Box Center）** | 默认，所有选中物的外包盒中心 |
| **3D 游标** | 游标位置 |
| **各自原点（Individual Origins）** | 每个物体绕自己原点 |
| **质心（Median Point）** | 所有选中物的平均位置 |
| **活动元素（Active Element）** | 最后选中的那一个 |

### 什么时候改轴心点

- **默认大多数情况用"中位点"**
- 要让多个物体各自原地自转？→ **各自原点**
- 要让物体围绕场景某一点旋转？→ 先把游标放那里 → **3D 游标**

---

## 六、变换坐标系（Transform Orientation）

变换方向决定 X/Y/Z 轴**按谁的方向**。3D 视图头部栏上有"变换方向"下拉。

### 常见选项

| 方向 | 说明 |
|---|---|
| **全局（Global）** | 世界坐标系，默认 |
| **局部（Local）** | 物体自身的坐标系 |
| **法向（Normal）** | 按面/点的法线方向 |
| **视图（View）** | 当前视角方向 |
| **自定义（Custom）** | 手动指定 |

**新手阶段保持"全局"即可**，等到做倾斜物体上的细节时再切换到"法向"或"局部"。

---

## 七、吸附工具（Snap）

吸附是"磁性对齐"功能——让物体在移动时自动对齐到某个参考。

### 开启吸附

- **临时吸附**：变换时按住 `Ctrl` 键
- **永久吸附**：点击 3D 视图头部的"**磁铁图标**"（或 `Shift + Tab`）

### 吸附目标

点磁铁旁边的下拉框可以选择吸附到什么：

| 目标 | 作用 |
|---|---|
| **增量（Increment）** | 按固定网格步长吸附（默认 1 单位） |
| **顶点（Vertex）** | 吸附到其他物体的顶点 |
| **边（Edge）** | 吸附到边 |
| **面（Face）** | 吸附到面 |
| **体积（Volume）** | 吸附到体积内 |
| **边中点** | 吸附到边的中点 |
| **边垂线** | 吸附到边的投影垂点 |

### 吸附实战

要把一个物体精确放到另一个物体的角点上：

1. 开启吸附，目标选 **顶点**
2. 选中要移动的物体
3. 按 `G` 移动，把鼠标悬停到目标顶点附近
4. Blender 自动吸附过去
5. 左键确认

---

## 八、场景单位设置

属性编辑器 → 场景属性（倒数第二行的 🌍） → **单位**：

- **单位系统（Unit System）**：**公制** / 英制 / 无
- **长度单位（Length）**：米 / 厘米 / 毫米 / ...
- **单位比例（Unit Scale）**：通常保持 1.0

**做建筑、家具建议用"米"；做小道具用"厘米"**。不同尺度适用不同单位以避免数字过大或过小。

---

## 九、精确坐标输入

### 侧栏 N 的"项"面板

选中物体后按 `N`，侧栏的"项"标签显示：

- **位置 X/Y/Z**：世界坐标
- **旋转 X/Y/Z**：欧拉角（度数）
- **缩放 X/Y/Z**：相对 1.0 的缩放
- **尺寸 X/Y/Z**：物体外包盒实际尺寸

可以**直接点数字输入精确值**。输入时可以用数学表达式：`2*0.5` 会算成 `1`。

### 变换时输入

在按 `G/R/S` 的过程中直接敲数字：
- `G Z 2` → 沿 Z 轴移动 2 单位
- `R Z 45` → 绕 Z 轴旋转 45 度
- `S 0.5` → 缩放到一半

---

## 十、清空变换

有时候变换多了想"归零"：

| 快捷键 | 作用 |
|---|---|
| `Alt + G` | 清空位置（物体飞回原点） |
| `Alt + R` | 清空旋转 |
| `Alt + S` | 清空缩放 |

**注意**：清空位置不是删掉物体，而是把位置归 `(0,0,0)`。

---

## 动手练习 2.3

1. 把默认立方体删掉 (`X`)
2. `Shift + C` 游标归零，再按 `Shift + A` 添加一个猴头 Suzanne，确认它出现在原点
3. `Shift + 右键` 在空间某处点一下，游标跑到那里；再 `Shift + A` 添加一个球，球在新位置
4. 选中球，`Shift + S` → "选中项 → 游标"，再把游标 `Shift + C` 归零，然后 `Shift + S` → "选中项 → 游标"，球回到原点
5. 打开吸附（磁铁），设为"顶点"，选中猴头，按 `G` 移动到球的某个顶点上，观察磁吸效果
6. 按 `N` 看看猴头的位置、旋转、尺寸数值，直接修改位置 X 为 `3`，确认物体跳过去
7. 按 `Alt + G` 让它归零
8. 改变轴心点（点 3D 视图顶部的下拉，选"3D 游标"），然后选中猴头按 `R` 旋转，观察它是绕游标而不是绕自身旋转
