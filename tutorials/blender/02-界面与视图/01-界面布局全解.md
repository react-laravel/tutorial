# 2.1 界面布局全解

> 本节把 Blender 默认界面**每一块区域**都拆开讲清楚。看完这节你再打开 Blender，应该能准确叫出每个区域的名字和作用。

---

## 总览：界面由编辑器拼接而成

Blender 的界面不是一成不变的——它由若干**编辑器（Editor）** 拼接而成。每个编辑器是一块功能独立的区域，可以自由分割、合并、替换类型。

默认场景启动后，你看到的是一种预设布局，包含以下几个编辑器：

```
┌────────────────────────────────────────────┐
│           顶部栏 + 工作区标签                 │
├─────────────────────────────┬──────────────┤
│                             │  大纲视图     │
│                             ├──────────────┤
│         3D 视图              │              │
│       （中间最大的）          │  属性编辑器    │
│                             │              │
├─────────────────────────────┴──────────────┤
│                 时间线                      │
└────────────────────────────────────────────┘
```

---

## 一、顶部栏（Topbar）

位于窗口最上方，从左到右包含：

### 1. 应用菜单（File / Edit / Render / Window / Help）

- **文件（File）**：新建、打开、保存、导入导出
- **编辑（Edit）**：撤销、重做、偏好设置
- **渲染（Render）**：渲染图像 (F12)、渲染动画
- **窗口（Window）**：新建窗口、截图、切换全屏
- **帮助（Help）**：手册、版本信息

### 2. 工作区标签

一排标签：**布局 / 建模 / 雕刻 / UV 编辑 / 纹理绘制 / 着色 / 动画 / 渲染 / 合成 / 几何节点 / 脚本**

每个标签是一套**预设窗口布局**。点不同标签会切换到为该任务优化的界面。新手阶段主要使用：
- **布局（Layout）**：日常综合工作区
- **建模（Modeling）**：对 3D 视图加强的建模布局
- **着色（Shading）**：下半部分变成节点编辑器，用于做材质
- **渲染（Rendering）**：显示渲染结果的编辑器

### 3. 场景与视图层

顶部栏最右侧的两个下拉框：
- **场景（Scene）**：一个 .blend 文件可以包含多个独立场景
- **视图层（View Layer）**：用于高级渲染分层，新手暂时不管

---

## 二、3D 视图（3D Viewport）

**这是你 90% 时间所在的区域**。中间最大的黑色（深灰）窗口就是它。

### 3D 视图的组成

```
┌──────────────────────────────────────────────┐
│ [模式下拉] [视图][选择][添加][物体]  [导航 gizmo]│  ← 头部
├──────────────────────────────────────────────┤
│                                              │
│  [工具栏]                         [小工具]   │
│   T          3D 视图主区域          轴向     │
│                                              │
│                                     [侧栏 N]│
├──────────────────────────────────────────────┤
│         [选中物体信息栏]                     │  ← 底部状态栏
└──────────────────────────────────────────────┘
```

#### 头部栏（Header）

顶部灰条从左到右：

1. **模式选择下拉**：物体模式 / 编辑模式 / 雕刻模式 / ...
2. **视图菜单**：视图操控命令
3. **选择菜单**：选择相关命令（全选、反选、随机选等）
4. **添加菜单**：等同于 `Shift + A` 的添加物体菜单
5. **物体菜单**：物体相关操作
6. **右上角的视图小工具**：轴向导航、切视图、相机等

#### 左侧工具栏（T 键切换）

一列纵向排列的工具图标。新手常用：
- **选择工具**（箭头）
- **游标**
- **移动 / 旋转 / 缩放 / 变换**（其实都有快捷键 G/R/S，但图标也能用）
- **注释** 等

**按 `T` 键可以切换显示/隐藏**。

#### 右侧侧栏（N 键切换）

**按 `N` 键**打开一个纵向面板，分多个选项卡：

| 标签 | 作用 |
|---|---|
| **项（Item）** | 选中物体的位置、旋转、缩放、尺寸 |
| **工具（Tool）** | 当前工具的参数 |
| **视图（View）** | 视图参数、锁定、相机到视图等 |

**最常看的是"项"选项卡**——可以直接输入数字精确控制物体位置。

#### 3D 视图右上角的 Gizmo

一个彩色的小坐标轴，显示当前视角方向。你可以：
- **点击红/绿/蓝轴**：切换到正视图
- **按住拖动**：自由旋转视角

下方几个小图标：
- **镜头**：切换正交/透视
- **相机**：切换到相机视角
- **手型**：平移视图
- **放大镜**：缩放视图

#### 着色模式切换（右上角 4 个球）

决定 3D 视图里的显示方式：

| 图标 | 名称 | 说明 |
|---|---|---|
| 线框 | Wireframe | 只显示线框，最快 |
| 实体 | Solid | 默认，显示灰色实体 |
| 材质预览 | Material Preview | 显示材质和环境反射，**新手推荐** |
| 渲染预览 | Rendered | 真正的渲染效果，实时光线追踪 |

**快捷键**：`Z` 键显示饼状菜单快速切换。

---

## 三、大纲视图（Outliner）

右上角的树状列表。它是**场景中所有物体的清单**。

### 层级结构

```
场景集合
├─ 集合（Collection）
│  ├─ 立方体 (物体)
│  │  └─ 立方体 (网格数据)
│  │     └─ 材质 (材质槽)
│  ├─ 点光
│  └─ 相机
```

### 各列图标

- **眼睛图标 👁**：在视口中显示/隐藏
- **相机图标 📷**：渲染时显示/隐藏（有的文件还会有）
- **🔒**：锁定，不可选中

### 常用操作

- **左键**：选中物体
- **双击名称**：重命名
- **右键**：弹出菜单
- **拖动**：调整层级，或把物体放进其他集合
- **M 键**（在 3D 视图选中物体后）：移动到集合

---

## 四、属性编辑器（Properties）

右下角那一堆图标的面板。它是 Blender 里**信息密度最高**的区域。

### 左侧图标栏（从上到下）

| 图标 | 名称 | 作用 |
|---|---|---|
| 🎬 活动工具 | Active Tool | 当前工具参数 |
| 📺 渲染 | Render | 渲染引擎和渲染相关设置 |
| 🖨 输出 | Output | 分辨率、帧率、输出路径 |
| 🏞 视图层 | View Layer | 视图层设置 |
| 🌍 场景 | Scene | 场景级参数（重力、单位） |
| 🌐 世界 | World | 世界背景、HDRI、环境光 |
| 📦 集合 | Collection | 集合属性 |
| 🟧 物体 | Object | 物体变换、显示等 |
| 🔧 修改器 | Modifier | **扳手图标，修改器堆栈** |
| ✨ 粒子 | Particle | 粒子系统 |
| ⚛ 物理 | Physics | 物理模拟 |
| 📐 物体约束 | Constraints | 约束 |
| 🔺 物体数据 | Object Data | **绿色三角形，网格数据** |
| 🔲 材质 | Material | **红白球，材质槽和节点** |
| 🖼 纹理 | Texture | 旧版纹理槽（已少用） |

**新手阶段最常点的三个**：
1. 扳手（修改器）
2. 红白球（材质）
3. 绿三角（物体数据，调平滑着色等）

---

## 五、时间线（Timeline）

底部那条长条。包含：

- **帧号滑块**：当前时间
- **播放/暂停/下一帧** 按钮
- **关键帧标记**：动画用
- **开始帧 / 结束帧** 输入框

新手阶段用不到，但别关掉它（关了以后做动画又得找回来）。

---

## 六、状态栏（Status Bar）

窗口最底部的细条。显示：

- 当前版本号
- 选中物体的信息（顶点数、面数）
- 剩余内存等系统信息

可以右键菜单里自定义显示哪些信息。

---

## 自定义布局

### 分割与合并编辑器

把鼠标移到**任意编辑器的边缘**，光标变成双向箭头后：
- **左键拖动**：调整大小
- **右键**：弹出菜单，可选 "垂直分割"、"水平分割"、"合并区域"
- **按住角落的斜线区域往内拖**：分割
- **往外拖**：合并

### 切换编辑器类型

每个编辑器的左上角有一个小图标——点它可以切换这个区域到其他编辑器类型（比如把 3D 视图改成节点编辑器）。

### 最大化编辑器

- `Ctrl + 空格`：最大化/还原当前编辑器
- `Ctrl + Alt + 空格`：全屏（隐藏标题栏）

---

## 动手练习 2.1

1. 分别按 `T` 和 `N` 打开/关闭工具栏和侧栏，感受布局变化
2. 点击顶部"建模"标签，再切回"布局"，观察差异
3. 在 3D 视图右上角点击 **实体/材质预览/渲染** 切换着色模式，看立方体的显示变化
4. 按 `Z` 弹出着色模式饼菜单，用鼠标选择切换
5. 在大纲视图里，点击眼睛图标隐藏默认立方体，再点一次显示
6. 点击属性编辑器左侧的**红白球图标**，看看材质属性面板长什么样
7. 把鼠标放在 3D 视图和大纲视图之间的竖直边界上，拖动调整宽度
8. 按 `Ctrl + 空格` 最大化 3D 视图，再按一次还原

全部熟练后进入下一节，练习视图导航。
