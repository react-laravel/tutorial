# 2.4 工作区与编辑器

> 本节讲 Blender 的工作区系统和编辑器类型。理解后你就能针对不同任务切换到最合适的界面。

---

## 一、什么是工作区（Workspace）

顶部那排标签：**布局 / 建模 / 雕刻 / UV 编辑 / 纹理绘制 / 着色 / 动画 / 渲染 / 合成 / 几何节点 / 脚本**。

每个标签就是一个**工作区**——预设好的界面布局，针对某类任务优化。点不同标签，整个界面会瞬间重组。

### 工作区的本质

工作区 = **编辑器的分割布局 + 预设参数**。它不会改变你的数据，只是改变你看数据的方式。你在任一工作区做的操作都会同步到所有工作区（因为数据是共享的）。

---

## 二、默认工作区一览

### 布局（Layout）— 默认

- 中央：3D 视图
- 右上：大纲视图
- 右下：属性编辑器
- 底部：时间线

**这是 Blender 的"首页"**。大部分操作都可以在这里完成。新手阶段 80% 时间待在这里。

### 建模（Modeling）

- 3D 视图最大化（去掉了顶部时间线）
- 物体已自动进入编辑模式
- 左侧工具栏更完整

**专用于编辑模式建模**。其实和"布局"差别不大，只是布局更适合"纯建模"任务。

### 雕刻（Sculpt）

- 顶部有雕刻笔刷面板
- 左侧是详尽的雕刻工具栏
- 3D 视图已进入雕刻模式

**做高模雕刻时切到这个工作区**。

### UV 编辑（UV Editing）

- 屏幕左半：UV 编辑器
- 屏幕右半：3D 视图（编辑模式）

**专用于展 UV**。第 6 章会大量使用。

### 纹理绘制（Texture Paint）

- 左侧：图像编辑器显示贴图
- 右侧：3D 视图在纹理绘制模式

**直接在 3D 模型上画贴图**。

### 着色（Shading）

- 上半部分：3D 视图（材质预览模式）
- 下半部分：**Shader 节点编辑器**

**做材质时的主工作区**。第 6 章会用到。

### 动画（Animation）

- 包含时间线、动画曲线编辑器、摄影表
- 3D 视图侧有动画相关面板

**做动画时使用**。本教程不涉及。

### 渲染（Rendering）

- 图像编辑器显示渲染结果
- 一般渲染完 `F12` 后 Blender 会自动切到这里

**查看渲染结果**。

### 合成（Compositing）

- 合成节点编辑器
- 右侧是节点预览

**做后期合成时使用**，本教程不涉及。

### 几何节点（Geometry Nodes）

- 下半部分是几何节点编辑器

**用于程序化建模**，进阶内容。

### 脚本（Scripting）

- Python 控制台 + 文本编辑器 + 信息面板

**Python 脚本编程用**，进阶内容。

---

## 三、新手应该常用的工作区

新手阶段只需要熟练使用：

1. **布局**（90% 时间）
2. **建模**（10% 时间，或者直接在布局里按 Tab 进编辑模式）
3. **着色**（做材质时）
4. **UV 编辑**（展 UV 时）
5. **渲染**（出图后查看）

其他工作区先不管。

---

## 四、工作区切换的快捷键

- `Ctrl + Page Up` / `Ctrl + Page Down`：切换到下一个 / 上一个工作区
- **点击标签名**：直接跳转

---

## 五、编辑器类型详解

每个编辑器区域都可以通过左上角的"**编辑器类型**"图标切换成其他类型。Blender 有十几种编辑器：

### 3D 视图（3D Viewport）
- 图标：3D 立方体
- 用途：查看和编辑 3D 场景

### 图像编辑器（Image Editor）
- 图标：图片
- 用途：显示和编辑图片、渲染结果、UV

### UV 编辑器（UV Editor）
- 图标：UV
- 用途：展 UV 时编辑 UV 岛屿

### Shader 编辑器（Shader Editor）
- 图标：红白球
- 用途：节点式材质编辑

### 几何节点编辑器（Geometry Nodes Editor）
- 图标：几何点
- 用途：节点式建模

### 合成节点编辑器（Compositor）
- 图标：相机
- 用途：后期合成

### 视频序列编辑器（Video Sequence Editor）
- 图标：胶片
- 用途：视频剪辑

### 影片剪辑编辑器（Movie Clip Editor）
- 图标：影片
- 用途：跟踪和相机追踪

### 动画编辑器类（Dope Sheet / Graph / Nonlinear）
- 用途：动画曲线和关键帧

### 文本编辑器（Text Editor）
- 图标：文本
- 用途：写 Python 脚本或注释

### Python 控制台（Python Console）
- 图标：">_"
- 用途：交互式 Python 命令

### 信息（Info）
- 图标：i
- 用途：显示日志和操作历史

### 大纲视图（Outliner）
- 图标：清单
- 用途：场景清单

### 属性编辑器（Properties）
- 图标：属性
- 用途：物体属性面板

### 文件浏览器（File Browser）
- 图标：文件夹
- 用途：浏览文件系统

### 资产浏览器（Asset Browser）
- 图标：文件夹
- 用途：管理资产库

### 偏好设置（Preferences）
- 图标：齿轮
- 用途：调节 Blender 设置

## 六、自定义工作区

### 修改现有工作区

直接在某个工作区里拖动编辑器边缘、分割合并区域，改完自动保存。下次打开 Blender 这个工作区还是你改的样子。

### 新建工作区

工作区标签栏最右侧有个 **"+"** 按钮，点它会弹出"添加工作区"菜单，可以：
- 从现有模板复制一个
- 创建空白工作区

### 删除 / 重命名

**右键** 点击工作区标签：
- **删除**
- **重命名**
- **复制**

---

## 七、右键 Python 快速查询

Blender 的每个控件（包括菜单、按钮、输入框）都支持右键查询：

- **右键** → **在线 Python 参考**：直接打开 API 文档
- **右键** → **编辑源**：查看对应源代码
- **右键** → **复制数据路径**：获得这个属性的 Python 路径

这是 Blender 最棒的开发者设计之一。你随时可以了解"这个按钮背后到底在做什么"。

---

## 八、多窗口与全屏

### 多窗口

菜单：`窗口` → `新窗口`，会复制一个新的 Blender 窗口。你可以在不同窗口显示不同工作区，适合多显示器用户。

### 全屏

- `Ctrl + 空格`：将当前编辑器最大化（保留顶部栏）
- `Ctrl + Alt + 空格`：真全屏（隐藏顶部栏）

---

## 九、恢复默认布局

如果你把界面弄乱了，不想手动复原：

菜单：`文件` → `默认` → `加载出厂设置`

注意这会**重置所有偏好设置**，包括中文语言。所以操作前请确认你能重新设置。

或者：`窗口` → `还原布局`（如果有，某些版本可能在不同位置）

---

## 动手练习 2.4

1. 依次点击所有工作区标签（布局、建模、雕刻、UV 编辑、纹理绘制、着色、动画、渲染、合成、几何节点、脚本），**粗略**看一眼每个工作区的布局
2. 回到"布局"工作区
3. 把右上角的大纲视图切换成 Shader 编辑器（点左上角的图标换类型），再换回大纲视图
4. 把 3D 视图往右拖一点，让它变窄
5. 按 `Ctrl + 空格` 把 3D 视图最大化，再按一次还原
6. 在工作区标签栏右键点一下"雕刻"，选"删除"（你可以随时通过 `+` 重新添加）
7. 把雕刻工作区加回来（点 + → General → Sculpting）
8. 按 `Ctrl + Page Down` 切到下一个工作区，再按 `Ctrl + Page Up` 回来

## 本章小结

学完第 2 章，你应该能：

- ✅ 流畅地用中键操控 3D 视图
- ✅ 用小键盘快速切换正视图、顶视图等
- ✅ 理解 X/Y/Z 轴向，知道 Z 是垂直轴
- ✅ 操作 3D 游标和吸附菜单
- ✅ 在不同工作区之间切换
- ✅ 认识所有默认编辑器

如果你觉得视图导航还不熟练，**不要急着进下一章**——请回到 2.2 再多练几遍。视图操作是下一步一切工作的基础。
