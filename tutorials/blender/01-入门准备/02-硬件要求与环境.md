# 1.2 硬件要求与环境建议

> 硬件决定你能不能"舒服地"学习 Blender。硬件不够不代表不能学，但会让某些操作变卡顿。

---

## 最低配置（能跑）

| 组件 | 最低要求 |
|---|---|
| CPU | 64 位，双核 2GHz，SSE 4.2 |
| 内存 | 8 GB |
| 显卡 | 支持 OpenGL 4.3，2 GB 显存 |
| 硬盘 | 2 GB 安装空间 |
| 显示器 | 1920×1080 |

## 推荐配置（舒服学）

| 组件 | 推荐 |
|---|---|
| CPU | 6 核以上，3GHz+ |
| 内存 | 16 GB 或以上 |
| 显卡 | NVIDIA RTX 30/40 系列，8 GB+ 显存 |
| 硬盘 | SSD，预留 50 GB 以上工作空间 |
| 显示器 | 2K 或以上 |

## 显卡的选择很关键

Blender 的两个渲染引擎对显卡都很敏感：

- **EEVEE Next**：依赖 OpenGL/Vulkan，任何现代独显都能跑
- **Cycles**：支持 **NVIDIA OptiX**（最快）、AMD HIP、Intel oneAPI、Apple Metal

**如果你要买新电脑学 Blender**：闭眼选 NVIDIA 独显。OptiX 加速在 RTX 系列上对光线追踪有硬件支持，Cycles 渲染速度是 CPU 的几十倍。

**核显/集显用户**：可以学，但渲染时只能用 CPU，速度会慢 10–50 倍。建议先学建模、材质这些"轻渲染"的部分，渲染最终图时有耐心一点。

## 外设：三键鼠标 + 数字小键盘

这两样在 Blender 里的重要性**仅次于电脑本身**。

### 为什么必须有三键鼠标

Blender 大量使用**鼠标中键**：
- 按住中键拖动 = 旋转视图
- Shift + 中键 = 平移视图
- 滚动中键 = 缩放
- Ctrl + 中键 = 精确缩放

**触控板用户**：可以在偏好设置里勾选"**模拟三键鼠标**"，用 Alt + 左键代替中键，但体验远不如真鼠标。

### 为什么需要数字小键盘

小键盘的 `1/3/7` 是**切换正视/右视/顶视**的快捷键，`0` 是相机视角，`.` 是聚焦选中物体。这些操作使用频率极高。

**笔记本用户没有小键盘怎么办？**

Blender 提供了**"模拟数字键盘"**选项：
1. 菜单 `编辑` → `偏好设置` → `输入`
2. 勾选 **"模拟数字键盘"**
3. 从此主键盘的 `1–9` 就会映射到小键盘

代价：主键盘的 `1/2/3` 原本是"点/边/面"选择模式切换，模拟后这些功能会被顶替，得用菜单或自定义键位代替。

## 操作系统

| 系统 | 体验 |
|---|---|
| **Windows 10/11** | 支持最完整，社区用户最多 |
| **macOS**（含 Apple Silicon） | 原生支持，Metal 加速 |
| **Linux** | 官方一等公民，稳定性最好 |

三大系统都能跑 Blender 5.1，性能差别不大，按你现有电脑选即可。

## 工作环境建议

### 屏幕分辨率

Blender 的界面元素比较密集，**1080p 是底线**，1440p（2K）会舒服很多，4K 再加上 125%–150% UI 缩放是最佳体验。

界面文字太小？在偏好设置 → 界面 → 缩放调大：
- 1080p：1.0–1.1
- 1440p：1.1–1.2
- 4K：1.5–1.8

### 桌面空间

Blender 的快捷键设计**假设你的左手常驻主键盘区**。桌面上要留出足够空间让鼠标大幅移动——建模时鼠标移动距离远超你想象。

### 安静的环境

Blender 的学习强度很高，需要集中注意力理解空间关系。找个不被打扰的时段学习比硬挤时间高效得多。

## 动手练习 1.2

1. 打开电脑的系统信息，确认：
   - 你的显卡型号
   - 显存大小
   - 系统内存
2. 如果是笔记本，确认你是否需要启用"**模拟数字键盘**"
3. 如果没有中键鼠标，准备借或买一个（真的很关键）
