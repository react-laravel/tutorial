# 1.3 下载安装与中文切换

> 这一节手把手带你完成从下载到第一次看到中文界面的全过程。跟做就行，遇到问题不要慌。

---

## 下载 Blender 5.1.0

### 官方下载地址

**只从官网下载**：`www.blender.org/download`

千万不要从第三方下载站下载，可能被捆绑广告软件。官网下载是完全免费的，不需要账号、不需要邮箱。

### 三种安装包（Windows）

进入下载页后你会看到多种下载方式：

| 类型 | 说明 | 推荐度 |
|---|---|---|
| **Installer (.msi)** | 标准安装程序，会写入注册表 | ⭐⭐⭐ 推荐新手 |
| **Portable (.zip)** | 绿色版，解压即用 | ⭐⭐ 适合多版本共存 |
| **Microsoft Store** | 应用商店版 | ⭐ 更新稍慢 |

### macOS

- **Apple Silicon (M1/M2/M3/M4)**：下载 `macOS Apple Silicon` 的 `.dmg`
- **Intel Mac**：下载 `macOS Intel` 的 `.dmg`

搞不清楚？左上角苹果菜单 → 关于本机，看"芯片"一栏。

### Linux

下载 `.tar.xz`，解压后运行里面的 `blender` 可执行文件即可。大部分发行版的包管理器也有 Blender，但版本可能不是最新。

## 安装步骤

### Windows 安装

1. 双击下载的 `.msi` 文件
2. 点击 `Next` → 同意许可协议 → `Next`
3. 安装位置保持默认（`C:\Program Files\Blender Foundation\Blender 5.1\`）
4. 点击 `Install`，可能会请求管理员权限
5. 完成后从开始菜单找到 "Blender" 启动

### macOS 安装

1. 双击 `.dmg` 文件挂载
2. 将 Blender 图标**拖到 Applications 文件夹**
3. 首次启动时右键点击 → 打开（绕过 Gatekeeper 警告）
4. 之后可以从启动台或 Spotlight 启动

### Linux 安装

```bash
tar -xf blender-5.1.0-linux-x64.tar.xz
cd blender-5.1.0-linux-x64
./blender
```

建议创建一个桌面快捷方式，方便后续启动。

## 首次启动：快速设置向导

第一次启动 Blender 会弹出一个**快速设置（Quick Setup）**对话框。这是中文切换**最简单**的时机！

### 关键选项

**Language（语言）**：
下拉选择 **简体中文 (Simplified Chinese)**。选完后对话框本身不会立刻变中文，但进入主界面后所有菜单都会是中文。

**Shortcuts（快捷键方案）**：
保持默认的 **Blender** 即可。不要选 Industry Compatible，那是为从 Maya/3ds Max 转过来的老用户准备的。

**Select With（选择键）**：
保持默认 **Left**（左键选择）。早期 Blender 用右键选择，现在统一左键了。

**Spacebar（空格键）**：
建议选 **Play** 或 **Tools**，不要选 Search（搜索功能有专门的 F3 键）。

**Theme（主题）**：
保持默认的深色主题 **Blender Dark** 即可，护眼。

完成后点击 **Save New Settings**，这个设置就被永久保存了。

## 已经关闭了向导怎么办？

如果你不小心关闭了快速设置窗口，或者当时没选中文，手动切换步骤：

1. 顶部菜单：`Edit` → `Preferences`
2. 左侧列表选 **Interface**
3. 找到 **Translation** 区块，确认它是展开的
4. **Language** 下拉选 **简体中文 (Simplified Chinese)**
5. 下方勾选三个复选框：
   - ☑️ **Tooltips**（工具提示）
   - ☑️ **Interface**（界面）
   - ☑️ **New Data**（新数据）
6. 关闭偏好设置窗口，所有菜单立刻变为中文

> 💡 **新数据** 这个选项的意思是：新建的物体是否也用中文名（比如 "立方体" 而不是 "Cube"）。**建议勾选**，新手更容易理解。但如果你以后要和英文教程或国外社区交流，也可以关掉这一项。

## 验证安装成功

界面切换到中文后，你应该看到：

- 顶部菜单栏：**文件 / 编辑 / 渲染 / 窗口 / 帮助**
- 左侧工具栏带有中文工具提示
- 场景中有一个**立方体**、一盏**点光**、一台**相机**
- 底部状态栏显示 "Blender 5.1.0"（或类似版本号）

恭喜！你已经成功安装并汉化了 Blender。

## 常见问题

### Q1：启动时显示"无法初始化 OpenGL"
你的显卡驱动太旧，或者显卡不支持 OpenGL 4.3。
- **解决**：升级显卡驱动到最新版本。如果是集显且机器较旧，考虑换机器。

### Q2：启动后界面一闪而过就关闭了
大概率是显卡驱动问题或系统兼容性问题。
- **解决**：
  1. 右键 Blender 图标 → 属性 → 兼容性 → 以管理员身份运行
  2. 更新显卡驱动
  3. 尝试下载 Portable 版

### Q3：中文菜单有些字显示成方块
这是字体回退问题，极少出现在 5.x 版本。
- **解决**：偏好设置 → 界面 → 字体 → 接口字体，指定一个中文字体（如 `C:\Windows\Fonts\msyh.ttc`）。

### Q4：macOS 显示"已损坏无法打开"
Gatekeeper 不识别签名，不是真损坏。
- **解决**：终端运行 `sudo xattr -rd com.apple.quarantine /Applications/Blender.app`

### Q5：我想保留英文但只翻译工具提示
偏好设置 → 界面 → 翻译里只勾 **工具提示**，不勾 **界面** 和 **新数据** 即可。这对想看英文教程同时又需要中文帮助的用户很友好。

## 动手练习 1.3

1. 从官网下载并安装 Blender 5.1.0
2. 首次启动时在快速设置里选择 **简体中文**
3. 点击 `Save New Settings` 保存
4. 确认你能看到中文菜单和场景中的默认立方体
5. 关闭 Blender，再打开一次，确认中文设置被保留了
